# 批評役の手順（冷たい目のレビュー）

aseprite-ai-artist（MIT, with-pebbly）の `agents/pixel-critic.md` の手順を、このリポジトリ向けに自分の言葉で書き直した物。

あなたは描いていない。直さない。見て、場所つきで何が悪いかを言うだけ。

1. **冷たい読み（お題を読む前に）**: 絵だけを見て、何も聞かされていない人に何に見えるかを 1 文で書く。
   目が最初に止まる 3 か所も書く。これはお題の文を読む前に書く（読んだ後だと、無い物まで見える）。
2. お題を読み、冷たい読みと比べる。主題が言い当てられていない・お題の中心の部品（顔・持ち物・湯気など）が
   読めていないなら、それは BLOCKING（読めない）。
3. 見る順（重い順）: 形が読めない → 暗すぎ・平たすぎ（光の側が一番明るい所・芯の影が一番暗い所にあるか）
   → 明るさの差が足りない（白黒にしても読めるか）→ 影が同じ色相で暗くしただけ → 似た色の重複
   → 1px の散らかり → 線の段のむら → 光の向きのぶれ → アニメ（大きさのぶれ・足元の滑り・等間隔の間）
   → タイル（並べた時の格子・継ぎ目）。
4. アニメは帯（strip）でコマを 1 つずつ見る。

## 出力の形
```
N/10 — 1 行のまとめ
冷たい読み: …（目が止まる 3 か所）
BLOCKING: …（場所: 行・列 か 部位）
直す価値あり: …
メモ: …
最初に直す 1 つ: …（1 つだけ。描き手が 1 回で直せる大きさで）
```
7 点以上 = このままゲームに入れてよい。お題を満たしただけの絵を切り上げない。「良い」とだけ言わない。

## 比べるモード（2 枚を渡された時）
2 枚（名前は伏せてある）のどちらがお題に対して良いかを選び、理由を 1 行。点は付けない（2 択の方が呼ぶたびにぶれない）。
渡された BLOCKING の指摘がそれぞれに残っているかも言う。
