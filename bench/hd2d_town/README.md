# hd2d_town — HD-2D の町の試作（タイル地図 → 3D の町・パーティが歩く）

plans/engine-hd2d.md の段階 0 のうち、「タイル地図 JSON から 3D の地面と箱を組み、2D の絵を立てる町」と
「パーティ 3 人が大通りを歩いて止まる」を、エンジン（Scene3d）だけで組んだ試作。どの口も窓を開かない。

| 口 | 中身 |
|---|---|
| `make compare` | Blender の試作（`~/Desktop/hd2d_lab/art/hd2d_gen/out/blender_tilemap_avenue_15_50_day.png`）と同じ止めたカメラ・同じ配置で 1 枚描き、左右に並べる（`debug/compare_side_by_side.png`） |
| `make frames` → `make video` | 地図の `walk` の台本で歩いて止まる 30 fps のコマを CPU（SoftRaster）で描き（`debug/frames/`）、mp4 にする（`debug/hd2d_town_walk.mp4`） |
| `make time` | 歩く場面の 1 コマの CPU の時間（後がけつき・なし） |
| `make test` | 地図の読み・立体の決まり・面の向きと uv・カメラの式・隊列と追従カメラ |

## 作り

- **地図**: `assets/town_avenue.map.json`（hd2d_lab の写し。ground・height・shape・objects の文字の格子・buildings・margin・camera.frame・walk・variants）。
  差分 `variants.step`（草を 0.25 m 上げて縁石と笠石）を使う。
- **立体の組み立て**（`src/TileMap3d.flix`。Godot の GridMap・Unity の Tilemap に当たる）: Blender の試作 `blender_tilemap.py` の決まりを写した。
  床（座標のハッシュで 90° 回しと反転・頂点の AO）・段の側面（隣より高いマスのふち）・縁石と笠石・下げた水路と水面・建物（壁タイル 3 段・窓と扉は壁の絵の差し替え・階の境の帯・厚みのある切妻屋根）・
  面ごとにタイルを貼る箱（生垣は隣の生垣と面を省く・木箱・柵・目印の石の柱）・地図の外（低い地面と暗い森）。
  面は材質ごとに 1 つの形にして `Scene3d.staticGroup` 1 つにまとめる（読み込みで 1 回）。
- **板の物**（木・低木・街灯・町の人・隊列）: `Scene3d.billboard` + `withCastShadows(true)` + `withReceiveShadows(true)`。32 画素 = 1 m。
  カメラが水平なので板は地面に垂直に立つ（1/cos の伸ばし無し）。足元の楕円の影はコードで作った絵を半透明の四角に貼る。
- **カメラ**（`src/TownCamera.flix`）: `Camera3d.lensShift`（段 1 でエンジンに足した欄）。画面の上の端で 15°・下の端で 50° 地面を見下ろす
  （lensShift.y ≈ −0.79・縦の画角 ≈ 49.6°）。目の位置は地図の `camera.frame` から Blender と同じ式で決める。
- **隊列と追従カメラ**（`src/Party.flix`）: 先頭が `walk.col` 列を `fromRow` → `toRow` へ北へ歩き、仲間は 1 マス・2 マス後ろの道をなぞる。
  歩く速さは「画面の真ん中の行で地面が `groundFlowH`（画面の高さ/秒）流れる」値（この地図で約 2.3 m/s）。
  カメラは歩く間は先頭と同じだけ動き（遅れ 0）、止まる時だけ `stopSec`（0.7 秒）かけてなめらかに止まる（先頭が止まる前後に半分ずつ・後ろへ戻らない）。
  `CameraRig.followDelta` は「目標との差 × min(1, k·dt)」なので、等速で歩く間ずっと速さ / k の遅れが残る。遅れ 0 の追従には足りないので使っていない。
- **テクセルに丸める**: `assets/town.json` の `snapToTexels`（既定 true）。隊列の位置とカメラを 1/32 m に丸め、先頭とカメラの距離も丸めた値にそろえる。
- **見た目のつまみ**: `assets/town.json`（角度・太陽・環境光・かすみ・露出・ブルーム・F 値・彩度・色の掛け目・周りの暗さ・影の奥行き）。

## 歩く先の町が出来ていく動画（`assets/buildup.json`・`src/Buildup.flix`・`src/BuildVideo.flix`・`src/TownGpu.flix`）

- 町の面は持ち主の部品（マスの地面・箱の物・目印・建物の壁・屋根・窓と扉 1 枚ずつ）ごとに形を分け（`Faces.Owner`・991 個）、時刻で出し方を替える。
  マスの地面はせり上がり（少し行き過ぎて戻る）、箱の物と板の物は 5 m 上から降って着地し（一瞬つぶれて伸びる・土ぼこりのドット絵の粒・足元の影は小さい所から広がる）、
  建物は壁が下から伸び → 屋根が降ってかぶさり → 窓と扉が 1 枚ずつポンと出る。目印の石の柱は 14 m 上から降り、カメラが上下に小さく揺れる。
- 出来た物は `staticGroup("settled")` にまとめ、出来ていく途中の物だけを毎コマ置いた物として描く。まとめ直しは 0.5 秒（15 コマ）ごと（その間に出来た物は置いた物で描く）。
  毎コマまとめ直すと engine が「30 コマ続けて作り直した」と知らせるため。全部出来た後は読み込みで作った町の集まり 1 つに替える。
- 歩き: 背中・右・正面の 2.5 頭身の帯（左は右の反転）・コマは 0.333 秒ごとに全員同じ時計で・約 3.46 マス/秒・足元は画面の上から 55%・キャラの影は足元の楕円だけ。
  カメラの横と奥は先頭の道を Hann 窓でならし（等速の間は遅れ 0・止まる・曲がる所だけ 0.35 秒ずつ丸める）、高さは指数で遅れて追う（k = 2.5/秒）。
- 置く升を先に薄く光らせるのは入れていない（推し: 入れる。せり上がりの 0.3 秒前に升の形の光の板を半透明で置く。次の手）。
- GPU で撮る: `make gpu-buildup`（隠しウィンドウ・`FLIX_GE_FRAME_SHOT`・dt 固定 1/30）→ `make buildup-video`。窓の書き出しは engine が 1 回の起動で 64 コマまでに決めているので、頭のコマを替えて 16 回起動する。
  GPU の描き手のビルボードは project.json の textures の名前だけを引くので、GPU の時は板の絵を project.json の名前で渡す（`Look.projectBillboards`）。
- 重さ: `make gpu-bench`（出来た町を歩く場面・後がけと太陽の影のあり・なしの 4 通り・垂直同期なし・`debug/gpu_bench.log`）。
  WebGPU（Apple M4 Pro・1280×720）の 1 コマ（2 区間 × 240 コマ・ms・avg / p95 / p99）: 後がけ＋影 4.4〜3.3 / 5.5〜3.9 / 6.0〜4.3・後がけだけ 3.9〜2.8 / 5.1〜3.6 / 6.2〜3.9・
  影だけ 2.2〜1.7 / 3.1〜2.0 / 3.3〜2.5・どちらも無し 2.1〜1.7 / 2.6〜2.0 / 2.9〜2.3。GPU の時間（timer query）は WebGPU では取れず null（1 コマの時間は CPU と GPU の重い方で決まる）。
- まとめ直しの重さ（CPU・値を作って描く物の列を出すまで）: 出来ていく 12.6 秒の間に 25 回・合計 5.0 ms・最大 0.38 ms。GPU の描き手が持ち越しを作り直す重さは上の gpu-bench には入っていない【未測】。

### 前線と待機の動き（人の指摘「歩きながら生成されていく感じに」「待機モーションがほしい」の後）

- 横 1 行は同時に出来る。前線は先頭の 4 行先（`lead`）で先頭と一緒に進み、止まれば止まる。建物はその一番手前の行に前線が来た時に生える。
  先頭が行き着いた後に残る奥の行は 1 秒に 2.5 行（`afterRowsPerSec`）。はじめに隊列のまわりの行は 1 行 0.18 秒おきに出来る。
- 地図の南の外（カメラの手前）を一番南の行と同じ高さにした（南の端の崖の面が画面の下を屋根のように横切っていた）。
- 待機: 届いた息遣いのコマ（`traveler_idle.png`・`merchant_idle.png`・向きごとに 吸った・吐いた）を 0.8 秒ずつ・1 人ごとに 0.27 秒ずらす。
  絵が無い時の代わりに、息遣い（1.8 秒で縦に ±1.5%）と足踏み（歩きのコマを 0.5 秒ごと）を `idle` で選べる。

### キャラの影（人の指摘「影が弱い」「本家の影を真似て人形に斜めに伸びる感じに」の後）

| 予告の町のコマ（P05）の読み | 数と特徴 |
|---|---|
| 向き | 太陽の向きへ斜め（このコマでは画面の右上・北東へ。町の太陽の向きの場面ごとに替わる） |
| 長さ | 背の 0.8〜1 倍。大半はキャラの体の後ろに隠れ、横に細い筋として見える |
| 濃さ | 日なたとの明るさの比 約 0.67（影 105・日なた 156） |
| 縁 | 柔らかい（720p で 2〜3 px ほどのぼけ） |
| 人の形 | 輪郭（帽子のつば）が読める程度 |
| 足元の濃い所 | ほぼ無い |
| 隊列の 3 人 | 縦に並んでも影は斜め横へ出て、前の人の体に隠れるので重ならない |

- 第 1 案「人形の斜めの影」= engine の板の太陽の影（`withCastShadows`・絵の α で形を切る・歩きのコマに合わせて形が替わる）。影の地図 4096・縁のならし 2 で縁の揺れを抑える。足元は薄い小さな楕円だけ。
  太陽 55° なので長さは背の 0.7 倍。この町の太陽（南から東へ 35°）では影は北西（画面の左上）へ伸びる。
- 比べ用の 3 案: 濃い楕円（α 最大 0.95・幅 1.2 倍）・楕円＋太陽の向きへ 0.7 m の薄い影（α 0.6）・小さい濃い塊（幅 0.75 倍・影の側へ 0.12 m）。`charShadow`（GPU は `CHAR_SHADOW`）で選ぶ。
- 影の濃さは場面の太陽の影 1 つ（`shadowStrength`）で決まり、キャラの影だけを薄くする欄は engine に無い【engine の案: ビルボードごとの影の濃さ】。

### 夜と霧（`assets/town_night.json`・`town_night_fog_mid.json`・`town_night_fog_strong.json`）

- 夜: 月明かり（南西 −35°・高さ 40°・青 (0.45, 0.55, 1.0)・強さ 0.2）・環境光 0.05・露出 −1.8・街灯 6 本の点光源（強さ 7・届く 5.5 m・火袋の 0.25 m 手前）・火袋の光る板（emission × 6）＋ブルーム。
- 街灯は Blender の 3 灯の飾り街灯（`sprites/street_lamp_ornate.png`・43×104 画素）。夜は火袋のガラスの画素（明るさ 0.55〜0.8）だけを、火袋の真ん中から 6 画素でなめらかに落ちる重みで光らせる板（`Images.lanternGlow`・emission × 16）と、火袋ごとの淡いハローの丸い板（1.1 m・× 0.64）を重ねる。点光源は柱ごと 1 つ（真ん中の火袋の高さ 2.47 m・0.7 m 手前・色 (1.0, 0.7, 0.38)・強さ 5.5・届く 5.5 m）。lift (0.98, 0.97, 1.06) で暗い所を紫へ。
  予告の数のうち、ブルーム 0.7 / 1.2 / 0.85 と届く 8 m は町全体が橙の靄で白っぽくなったので、閾値 0.9・強さ 0.3・大きさ 0.85、届く 5.5 m に戻した（前後の絵 `debug/ornate_lamp_before_after.png`）。点光源の影は engine の別の枝待ち。
  地図の街灯は 6 本で、engine の 8 本の選び方の内に収まる（Blender の試作は差分で 12 本。足すなら画面に同時に 6〜8 本）。
- 霧: engine の `PostStack.HeightFog`（別の枝から merge）。中 = 濃さ 0.8・高さの落ち 1.2/m・上限 0.8・奥の霞 12→40 m／強 = 濃さ 1.6・落ち 0.9/m・上限 0.92・奥の霞 8→30 m・
  色は夜の青紫 (0.56, 0.52, 0.82)・むら 4.5 m・流れ 0.5 m/秒・街灯のにじみ 1.2。霧の板の代用（`town_night_fog_sheet.json`・雲状ノイズを流す半透明の板 2 枚）は比べ用に残す。
- 板（キャラ・木）は光の法線がカメラ向きなので、北に立つ街灯の光は板の裏から当たり、真っ黒な影絵になった。engine の板の材質は点光源を受けるが、
  法線がカメラ向きに決まっていて、灯りに近い側を明るくする道は無い【engine の案: ビルボードの光の法線を上や灯りの方へ寄せる欄・点光源の影と一緒に】。
  ゲーム側の仮の手: 夜は板を光を当てない板にして、色の掛け目を「夜の地 (0.32, 0.35, 0.55) ＋ 街灯の色 × 近さ（届く距離の 1.2 倍で 0・2 乗）× 1.6」にする（`boardLamplight`・街灯の板は除く）。
  灯りに近い側だけを明るくする事はできない（板 1 枚で 1 色）。光を当てない板なので、夜はキャラが建物の影を受けない。
- 人が決めた夜の霧は「中」。キャラの影は「人形の斜めの影」を長く: 昼の太陽を 55° → 40° にして、影は背の 0.7 → 1.2 倍（街灯・木・建物の影も同じ向きと長さ）。

## 動かす前に

- engine の出ていない版の API（`Camera3d.lensShift`・`Camera3d.camera`）を使う。engine の根で `make sync-engine-full` してから流す。
- CPU の 1 コマは 1280×720 で後がけつき約 1.3 秒・なしで約 0.26 秒（`make time`）。`make frames` は 279 コマで約 6 分。

## 確かめた事と、確かめていない事

- CPU（SoftRaster）の描き出しだけで確かめた。**GL・WebGPU の窓では見ていない【未確認】**（人が「今ゲーム起動しないで」と言ったため）。
- 後がけ（AgX・ブルーム・ピントの奥行きでぼかす・彩度・周りの暗さ）は CPU の後がけの道（`PostStack.build` → `HeadlessRender.renderPngFull`）で掛けた。
- 窓で入力で歩く版（`Main`）は作っていない。台本で歩く。

## 人に決めてほしい事（推しつき）

1. **lensShift を `Camera3d` の欄にした事**（閉じたレコードに欄を足した）。外のゲームで `{ eye = .., far = .. }` と全部の欄を字で書いたカメラはコンパイルできなくなる（リポジトリの中の 60 か所は直した。外の fps3d_lab・lamplighter などは engine-upgrade の時に `lensShift = Vec2.zero()` を足すか `Camera3d.camera(..)` へ替える）。
   推し: このまま（Unity の Lens Shift と同じ欄・作る関数 `Camera3d.camera` も足した）。リリースの移行メモに 1 行載せる。
2. **TileMap3d をこの bench に置いた事**（engine_world へ上げていない）。理由は「層を置く物差し」（使い手が 1 本だけ）。
   推し: lensShift が出たら hd2d_lab へ移して、ここは消す（2 つの写しが別々に育たないように）。
3. **見た目の差**（並べた 1 枚）: 形・配置・カメラは Blender とほぼ重なる。色はエンジンの方が石畳が明るく白っぽく、Blender の方が暖かく霞む。
   推し: 色合わせはつまみ（`assets/town.json`）で続ける。Blender の板は「法線を太陽へ向けた」光の当て方で、エンジンの板は法線がカメラ向き（太陽 55°/35° で約半分の当たり）なので、板の明るさは `boardTint` で寄せる。
   法線を太陽へ向ける欄をエンジンに足すかは相談（ビルボードの光の法線）。
   2 回目のレビュー（78 点）の後に直した: ピントを目からの距離にした（手前の石畳がぼける）・環境光を下げ hemisphere を上げた・影の奥行きを 28 m に絞った。
   「色と線が濃く、影が目立たない」と言われて切り分けた（`bin/three_up.sh` で前・後・Blender を並べた 1 枚 `debug/look_before_after_blender.png`）:
   - 色と線が濃い元は、後がけの色の仕上げの `lift` を 0 にしていた事（`PostStack.ColorGrade` は 1 が「何もしない」。0 で暗い所が黒く潰れ、屋根と生垣の暗い所が中央の 0.1 倍まで落ちていた）。`town.json` の `lift`・`gamma` に出し、1 にした。
   - 影が浅い元は、ブルーム（0.35）が日なたの全部を拾って画面を白く霞ませていた事と、環境光が強すぎた事。ブルームを 0・環境光 0.15・太陽 3.0・影の濃さ 1.0 にした。
   - 数（1920×1080 の切り抜き・Blender / 前 / 後）: 奥の石畳の明るさ 187 / 207 / 187・目地の暗さ（p5/中央）0.57 / 0.41 / 0.67・隣の画素の差 4.6 / 8.4 / 5.0・屋根の彩度 0.55 / 0.62 / 0.65・生垣の彩度 0.46 / 0.72 / 0.56。
   残る差: 建物の西の壁（日の当たらない縦の面）が Blender より暗い（Blender は空の光が縦の面にも回る）。Blender の画素の縁の柔らかさ（描き出しの 1.5 px のフィルタ）は FXAA で少し寄せただけ。
3b. **シフトしたカメラの太陽の影の地図が粗い**（エンジンの相談）。視錐台を囲む球（`Scene3d.shiftedFrustumSphereOf`）は、下へずらした角が地面のずっと下まで伸びるので半径が大きく（影の奥行き 40 m で約 51 m）、2048 の地図で 1 テクセル ≈ 5 cm になり、街灯の柱の影が PCF で消える。
   推し: 当面は `shadowDistance` を絞る（ゲーム側・今は 28 m）。足りなければ「影を受ける物の高さの範囲（地面の高さの下限）で球を切る」欄を相談する（見下ろしの 3D 全部に効くが、場面に地面の高さの約束が要る）。
4. **森の板は影を落とさない**（CPU の 1 コマが重くなるわりに見えない）。Blender は落とす。推し: このまま。
5. **四角の対角線を AO で選び直している**（Minecraft の頂点 AO）。Blender は選び直さないので、暗い角の形が少し違って見える。推し: このまま（良くなる方の違い）。
6. **歩き出しは 1 コマで全速**（Blender の試作と同じ）。止まり方だけなめらか。推し: 0.2〜0.3 秒でなめらかに加速させる（次の手）。
7. **窓で入力で歩く版**: 止まる時刻を前もって知れないので、今の「止まる前後に半分ずつ」の寄せはそのまま使えない。推し: 歩く間はカメラを速さ × stopSec / 2 だけ後ろに置き、止まったら同じ式（1 − smoothstep の積み）で追いつかせる（遅れは一定で、止まる時に戻らない）。
8. **TileMap3d の中の向き・面・壁の種類が文字列のまま**（"s"・"tnsew"・"door"）。推し: hd2d_lab へ移す時に enum にする。

## 立ったまま輪で出来る動画

`make center-video`（台本 `assets/buildup_center.json`・`BUILDUP` で切り替え）。隊列 3 人は大通りの真ん中（列 13・行 12）に横並びで立ち、息遣いのまま動かない。
前線は行ではなくマスまでの距離で決める（`Buildup.radialFront`）。はじめはゆっくりで、後ほど速い: 輪の届く距離は時間の 1/0.65 乗で増え、8 秒で一番遠いマスへ届く（3 秒で足元の 2〜3 マス）。
部品の動きの秒は出始めの 2.2 倍から終わりの 0.7 倍へ替え、土ぼこりの粒はその逆数の倍（後ほど多い・`Buildup.paced`）。記念碑は最後に降ってカメラが揺れる（幅 0.2 m）。
カメラは足元からの距離 0.45 倍で寄った所から 1.35 倍へ、時刻でなく輪の届いた割合で引く（輪が 80% 届いた所で引き終え、輪が画面の外へ出る前に追いつく）。
輪が届いた後に遅れて降る物は作らない（マスの時刻を輪の終わりで頭打ちにし、終わりの部品の秒は 0.55 倍＝落ちる 0.15 秒）。記念碑は輪が止まった瞬間に降りはじめ、0.28 秒でドスンと着地する。
着地の演出（`Buildup.impactOf`）: 3 コマ止める（`storyTime`・hitstopSec 0.1）・露出を 3 段上げて 2 コマで戻す（`flashAt` → `TownScene.postFlashAt`）・縦揺れ 0.35 m を 0.5 秒で減らす・土ぼこりは粒 3.5 倍で外へ大きく広げる・
衝撃が 14 m/秒で外へ伝わり、木・街灯・町の人の板が距離で遅れて跳ねて縮む（`waveAt`・近くで 0.6 m）。木箱と生け垣は出来た物の集まりに入っているので跳ねない（跳ねさせると集まりを毎コマ作り直す）。
カメラは引き終えた時に追う点を北へ 3 m ずらし、奥の記念碑が降る所を画面に入れる（aimNorth）。全部出来るのは 9.2 秒。立つ所は大通りの入口（列 13・行 15）。揺れが収まった 1.0 秒後（10.6 秒）に、先頭が大通りを北へ 7 マス、記念碑の池の手前（行 8）まで歩き、2 人は 0.9 秒かけて横並びの位置から 1 マスずつ後ろへ寄る（`formationAt`）。
建物の裏へ回る道（前の版の東へ曲がる道）は、右の建物の陰にパーティが隠れたのでやめた。カメラは歩き出してから 1.5 秒で、引いた位置から歩く追従カメラ（横と奥は先頭を追い、止まる所だけ丸める）へ移る。
歩くカメラの引きは 1.7 倍（足元の点からの距離・`walkZoom`）で、止まった所でもパーティと池と記念碑が画面に入る。足元は画面の高さ 0.62。2.0 秒歩いて止まり、正面を向いて息遣いで 4.5 秒（全体 17.5 秒・526 コマ）。
