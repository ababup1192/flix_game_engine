# 画面なしで流す・出来事で鳴らす・番号で選ぶ（0.45.0 の 4 つ）

試し（`spike/engine-abstraction`）を tetris とノベルに当てて型とテストが通った物を、エンジンに足した。
どれも足すだけで、今ある API の型は変えていない。使い方の全文は各モジュール冒頭の doc。

| | 足した物 | 何を解くか |
|---|---|---|
| N1 | `App.trace` / `App.traceFrame` / `App.TraceStep` + `PropertyTest` | 画面を開かずに実機と同じ経路（advanceFrame → audio → sustained）を流し、でたらめな入力で「どう遊んでも崩れない決まり」を確かめる |
| N2 | `Timeline.soundsSince` / `progressSince` | 途中で始まる演出（起点の時刻を World に持つ）の音と進みを、同じ時刻表から引く |
| N3 | `eff Emit[e]` + `Emit.collect` / `Emit.Events` / `collectInto` / `since` | 規則の奥で起きた出来事を、戻り値を変えずに外へ出し、固定刻みでも 1 回ずつ鳴らす |
| N4 | `Hash01.indexOf` / `pickBy` | 番号で列から 1 つ選ぶ（同じ番号なら毎回同じ・乱数の状態を持たない） |

## N1 性質テスト（PropertyTest）

**何を:** 種（seed）で決まる入力の列（`Input[r]` = Idle・Tap・Hold・Release・Move・Press・Drag・Up・Wheel）を
`generate` で作り、`App.traceFrame` で 1 フレームずつ流す。決まりは「1 フレームの前後（`App.TraceStep`）→ 崩れていれば説明」。
`forAll(app, setup, { seeds, length, spec }, 始まり, 決まり)` が `None` なら全部の種で通った。崩れたら
「seed 3・120 フレーム目（入力 98 個目）: 説明」が返る。

**なぜ:** 「この手順ならこうなる」のテストは、書いた人が思いついた押し方しか見ない。音が 2 回鳴る・数が合わない、は
思いつかない押し方（同じフレームに 2 つの操作・刻み 0 回のフレーム）で出る。乱数で押し方を作り、崩れた最初の所を指す。

**決めたこと:**
- フレームは実機と同じ `App.frameOf` で組む（押した瞬間 = 前のフレームに無かったキー）。続けて同じキーを Tap する・押したまま
  Press するときは間に離すフレームを 1 つ挟む。挟まないと 2 回目が押した瞬間にならず、テストが「押したのに反応しない」を見落とす。
- `keyOf` は `(役, World) -> Key`。キーの割り当てを Doc で変えるゲームは World の Doc から引く。
- 決まりは数が保たれる形で書く（升の数 = 前の升 + 固めたミノ × 4 − 消した行 × 10・灯り = 前の灯り − 疑った数）。
  「同じ種なら同じ盤」は乱数を使わない規則ならいつも通る弱い決まりなので使わない。
- 空振りを止めるテストを 1 本添える（どれかの種で行が消えている・選択肢の 2 つ目が選ばれている）。
  ノベルの雛形は最初 UI が空の World で流していて、選択肢のカーソルが動かず、壊しても通っていた。

**ほかのジャンルでは:** アクション = HP が負にならない・敵の数 = 涌いた数 − 倒した数。RPG = 所持金 = 前 + 拾った − 買った。
パズル = 手数が 0 より下にならない。UI = 開いた窓は必ず閉じられる（Escape を押し続ければ最初の画面へ戻る）。

## N2 起点から測る時刻表（soundsSince / progressSince）

**何を:** `soundsSince(起点, 前のフレームの時刻, 今の時刻, 表)` = `soundsBetween(前 − 起点, 今 − 起点)`。
`progressSince(起点, 今, タグ, 表)` = 起点から測った `progressOf`。

**なぜ:** 灯りが消える・敵が倒れる演出は、ゲームの時計の途中で始まる。起点を World に 1 つ持てば、鳴らす側（audio）と
描く側（view）が同じ表を読み、音と絵がずれない。起点を置いたフレームは前の時刻が起点より前なので、頭の音も鳴る。

**ほかのジャンルでは:** 敵が倒れた時刻を起点に、倒れる動き・爆発の音・得点の表示。宝箱を開けた時刻から、蓋・光・音。

## N3 出来事（Emit）

**何を:** 規則は `Emit.emit(出来事)` と書き、型に `\ Emit[Event]` を足す。系は `Emit.collectInto(() -> 規則(…), w#events)` で
出来事を World の欄 `Emit.Events` に溜める。audio は `Emit.since(ws#before#events, ws#after#events)` で、このフレームに
足された分だけを読む。規則を直に呼ぶテストは `Emit.collect` で包む。

**なぜ:** 戻り値に `(World, 出来事の列)` を通すと、途中の関数が全部その形に変わる。effect なら途中の関数は型に 1 つ足すだけ。

**固定刻み（withFixedStep）の決まり:** 「毎刻み events 欄を置き換える」形は、刻みが 0 回のフレームに前の出来事が残って
もう一度鳴り、刻みが 2 回以上のフレームは前の刻みの出来事が消える。`Emit.Events` は collectInto の呼ばれた回数を通し番号として
出来事に振り、audio は前後の World の番号の差を読む（Bevy の `Events` と同じ考え: 書く側は番号を進め、読む側は前に読んだ所を覚える）。
刻み 0 回のフレームは World が変わらないので空、2 回以上なら全部の刻みの分が出た順に読まれる。
`engine_world/test/TestEmit.flix` が、長さの違うフレーム（刻み 0〜5 回）を 20 種 × 200 フレーム流して確かめる。
溜めは collectInto 64 回分を残す（1 実フレームの間の呼ばれ方 = 刻み 5 回 × 出来事を集める系の本数より多ければ読み落とさない）。

**ほかのジャンルでは:** シューティング = 当たった・倒した・取った。RPG = 戦闘の 1 手の中の「急所」「状態異常」「レベルアップ」。
物理パズル = 固定刻みの中で起きた衝突の音。

## N4 番号で選ぶ（Hash01.indexOf / pickBy）

**何を:** `indexOf({ index, channel }, n)` は 0..n−1 の添字、`pickBy(鍵, 列)` は列の 1 つ（空なら None）。同じ鍵なら毎回同じ。

**なぜ:** 台詞の差分・敵の技・タイルの柄を選ぶたびに乱数の状態を World に持ち回すと、選ぶ順や回数で結果が変わる。
番号（何体目・何日目・何行目）から選べば、巻き戻しても描き出しても同じ物が出る。

## やらない事

- **App の型を変えない。** `App[w, ef]` に出来事の型の引数を足さない。出来事は World の欄に置き、App は前後の World を audio に
  渡すだけのまま（今の withAudio の形）。
- **乱数の effect は作らない。** 性質テストの列は標準ライブラリの `Math.Random.runWithSeed` で作り、ゲームの規則には乱数の
  effect を持ち込まない（選びは Hash01 の番号か、World に持つ種）。
- trace は Doc の読み直し・F8・ミキサーを通さない（実機でもフレームの中身を変えない物）。
- 縮める（shrink: 崩れた列を短くして見せる）はまだ作らない。崩れた入力までの列（`Broken#inputs`）を返すまで。
