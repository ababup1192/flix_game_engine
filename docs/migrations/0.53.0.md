# engine 0.52.2 → 0.53.0 の手当て

自動生成の一覧は [0.53.0.auto.md](0.53.0.auto.md)（直す物 0 件）。

入ったのは 2 つ。

1. **人が見る動画を GPU で書き出す**（gpuvideo）: `VideoOut.writeFrames` が塗る物を選び（`FGE_GPU=auto|on|off`・既定の auto は駄目なら SoftRaster にして
   1 行知らせる）、どちらでも 1 コマごとの鍵 `drawhash.txt` とコマの表 `frames.json` を同じ形で書く。GPU の道は生の画素を ffmpeg へ流して
   `frames.mkv`（ffv1 の可逆）と `last.png` を書き、SoftRaster の道は今まで通り `f0000.png …` の連番。シェーダーの面は 1 回だけ書き出す（`bakeSurfaces`）。
   比べ（compare・reference-check）は今まで通り SoftRaster の絵と鍵だけを使う。
   internet_dungeon の transition（910 コマ）: GPU 64 s・`FGE_GPU=off` 251 s。drawhash.txt・sfx.txt・bgm.txt・コマ数・鍵の数が一致。
   Match3 の miss（203 コマ）も drawhash.txt が一致。gl-parity に半透明の幕の場面 veil を足した（7 場面とも 0 px）。
2. **窓なしのゲームの jar を分け合う**（jarshare・設計は [docs/design/prebuilt-jar.md](../design/prebuilt-jar.md)）: `bin/headless-run` は jar が古いと
   分かったら、作る前に段 1（同じ機械の `~/.cache/flix-headless-jar/<鍵>/`）→ 段 2（ゲームの repo の prerelease `headless-jar-cache` の `<鍵>.jar`・
   gh で取り 30 秒で諦める）の順に見て、鍵と中身の SHA-256 が合えば写して使う（「[headless-run] 先に作った jar を使う（段 1 か 2・N 秒）」）。
   新しい作業場の 1 回目の `make render SHOT=title` が、作る時 83〜114 秒・段 1 から取った時 7.6 秒（重い時間帯の途中の測り）。
   段 2 へ上げるのは作り手（`bin/fge jar builder run`・`FGE_JAR_PUBLISH_REMOTE=1`）だけ。launchd の作り手（`bin/fge jar builder install`）は
   口だけで、Mac mini へはまだ取り付けていない。

## ゲームで直す物

1. **直さなくてよい**: 自動の一覧は直す物 0 件。今の `VideoKit` などの動画の口はそのまま SoftRaster で書く。
2. **動画を GPU で書き出すには** `VideoOut.writeFrames` を使う（internet_dungeon は ababup1192/id-gpuvideo の `VideoKit`・`FlowVideo`・`Match3Video`）。
   SoftRaster の連番（`f0000.png …`）を読んでいた道具は、GPU の道では `frames.mkv` と `last.png` を読む（`frames.json` の `painter` で見分ける）。
3. **Match3 の動画の SoftRaster の絵は、面の貼り絵のずれの直しの分だけ前と変わる**（机と紙の面が半分ずれて欠けていた。GPU の絵が正）。
   internet_dungeon の reference-check（194 枚）には Match3 の動画のコマは入っていないので、更新する基準の絵は無い。動画を前後で比べる時は、
   この直しの分の違いが出るのが正しい。
4. **分け合わない時**: packages.lock の無いゲームと、`FLIX_CMD` で別の flix を渡した時は分け合わない。`FGE_JAR_CACHE=off`（段 1・段 2）・
   `FGE_PREBUILT_JAR=off`（段 2）で止められる。build/headless/.lock/pid と last-build-seconds の形は変わらない（取った時は last-build-seconds を書かない）。

## 新しく使える物

| 口 | 中身 |
|---|---|
| `VideoOut.settingsOf` / `writeFrames` | 動画のコマを GPU か SoftRaster で書き、鍵とコマの表を同じ形で書く（`FGE_GPU`・`FGE_VIDEO_PAINT=all|none|frames:A-B`・`FFMPEG`） |
| `bin/fge jar builder run --repo=<ゲームの clone>` / `install` / `uninstall [--dry-run]` | jar を先に作って段 2 へ上げる作り手（launchd は 5 分ごと） |
| `FLIX_PRINT_JAR=1 bin/flix` | 使うコンパイラの jar のパスを出して終わる（JVM を起こさない） |
