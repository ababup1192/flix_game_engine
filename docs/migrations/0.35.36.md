[../rule-defenses.md](../rule-defenses.md)）。ゲームは `make sync-agents GAME=…`（engine-upgrade）で受け取る。

- **コミットのゲートがゲーム固有の口を呼ぶ**: ゲームの Makefile に `precommit-local` があれば、ステージしたファイルを

- **NOTES.md が溜まるとコミットで止まる**: 先頭の項が多すぎたら `make notes-rotate`（古い項を `notes/<年-月>.md` へ）。
- **forbid に stderr-println**: ゲームで `System.err.println` などを直に呼ぶと止まる。知らせは `Log.fellBack` / `Log.warnThen`。
- **スキル**: flix-docs・quality-assurance の例は同じフォルダの `reference.md` へ。

## 新しい口: 押す物の当たりを描く時と同じ前後で選ぶ `SortingLayer.pick`

```flix
SortingLayer.pick(pointer, (Layer.Scene, (Target.Door, doorRect) :: Nil) ::
                           (Layer.Prompt, (Target.Block, screenRect) :: (Target.Yes, yesRect) :: Nil) :: Nil)
// : Option[Target]
```

- 層の前後は `compose` と同じ `zRange` の底の順。同じ層の中は列の後ろほど手前（`ZStack.of` に積む順と同じ）。
  `UiFocusNav.hitTest`（列の前ほど先に当たる）とは向きが逆。
- 確認の窓が開いている間に奥を押せなくするには、窓の層の列の先頭に画面全体の矩形を 1 つ置く。
- if を並べて当たりの順を書いている所（例: 確認の窓 → ページ → …）は、この口へ移すと見た目の層とずれなくなる。
