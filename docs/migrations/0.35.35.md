# engine 0.35.34 → 0.35.35 の手当て

自動生成の一覧は [0.35.35.auto.md](0.35.35.auto.md)。

- **字も薄まる**: `Render.fade` / `fadeAll` が字（`Render.Item.Text`）にも効くようになった（今までは字だけ濃いまま残った）。
  字を薄めたくなくて fade の列に混ぜていた所は、字を列の外へ出す。字を `tint` の暗さで薄めていた手当て
  （`Color.darken` など）は fade に戻せる。直した後は `make compare` で、字の出入りの絵だけが変わったかを見る。
- **一発の音はループしない**: 鳴り続ける音（`App.withSustained`）と同じ名前を一発の音（`App.withAudio`）で鳴らすと、
  ループの設定が残ってループし続けていた。エンジンが鳴らす前にループを外す。同じ名前を使い分けていた所はそのままで良い。
- **noTempo に拍を書くと止まる**: `Timeline.noTempo()` の表に拍・小節（`Beats`・`Bars`・`ToNextBar`・`ToBeat`・`ToPickup`）
  で書いた行があると、`build` が `BuildError.BeatsWithoutTempo` を返す（`buildOrBug` は止まる）。
  曲に乗せる表は `Timeline.tempo(bpm, 拍子)` を渡す。
