# engine 0.108.0 → 0.109.0 の手当て

（手書きの節。版を上げる時に変わった所を足す。）

## make の run・render・check・test・flow とゲーム固有の作業を bin/fge から打てる（Windows でも）

`make run`・`make debug`・`make render`・`make render-all`・`make check`・`make test`・`make flow` の中身は `bin/fge` に移った
（`bin/fge run`・`debug`・`render <場面>…`・`render --all`・`check`・`test`・`flow run <flow>`）。make のターゲットはそれを呼ぶ 1 行なので、
macOS と Linux は今までどおり make で打てる。Windows は make 無しで `bin/fge <作業>` を打つ（Git for Windows の bash で engine のスクリプトを起こす。plans/windows.md）。

ゲームの Makefile に書いていた設定とゲーム固有のターゲットは、project.json に移すと Windows でも打てる（移さなくても Makefile のまま動く）。

| Makefile の物 | project.json の欄 |
|---|---|
| `SHOTS := a b` | `"shots": ["a", "b"]`（`bin/fge render` の使い方と `make help` に出る） |
| `PALETTE` と `PALETTE_DEPS` | `"prebuild": [{"out": "<PALETTE>", "deps": [<PALETTE_DEPS>…], "entry": "Palette.write"}]`（run・render の前に入力が新しければ作り直す） |
| `bot: ; X=$(X) $(HEADLESS_RUN) BotRun.play` と `X ?= 5` | `"tasks": {"bot": {"entry": "BotRun.play", "about": "…", "env": {"X": "5"}}}`。Makefile は `bot: ; @$(FGE_RUN) task bot` |
| `lint-cast: ; $(PYTHON3) art/cast/lint.py` | `"tasks": {"lint-cast": {"cmd": ["python3", "art/cast/lint.py"]}}` と `"lint": ["lint-cast"]` |
| `precommit-local` が流す検査 | `"precommit": ["lint-flixlint"]` |

- 移した後は `SHOTS`・`PALETTE`・`PALETTE_DEPS` を Makefile から消す（`make palette` は `bin/fge task palette` になる）。手本はテンプレートの project.json と Makefile。
- テンプレートの project.schema.json に `shots`・`lint`・`precommit`・`prebuild`・`tasks` が増えた。
- `K=V` の引数は環境変数として入口に渡る（`bin/fge task bot BOT_RUNS=1`・`make bot BOT_RUNS=1` も同じ）。
