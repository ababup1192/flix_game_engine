# engine 0.88.4 → 0.89.0 の手当て

ブラウザ版で素材を後から取る（`web.deferred`）・3D の絵を GPU へ直接上げる変更に伴う手当て。

## ゲームで直す物

| 直す所 | 直し方 | 止める物 |
|---|---|---|
| `ImageData.ImageDecoder` を record で組むコード（`{ decode = f }`。自前の handler・テストの中も） | `ImageData.decoderOf(f)` に替える（`platformImage` と `versionedKey` の欄が増えた） | 型検査 |
| `LoadProgress` の handler を自前で書いているコード（テストで知らせを集める handler など） | op が 1 つ増えた。`def downloads(k) = k(LoadProgress.localDownloads())` を足す | 型検査（handler の op が足りない） |
| `Texture3d.argb(t)` で画素を読むコード | `Texture3d.sourceOf(t)` で受けて `Texture3d.Source.Argb(pixels)` の時だけ画素を読む（ブラウザの絵は `Texture3d.Source.PlatformImage(key)` で、画素を wasm に持たない） | 型検査（`argb` が無い） |
| 作業中の版で `App.withAssetMissing` を使ったコード | `App.withMissingAssets` に改名（引数は同じ） | 型検査 |
| テストで `LoadProgress.AssetDownloads` を record で組む偽物 | `release = _ -> checked_ecast(())` と `spentMs = () -> checked_ecast(0.0)` を足す（`LoadProgress.localDownloads()` で済むならそれを使う） | 型検査 |
| テストで `BackgroundLoad.Pending` を record で組むコード | `idleSinceMs = -1.0` を足す | 型検査 |
| `App.Rec` を record で丸ごと組むコード（App.make などを通さず欄を全部書いた所） | 欄が 2 つ増えた。`backgroundSteps = Nil` と `decodeBudget = _ -> LoadProgress.DecodeBudget.Idle(4.0)` を足す（App の関数で組むなら直す所は無い） | 型検査 |

## 絵とふるまい

- デスクトップと画面なしの絵は変わらない（`localDownloads` は全部 Loaded・GPU の段は使わない）。
- ブラウザの 3D の絵の遠くの段は GPU の `generateMipmap` で作る。CPU の段（sRGB の曲線で平均）と色が少し違う（[docs/backend-parity.md](../backend-parity.md) の「近似」）。
- `App.withDecodeBudget` の既定は `Idle(4)`（ブラウザの 2D の絵の登録の初めの予算と同じ）。タップ待ち・タイトルの間に 3D の部屋を解きたいゲームは、その間を `Idle(150.0)` などへ上げる。

## 足した物

- `LoadProgress.downloads()`・`LoadProgress.AssetDownloads`・`LoadProgress.LoadState`・`LoadProgress.DecodeBudget`・`LoadProgress.localDownloads`: 後回しの素材の取り具合を引く口（[docs/startup.md](../startup.md)）。
- `BackgroundLoad`（`Group`・`start`・`Pending`・`readiness`）と `App.withBackgroundLoad`・`App.withMissingAssets`・`App.withDecodeBudget`・`App.stepBackgroundLoad`。
- `ImageData.PlatformImage`・`ImageData.decoderOf`・`Texture3d.Source`・`Texture3d.sourceOf`・`Texture3d.fromPlatformImage`・`Texture3d.decodeAtUsing`・`Mesh3d.withContentKey`・`Gltf.fromGlbKeyed`。
- `GlContext`（render_gl の層。ゲームは直接呼ばない）: `prefersGpuMipmap`・`generateMipmap`・`texImagePlatform`・`copyTextureLevel0`。自前で `GlContext` を実装していれば足す。
