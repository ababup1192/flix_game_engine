# engine 0.59.1 → 0.60.0 の手当て

F8 で止めた画面と注釈のスクショを、走っている間と同じ描き方（`renderFrame`）で描くようにした。
前は止めた時だけ別の描き方で描いていて、シェーダー面が代表色の四角や色の式の抜けた絵になり、
レンダーターゲットも描き直さなかった（X のホームで読んだポストのアバターが、止めると灰色から元の色に戻る・
濃い紺や黒の四角が重なる）。設計は [shader-doc.md](../shader-doc.md) の「F8 の止めた画面と注釈のスクショでの見え方」。

## ゲームで直す物

**ほとんどのゲームは無い。** 次の 2 つに当たるゲームだけ直す:

1. **`GameEngine.AnnotationRequest` を record の字面で組んでいる所**は、欄 `sprites`・`tileMaps`・`polygons` を消す
   （スクショは直前に画面へ塗ったコマを撮るようになり、描画命令を運ばなくなった）。
2. **`GameEngine.Game` の `saveAnnotation` を自前で受けていて `req#sprites` などを読んでいる所**は、その読みを消す。
   `def saveAnnotation(_req, k) = k(None)` のようなモックは直さなくてよい。

## 変わったこと

- 止めている間も、シェーダー面は GPU で本物を描き、レンダーターゲット（`App.withPasses`）も表示中の瞬間の World から描き直す。
- F8 のズーム・パンは、描く前の絵にカメラと同じ式で掛ける（`Annotate.applyInspectItems`）。面もほかの絵と一緒に動く。
  ズーム・パン中だけ、タイル層と静的層をほかの絵と同じ形に直して一緒に動かす（等倍なら走っている間と同じ）。
- 矩形を決めたフレームは、等倍・重ね物無しのコマを 1 回塗ってからスクショを撮る。ズーム中に矩形を決めると、
  そのコマが 1 フレームだけ見える。
