# engine 0.35.0 → 0.35.1 の手当て

自動生成の一覧は [0.35.1.auto.md](0.35.1.auto.md)（非互換 2 件）。

## なぜ変わったか

Studio から走行中のゲームへ描き出しを頼んだとき、描き出すたびに次の描き出しを呼ぶ輪と、
ゲームの中と make の 2 系統が同時に走る事故が起きた（2026-10-11）。その直しの 2 つ。

## 1. PaletteExport.write の効果に Fs.FileRead が増えた

中身が今のファイルと同じなら書かなくなった（同じ中身を書き直すと更新時刻だけが進み、
Studio が描き出しを起こし直すため）。呼んでいる所の handler に `Fs.FileRead` を足す。

```flix
// 前
run { PaletteExport.write(path, spec) } with Fs.FileWrite.runWithIO
// 後
run { PaletteExport.write(path, spec) } with Fs.FileRead.runWithIO with Fs.FileWrite.runWithIO
```

自前で色票を書き出しているゲームは、同じように「中身が同じなら書かない」にしておくと
Studio の描き出しが無駄に起きない（比べるだけなら `PaletteExport.isSameAsOnDisk`）。

## 2. RemoteDebug.Bridge に current が増えた

命令口の依頼と答えを番号で対にした（時間切れの依頼は取り下げ、遅れた答えは捨てる）。
Bridge は `RemoteDebug.start` が作る物で、ゲームが自分で組み立てることは無いので、
`pollRequest` / `respond` を使っているだけなら直す所は無い。
