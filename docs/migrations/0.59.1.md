# engine 0.59.0 → 0.59.1 の手当て

**ゲームで直す物は無い。**

## 変わったこと

- **F8 で止めている間にウィンドウの閉じるボタンを押すと、その場で閉じる。** ゲームが `App.withCloseRequest` を持っていても、
  止めている間は確認を出さない。前は閉じる要求を持ち越し、F8 を解いた最初のフレームでゲームへ渡していたので、
  注釈の作業の後で思い出したように「終了しますか？」が出た。止めていない時は今までどおりゲームへ渡す。
- 閉じるボタンへの答え方は `App.decideClose`（loop から切り出した内部の関数。ゲームからは呼ばない）が決める。
