## 直す物: `let _ =` がコミットで止まる（新しい lint `bin/fge value-discard`）

Flix は純粋な式の値を `let _ =` で捨てると、コード生成で式ごと消す。`let _ = Log.warn(..);` の知らせも、
`let _ = if (c) bug!(..) else ();` の止めも、型検査は通ったまま実行時に何もしない（`\ IO` の関数の中でも同じ）。
エンジンにも 10 か所あり、読み込みの fail-open の知らせ（DocJson・ShaderJson・PxSpriteAtlas・TerrainDoc）と、
「texture が見つからない」（SoftRaster・Frame）・「知らない音」（LwjglLayer）の知らせが今まで 1 行も出ていなかった。

0.35.16 から `let _ =` は保存時（hook）とコミット時（precommit）に止まる。全量は `bin/fge value-discard --all`。
書き直し方:

| 今の形 | 直した形 |
|---|---|
| 効果のある式を捨てる `let _ = List.foldLeft(.. Array.put ..);` | `discard List.foldLeft(..);`（純粋な式に使うと Flix が止める） |
| 純粋な関数の中の知らせ `let _ = Log.warn(行); v` | `Log.warnThen(行, v)`（`Log.fellBack` なら `Log.fellBackThen(.., v)`） |
| 繰り返しの中の知らせ `let _ = xs \|> List.forEach(x -> Log.warn(..)); v` | 行を `List.map` で集めて `Log.warnAllThen(行の列, v)` |
| 効果のある関数の中の知らせ `let _ = Log.warn(行); Ref.put(..)` | `Ref.put(..); Log.warn(行)`（式の値として末尾に置く） |
| `let _ = ctx#warnOnce(行); v` | `match ctx#warnOnce(行) { case () => v }` |
| 条件で止める `let _ = if (c) bug!(..) else (); 続き` | `if (c) bug!(..) else 続き` |
| 使わない引数を黙らせる `let _ = x;` | 引数の名前を `_x` にする |

`List.forEach` に純粋な関数を渡すと、`let _ =` を使わずに `match` で受けても中の呼び出しが消える。
lint では見えないので、知らせを繰り返しで出す所は `Log.warnAllThen` に寄せる（docs/error-handling.md の決まり 3）。

## 新しい口: `Log.warnThen` / `Log.fellBackThen` / `Log.warnAllThen` / `Log.fellBackLine`

知らせた後に返す値を一緒に渡す口。返す値が `unsafe IO` の中を通るので、Flix が消さない。
`Log.warn` / `Log.fellBack` はそのまま使える（効果のある関数の中で、式の値として置く）。

## lint z-table: 葉の中の小さな z は表の外でも止めない

表（`instance SortingLayer[`・`ZOrder.flix`）を持つパッケージで、表の外の `def zText(): Int32 = 2` のような
葉の中の z（0..31）を止めなくなった。32 以上と負の数は今までどおり止まる。範囲は `bin/lint-rules/z-table.json`
の `leafZRange`（鍵が増えたので `make upgrade-game` で配り直す）。0.35.15 で `let zText = 2` と書いて避けた所は
`def` に戻してよい。
