# engine 0.91.0 → 0.92.0 の手当て

3D に金属っぽさと粗さ（PBR）・周りの景色の映り込み（環境マップ）・太陽の光と影を足し、並べ替えが二乗になる所を直した変更に伴う手当て。
`Scene3d.scene(...)` から `{ .. | }` で場面を組み、材質を `Scene3d.material` から作っていれば、直す所は無い。

## ゲームで直す物

| 直す所 | 直し方 | 止める物 |
|---|---|---|
| `Scene3dCmd` を record で丸ごと組むコード | 欄が 2 つ増えた。`directionalLight = None` と `environmentMap = None` を足す（`Scene3d.scene(camera, size)` からの `{ .. | }` に替えれば今後も増えた欄で止まらない） | 型検査 |
| `Scene3d.MaterialFields` を record で丸ごと組むコード | 欄が 2 つ増えた。`metallicRoughness = None` と `metallicRoughnessShade = None` を足す（`Scene3d.material(spec)` から作るのが早い） | 型検査 |
| `Model3d.GltfMaterial` を record で丸ごと組むコード（テストの見本など） | 欄が 3 つ増えた。`metallic = 0.0`・`roughness = 1.0`・`metallicRoughnessTexture = None` を足す | 型検査 |
| `ShaderDoc.limitMaterialTexReads`・`materialParamNames`・`materialParamValues`・`materialTexReads`・`ShaderGen.compile3d`・`eqMaterial`・`hashMaterial` を直に呼ぶコード（自前の描き手） | 金属っぽさと粗さの絵の引数が 1 つ増えた。使わないなら `None` を渡す（`limitMaterialTexReads` は返す組も 1 つ増えた） | 型検査 |
| `SoftRaster3d.shadowLitFractionAt`・`SoftRaster3dLight.lightAt` を直に呼ぶコード（engine_tools の開発用） | 影の関数は光の種類に依らない形になり、太陽の入力が増えた。`docs/api-digest/engine_tools.md` の今の形に合わせる | 型検査 |
| 1 万個を超える列を `List.sortBy` などの標準の並べ替えで並べているコード | 並んだ入力・逆に並んだ入力・同じ値ばかりの入力で二乗になる（標準は安定でもない）。`Sort.sortStableBy(鍵の関数, 列)` に替える | `lint-forbid` の `list-sort-quadratic` |

## 絵とふるまい

- 金属っぽさと粗さ・環境マップ・太陽の無い場面の絵は変わらない（gl-parity の既存の全行と、テンプレートの reference が一致）。
- glb の `pbrMetallicRoughness` は今までどおり読まない。読むのは `Gltf.loadTexturedPbrUsing` を使った時だけ（読むと鏡面の分だけ 1 コマが重くなる）。

## 足した物

- `Scene3d.withMetallicRoughness`・`withMetallicRoughnessTexture`・`withoutMetallicRoughness`・`metallicRoughnessOf`、`Gltf.loadTexturedPbrUsing`: 金属っぽさと粗さ（[docs/scene3d.md](../scene3d.md)「金属っぽさと粗さ」）。
- `Scene3d.environmentMap`・`withEnvironmentIntensity`・`withEnvironmentBox`: 周りの景色のパノラマを映り込みに使う・室内は箱で映る位置を合わせる（同「周りの景色を映す」）。
- `Scene3d.directionalLight`・`directionalShadow`・`directionalLightOf`・`directionalShadowOf`・`directionalLightWarning`: 太陽 1 つと、その影（同「太陽（平行光源）と、その影」）。太陽を足したら `ambient` を下げる。
- `Sort.sortStableBy`・`sortStableWith`・`sortStable`: n log n で、同じ鍵は来た順のまま並べる。
