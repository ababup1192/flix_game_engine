# engine 0.47.0 → 0.48.0 の手当て

自動生成の一覧は [0.48.0.auto.md](0.48.0.auto.md)。使い方の全文は `engine_world/src/Yarn.flix` と
`engine_world/src/YarnRunner.flix` の冒頭、読める書き方は `bin/fge yarn help`。

会話のシナリオを Yarn Spinner の `.yarn` の部分集合で書けるようにした。`.yarn` を読むのは Go の
`bin/fge yarn build` だけで（木の JSON と、出どころのファイル・行番号を書き出す）、ゲームはその JSON を
`Yarn.loadOr` で読み、`YarnRunner` が木を直に辿って台詞・選択肢・コマンドを出す。
公式の ysc・.NET は使わない。

## ゲームで直す物

何もしなくても今までどおり動く（会話を JSON の rows で持っているゲームはそのまま）。
雛形 novel-starter は会話を `assets/talk/novel.yarn` へ移した（下の「移し方」の手本）。

## 新しく使える物

### 書ける物・断る物

- 読む: ノード（`title:` 〜 `---` 〜 `===`）・ヘッダ・`話し手: 台詞`・`#タグ`（`#face:happy` / `#suspect`）・
  `->` の選択肢と字下げ・`<<jump ノード名>>`・`<<stop>>`・`<<wait 秒>>`・`//` コメント・`\` のエスケープ。
- 断る（行番号と「代わりに」つき）: 変数（`<<set>>`・`<<declare>>`）・`<<if>>`・`{式}`・関数・`<<detour>>`・
  `<<once>>`・`=>` の行のグループ・`when:`・`[マークアップ]`・`#line:` / `#shadow`・ゲームを待つコマンド。
  分岐はノードを分け、どのノードを開くかはゲームのコードで決める。
- 話し手・タグ（キーと取れる値）・コードが開くノードは**語彙**で止める。正はゲームのコードの enum で、
  `Yarn.vocabJson` で `assets/talk/vocab.json` に書き出す（ゲームの `Talk.vocab`・`make talk-vocab`）。
  知らない名前は近い名前の案つきで止まる（`go/internal/suggest`・flow の check と同じ決まり）。

### 移し方（novel-starter の手順）

1. `src/Talk.flix` を足す: 話し手・タグ・開くノードの enum と `vocabOf(): Yarn.Vocab`・
   `pub def vocab(): Unit \ IO`（`Yarn.writeVocab(パス, vocabOf())`）・`load()`（`Yarn.loadOr`）。
2. `make talk-vocab` で `assets/talk/vocab.json` を書き、会話を `assets/talk/*.yarn` に書いて
   `bin/fge yarn build assets/talk`（`assets/talk/dialogue.json` を書く）。
3. World に `talk = YarnRunner.Runner[時計の名前]` を置き、開く所で `YarnRunner.start(シナリオ, ノード名, 今)`、
   決定で `YarnRunner.step(Action.Advance, 今, talk)`、選択肢で `Action.Choose(i)`、毎フレーム
   `Action.Tick`（`<<wait>>` の明け）。今出している物は `YarnRunner.shownOf` の 1 つ（出来事の列は World に溜めない）。
   選択肢の問いを台詞と同じウィンドウに並べるなら `YarnRunner.choicesFollow` で送る前に選択肢を出す。
4. flow の繋ぎ（0.47.0）は新しい書き方を作らない: 問い `talk`（開いているノード名・閉じていれば空）と
   `talkLine`（今の台詞のファイル:行）・`ready` は文字送りの間 `Busy("typing")`・会話を飛ばす drive `skipTalk`・
   始まり `talk node=<名前>` と `choice node=<名前>`（novel-starter の `src/E2e.flix`・`src/Starts.flix`）。
5. 読み直しは `DocTable.unnamedRow(dialogue.json のパス, …)`（保存即反映。開いているノードを頭から読み直す）。
6. テストの台本は `test/talk/*.yarn` を `bin/fge yarn build test/talk --vocab assets/talk/vocab.json`
   （語彙のパスは書き出した JSON に残り、次の build と check は同じ語彙で組む）。

### ずれの止め方

- コミットの前の門が `bin/fge yarn check`（`.yarn`・`dialogue.json`・`vocab.json` を触った時）を流し、
  書き出した `dialogue.json` が `.yarn` から作り直した物と違えば止める。
- `vocab.json` とコードの enum のずれは、ゲームの橋渡しテスト（`Yarn.vocabJson(Talk.vocabOf())` と
  ファイルの中身が同じ）で止める。`vocab.json` が `src/` より古ければ build がそう言う。
