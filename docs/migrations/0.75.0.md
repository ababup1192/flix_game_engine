# engine 0.74.0 → 0.75.0 の手当て

3D の場面に、Blender でベイクした光（lightmap）を貼れるようにした（`Scene3d.withLightmap`・glb の `TEXCOORD_1` → `Mesh3d.uvs2`）。
場面の絵の予算を project.json で変えられるようにし、大きすぎる絵を読み込みの時に縮める口を足した。
lightmap を付けない絵は 1 bit も変わらない（gl-parity とテンプレートの絵で確かめた）。

## ゲームで直す物

- **`Scene3d.InstanceFields` をレコードの形で開いて match しているゲーム**は `lightmap` の欄を足す（`instanceFieldsOf(i)#mesh` のように欄を読むだけなら止まらない）
- **`GameEngine.EngineConfig` を自分で組んでいるゲーム**（project.json を `ProjectLoader` で読まない物）は `scene3dTextureBudgetMB` の欄を足す（既定は `GameEngine.defaultScene3dTextureBudgetMB()` = 256）
- **自前の描き手で `RenderPaint.create` / `Render3d.fresh` を呼んでいるゲーム**だけ: `create` の cfg に `scene3dTextureBudgetMB`、`Render3d.fresh` に予算の MB を渡す
- **GLSL の字を比べるテスト**だけ: `Render3d.materialFragmentSource` の surface と `materialVertexSource` の kind に `lightmap` が増えた（`lightmap = false` の字は今と同じ）。`Render3d.MeshEntry` に `uv2` が増えた
- **形の鍵を固定値で比べているテスト**だけ: `TEXCOORD_1` を持つ glb の part の `Mesh3d.contentHash` が変わる（2 本目の uv が鍵に入る。絵は変わらない）

## 振る舞いが変わる物（型は同じ）

- `Gltf.loadTextured` は描くのに使う絵（baseColorTexture・normalTexture）だけを読むようになった。metallicRoughness・occlusion・emissive の画像は decode せず、`model#textures` にも入らない（絵は変わらない。読み込みが速くなり、ヒープが減る）
- `TEXCOORD_1` を持つ glb の part に、2 本目の uv（`Mesh3d.uvs2`）が付くようになった

## 足した物（使わなければ何も変わらない）

- lightmap: `Scene3d.Lightmap`（texture・colorSpace・intensity・maxLevels）・`Scene3d.lightmap(name)`・`Scene3d.lightmapMaxLevels()` / `lightmapLevelsForGap(gapPx)`・`Scene3d.withLightmap`・`Scene3d.lightmapOf` / `lightmapOfFields` / `lightmapWarning`・`Mesh3d.withUvs2` / `uvs2`（engine の `docs/lightmap.md`）
- 色空間: `Texture3d.ColorSpace`（`Srgb` / `Linear`）・`Texture3d.srgbToLinear` / `linearToSrgb`
- 絵の大きさ: `Texture3d.limitSize(maxSide, t)`・`Gltf.loadTexturedWith(limits, path)` / `fromGlbTexturedWith`・`Gltf.TextureLimits` / `noTextureLimits()`・`Mip.shrinkTo`
- 予算: project.json の任意キー `scene3dTextureBudgetMB`（3D の場面の絵を GPU に持つ量の上限。既定 256）
- `Scene3d.textureNamesOf(i)`（置いた物が読む絵の名前）

## 段階 G（色の線形化）の時の予告

- `Lightmap.colorSpace` は `Texture3d` の側へ移る（`{ colorSpace = .. | Scene3d.lightmap(n) }` と書いた所だけ止まる）
- ベイクした光の露出は `intensity` から `PostProcess` の exposureStops へ戻す（書き出しの ×2 は intensity に残る）
