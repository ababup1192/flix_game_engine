# engine 0.39.0 → 0.40.0 の手当て

自動生成の一覧は [0.40.0.auto.md](0.40.0.auto.md)。

ドット絵の道具 `bin/fge px` に台本（Starlark の `*.px.star`）と op を足し、音の道具 `bin/fge snd` を新しく入れた。
どちらも Go の道具で、Flix の API は変えていない。

## ゲームで直す物

ありません。何もしなくても今までどおり動く。

- 今ある `*.pxsrc.json` は今までどおり `bin/fge px build` で描ける（engine の testdata の絵はバイトまで同じ）。
- `make sync-agents` で、早見表の 2 行（ドット絵を台本で描く・音を台本で作る）・`bin/lint-rules/snd.json`
  （音の機種の縛りと検査の閾値）・`drawing.md` の周回の書き方が届く。

## 新しく使える物

### ドット絵の台本（`*.px.star`）

- `bin/fge px gen <名前>.px.star` で台本が書く pxsrc と色票をファイルへ書く。`bin/fge px build <名前>.px.star` は書かずに描く。
  繰り返す絵（タイルの描き分け・コマ・場面の部品の並び）は、指定を書き写さずに関数とループで書く。
- 台本の口: `px.write_spec`・`px.palette`・`op.<名前>(…)`（引数の型と範囲をその行で確かめる）・`px.frames`・`px.cycle`・
  `math.*`（正しく丸めた値で、OS・CPU で答えが変わらない）。一覧は engine の `docs/px-ops.md` の「台本」の節。
- 新しい op（昇格ループで足した物）: `courses`（石積み・れんが）・`text`・`canopy`（木の葉の玉）・`frames`・`scroll`・`glow`・
  `flag`・`bar`（ゲージ）など。一覧と引数は `bin/fge px ops`。
- `"style": "snes"` などの機種の縛り（`bin/lint-rules/px.json` の styles か `*.pxstyle.json`）・色の門・`bin/fge px snap`（周回を残す）。
  `bin/fge rounds snap` は WAV も受ける（`rN.wav` と波形の `rN.png`）。

### 音の道具（`bin/fge snd`）

- `bin/fge snd build <x.snd.star か x.sndsrc.json>`: 鳴らして検査し、gate を通れば target の WAV を書く。
  検査の結果は `debug/snd/<名前>/report.json`・波形は `debug/snd/<名前>/sheet.png`。assets/ には書けない（atelier/ に書いて swap）。
- 指定（`*.sndsrc.json`）: 音源の op（pulse・noise・song など）と効果の op（env・lowpass・svf・reverb・delay・normalize・finish など）。
  `"style": "gb"` / `"neo"` で機種の縛り（音源の数・使える厚み）。一覧は `bin/fge snd ops`・engine の `docs/snd-ops.md`。
- 譜面（今の `*.chip.json` と `*.instrument.json` をそのまま読む `song` の op）と、台本で曲を書く口（`mus`・`snd.write_chip`）。
  段のコマンド（DLY・CUT・RTG・VSL）・楽器の表・左右の振り・リバーブ / ディレイ / サイドチェイン。
- 書き出しはステレオが既定（`"channels": "mono"` でモノラル）。ステレオの WAV（smpl のループつきも）は 0.39.0 の
  `SfxSynth.wavBytesStereo` / `wavBytesStereoLooped` と同じバイトの並びで、ゲームはそのまま `assets/` に置いて鳴らせる。
- 検査: 音割れ（true peak）・音量（LUFS）・鳴りっぱなし（drone）・ループの継ぎ目。`bin/fge snd bars`（小節ごとの音量と広がり）・
  `bin/fge snd compare`（2 本の差と聞き比べ用の書き出し）。

## 気をつける所

- 譜面の曲の書き出し: 継ぎ目をまたいで伸びる音は、輪の終わり 40ms を輪の頭へ続く音へクロスフェードで寄せる。
  そのため、継ぎ目で音が伸びる譜面は、ゲームの `ChipDoc` から作った今の WAV と終わりの 40ms だけバイトが違う
  （internet_dungeon の bgmFight は終わりの 822 サンプルだけ違い、ほかは一致）。
- `*.px.star` と `*.snd.star` は Starlark（Python に似た小さな言葉）。台本の書き出し先は作業場の中・assets/ の外だけ（読むのは assets/ の Doc も読める）。

## エンジンの口（エンジンを直す人へ）

- Go: `go/internal/px`（台本は star.go）・`go/internal/snd`・共通に出した `crmath`（正しく丸めた math）・`starbox`（台本の箱）・
  `checklevel`（gate / lint / advice の 3 段）・`go/internal/waveform`（WAV の読み口と波形のシート。0.39.0 の左右の描き分けを持つ。
  `fge waveform`・`rounds snap`・`snd build` が使う）。
- テスト: `go/internal/px`（`TestBytesMatchAssets`・`TestStarGoldenSameOnEveryArch`）・`go/internal/snd`（決まったバイト・ループの小節・
  gate・WAV の往復）・`go/waveform_test.go`。
