# engine 0.35.17 → 0.35.18 の手当て

自動生成の一覧は [0.35.18.auto.md](0.35.18.auto.md)。コードの API は変わらない（doc コメントだけ）。
`make engine-upgrade` で AGENTS.md・スキル・lint の規約・お題（`agent-eval/engine.json`）が配り直される。

## 新しい: AGENTS.md の先頭の早見表（やりたいこと → 道具）

共通部の先頭に「やりたいこと → 使う道具 → 使わない（古い）」の表が入った。ゲーム固有の行は
`AGENTS.local.md` の頭に同じ形で置く（`AGENTS.md` の末尾に足される）。新しい仕組みを入れる人は、
この表に 1 行とお題を 1 本足す。

## 新しい口: `make agent-eval`（任意・claude CLI が要る）

何も教えていない `claude -p` にお題だけを渡し、選んだ道具（API・make の口・lint・スキル）を採点して表にする。
お題はエンジン共通の `agent-eval/engine.json`（配られる・上書きされる）と、ゲーム固有の `agent-eval/<名前>.json`（残る）。

```
make agent-eval                      # 全部（debug/agent-eval/<日時>/ に記録と表）
make agent-eval ONLY=hud-timer LABEL=try
make agent-eval-compare A=before B=after
```

お題の形と採点は `bin/fge agent-eval --help`。claude を何本も走らせるので、重い処理の約束（鍵）があるマシンでは鍵を通す。

## 新しい lint: `bin/fge forbid`（コミット時に .flix と Makefile）

古い書き方を 1 行の正規表現で止め、代わりに使う物を出す。エンジンの規則は `bin/lint-rules/forbid.json`
（`Depth.place` / `Depth.Bands` / `zIndex = 3 桁以上`）。ゲーム固有の規則と除外は
`bin/lint-rules/forbid.local.json` に同じ形で書く（配り直しでも残る）。全量は `bin/fge forbid --all`。

| 止まる形 | 直した形 |
|---|---|
| `Depth.place(range, footY, items)` | `ZStack.zIndex(Depth.orderAt(footY), ZStack.leaf(items))` |
| `zIndex = 900`（大きな数で手前へ） | `ZStack.of` に積む・`ZStack.topLayer(層, …)`・HUD は `App.withHudView` |

## lint z-table: 表の中の大きな数も止まる

表（`ZOrder.flix`・`instance SortingLayer[`）のファイルの中でも、`def zX(): Int32 = 数` の数が葉の中の z
（0..31）の外なら止まる。表に置くのは層の enum と zRange の範囲と、いくつもの View が分け合う葉の中の段だけ。
今ある物は木に積み直すか、`bin/lint-rules/z-table.local.json` の exempt に `"src/ZOrder.flix::zX"` と理由 1 行で残す。
