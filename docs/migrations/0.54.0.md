# engine 0.53.2 → 0.54.0 の手当て

自動生成の一覧は [0.54.0.auto.md](0.54.0.auto.md)（直す物 3 件・手当ては下の「ゲームで直す物」）。
App の欄を直に読まず、`enterHaltMarkers` / `exitHaltMarkers` を呼ばないゲームは、flix.toml の版を上げるだけで通る
（internet_dungeon・hoshizora・kieta_e・雛形はどれも当たらない）。

minor を上げたのは、`App.App` の形が変わり（record の別名 → 1 case の enum）、0.53.2 で出した pub を 2 つ消したため。

## ゲームで直す物

1. **`App.App` が record の別名から 1 case の enum になった**（中身は `App.Rec`・読むのは `App.rec`）:
   - `app#欄` で欄を読んでいたら `App.rec(app)#欄` へ。同じ関数で何度も読むなら、先頭で `let r = App.rec(app);` を 1 回
     （[flix-conventions.md](../flix-conventions.md) の「大きな record は enum で包む」）。
   - `{ 欄 = … | app }` で欄を差し替えていたら、その欄のビルダー（`App.withView`・`App.addSystem` など）へ。
     ビルダーの無い差し替えは `App.App.App({ 欄 = … | App.rec(app) })`。
   - `App.App[w, ef]` の型注釈と、`App.make … |> App.withX …` のビルダーの列はそのまま通る。
2. **`App.RemoteDebug.enterHaltMarkers` / `exitHaltMarkers` を消した**（0.53.2 で pub にした、App の F8 と /halt・/resume が使う口）:
   呼んでいたら `App.applyHaltLook(App.CursorLook.haltEnterLook())` / `App.applyHaltLook(App.CursorLook.haltLeaveLook())` へ。

## 変わった物

1. **ゲームの型検査が軽くなった**: App を enum で包んだので、37 欄の record の型が App を受ける全部の def とゲームのビルダーの列で
   展開されなくなった。internet_dungeon（id-x-worldshape dff9ffc4）の写しで素の flix check の user 時間が
   約 207 秒 → 187 秒（前 208.5 / 205.1 / 209.3・後 185.4 / 189.4 / 186.6。実時間は Mac mini の混み具合で揺れたので比べていない）。
2. **F8 の止めた画面と注釈のスクショで、テクスチャを貼る面の見分けを締めた**: 0.53.2 で「テクスチャ 1 枚を読むだけの面は元の絵を貼る」
   にした見分けに、次の式がすり抜けていた — scaled などの下で bindings の tex を ref で読む・ずらし量が uv で曲がる
   （dx に v が入る斜めの歪み・uv × uv の曲線・min / max / step の折れ線・ripples）。これらは貼らずに代表色で塗る。
   貼るのは、dx が u だけ・dy が v だけの 1 次式（`uv` と `add` `sub`・片側が uv を含まない `mul`）で読む時だけ
   （[shader-doc.md](../shader-doc.md) の「F8 の止めた画面と注釈のスクショでの見え方」）。
3. **止めた画面の出入りの見た目を値で決めるようにした**（見た目は 0.53.2 と同じ）: 入る時はタイトルのバッジを出して十字を見せ、
   抜ける時は形だけ戻す。見せるか隠すかは、動き出した拍に withCursor の宣言を当て直す。決めるのは純粋な `App.CursorLook`、
   当てるのは `App.applyHaltLook`。
4. **video-entries**: 正規表現を規約を読んだ時に 1 回だけ組む（`$(call video-mix-env,…)` を動画の口と取り違えないのは 0.53.2 と同じ）。
5. **checkd の説明**: 保存直後の check が約 11 秒遅い理由（flix 0.78 の repl は書き換えを macOS で 10 秒おきの監視でしか取り込まない）と、
   repl を Flix の内部 API の窓口に替える案を見送った理由を [checkd.md](../checkd.md) に書いた。

## 新しく使える物

| 口 | 中身 |
|---|---|
| `App.Rec` / `App.rec` | App の中身（37 欄）と、それを剥がす口。エンジンの中の口（Flow・RemoteDebug など）が読む。ゲームは読まずにビルダーで組む |
| `App.CursorLook`（`State`・`Visibility`・`Look`・`Badge`・`HaltLook`・`cursorChange`・`haltEnterLook`・`haltLeaveLook`） | 止めた画面の出入りの見た目と、withCursor の宣言を当て直すかを決める純粋なモジュール |
| `App.applyHaltLook` | 止めた画面の出入りの見た目をウィンドウへ当てる |
| `ShaderDoc.fieldsOf` / `ShaderDoc.remappedChild` | Spec の場を並べる・子の場を別の uv で読む節の子を返す（場を足したら remappedChild にも 1 case 足す） |
| `Drawable` の `Eq` / `ToString`・`BoxStyle` の `Eq` / `ToString` | 描画命令をテストで丸ごと比べる |
