# engine 0.92.0 → 0.93.0 の手当て

e2e の flow を撮った動画を、スマホの頁（テープ）で見て注釈を付ける道具 `bin/fge tape` と、ブラウザ版を URL の値から途中で始める口を足した変更に伴う手当て。
直す所は無い（足しただけ）。

## 使い始めるなら

| したいこと | 書く所 |
|---|---|
| ブラウザ版を `?talk=…&line=…` のような URL の値から始める | web の入口で `App.launchWithDevTools(WebLayer.devTools(), app)`。値の読み方は `App.DevTools.browser(pairs)`（`docs/api-digest/engine_world.md`） |
| flow を撮ってテープの頁を作る | `make tape FLOW=e2e/<名前>.flow`（写経元は templates/sound-novel-starter の Makefile・`src/render/TapeOut.flix`・`FlowVideo.writeTape`） |
| テープを GitHub Pages に置いて URL を渡す | `bin/fge tape publish <フォルダ> --repo <owner/name>`（既定は dry run。`--yes` で push） |
