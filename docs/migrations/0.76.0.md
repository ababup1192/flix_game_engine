# engine 0.75.0 → 0.76.0 の手当て（下書き）

一人称で歩いて調べるゲームのための小さな口を足した（`plans/engine-round10-3d-kit.md` の段 1）。
マウスを窓にキャプチャして動いた量を受け取る・GPU の時間を測って画面に出す・スポットライトの内側の角・場面の絵の枚数の上限。
使わないゲームの絵は 1 bit も変わらない（gl-parity の既存の全部の行で GL と CPU の絵がバイト一致・テンプレートの絵が前の版とバイト一致・描き出しの鍵の固定値がそのまま）。

## ゲームで直す物

- **`Scene3d.SpotLight` を字で全部の欄を書いているゲーム**は `innerFovY = None` を足すか、`Scene3d.spotLight(position, target, fovY)` を `{ color = .., intensity = .., range = .. | Scene3d.spotLight(p, t, fov) }` の形に替える（替えると、この先欄が増えても止まらない）。`None` は今と同じ縁
- **`SoftRaster3d.spotInnerRatio()` を呼んでいる所**は `Scene3d.spotInnerRatio()` に（GL と CPU の 2 か所にあった同じ値を 1 つにした。縁の cos は `Scene3d.spotConeOf`）
- **`GameEngine.EngineConfig` を自分で組んでいるゲーム**（project.json を `ProjectLoader` で読まない物）は `scene3dTextureBudgetCount` の欄を足す（既定は `GameEngine.defaultScene3dTextureBudgetCount()` = 64）
- **自前の描き手で `RenderPaint.create` / `Render3d.fresh` を呼んでいるゲーム**だけ: `create` の cfg の `scene3dTextureBudgetMB` を `scene3dTextureBudget = Render3d.textureBudgetOf(config)`（`{ megabytes, count }`）に、`Render3d.fresh` も同じ `Render3d.TextureBudget` を渡す（キーが増えても通り道の欄は 1 つのまま）
- **`GameEngine.Game` の handler を自分で書いているテスト**は 3 つの op を足す: `def consumeMouseDelta(k) = k(Vec2.zero())`・`def setMouseCaptured(_captured, k) = k(())`・`def isWindowFocused(k) = k(true)`
- **`FrameDiagnostics.Diagnostics` を字で組んでいる所**は `gpuNs`・`gpuPasses`・`scene3dCounts` を足すか、`{ submitNs = .. | FrameDiagnostics.empty() }` の形に
- **`App.Frame` / `App.PendingEdges` を字で組んでいる所**は `mouseDelta`（と Frame は `windowFocused`・`diagnostics`）を足す（`App.frameOf` で組んでいれば止まらない）
- **`App.CursorLook.HaltLook` を開いて match している所**は 3 つ目の `Capture` を足す

## 振る舞いが変わる物（絵は同じ）

- `App.withFixedStep` のサブステップ: `frame#mouseDelta` はホイールと同じ量の扱い（2 回目以降のサブステップは 0・0 回のフレームの分は次へ足す）
- `App.frameOf`・flow の `at=`・`PropertyTest` は、前のフレームとの cursor の差を `mouseDelta` に入れる（画面なしでも視点が回る）。実機はキャプチャしても出るバックエンドの量
- `fovY` が 0 のスポット（円錐が無い）は、内と外の cos が同じになる所で内側に 1e-6 を足すので、真ん中の 1 点の照らし方が変わりうる（前は smoothstep の両端が同じで値が決まらなかった。`fovY` が 0 より大きいスポットは変わらない）
- flow の記録は、マウスの動いた量が位置の差から出ない時（キャプチャ中）だけ `look=dx,dy` を書く。flow の手順にも `look=` を書ける（`bin/fge flow check` も読む）
- ヒッチの記録（DEBUG の起動）の診断は、App が 1 コマに 1 回だけ引き取ってゲームの `frame#diagnostics` と分ける（今までどおりの数が出る）

## 足した物（使わなければ何も変わらない）

- マウスのキャプチャ: `App.withMouseCapture(w -> Bool)`・`frame#mouseDelta`・`frame#windowFocused`・`GameEngine.Game.setMouseCaptured` / `consumeMouseDelta` / `isWindowFocused`（engine の `docs/modules/input.md` の「一人称の視点」）
- GPU の時間: `App.withDiagnostics()`・`frame#diagnostics`・`FrameDiagnostics.gpuNs` / `gpuPasses` / `scene3dCounts` / `Scene3dCounts` / `summaryLines`（`docs/performance.md` の §11）
- スポットの内側の角: `Scene3d.SpotLight.innerFovY`・`Scene3d.spotLight(p, t, fovY)`・`Scene3d.spotConeOf`・`Scene3d.spotInnerRatio`（`docs/scene3d.md`）
- 場面の絵の枚数の上限: project.json の任意キー `scene3dTextureBudgetCount`（既定 64）・`GameEngine.defaultScene3dTextureBudgetCount()`
- 3D の口の案内: `docs/scene3d.md`
