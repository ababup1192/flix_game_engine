# engine 0.88.0 → 0.88.1 の手当て

## ゲームで直す物

| 直す所 | 直し方 | 止める物 |
|---|---|---|
| `PolygonRenderCmd` か `Render.Item.Poly` を手で組むコード（テストの中も） | 欄に `triangles = None` を足す | 型検査 |

## 絵とふるまい

絵は変わらない。`triangles` は描く手間だけを減らす欄で、`DrawHash` の鍵にも入れない。

## 足した物

- `Triangulate.indices` / `Triangulate.fromIndices`: 多角形の割り方を頂点の番号の列で持つ。動かす・拡大する・回すだけなら同じ列を使える。
- `RawDraw.polygonWithTriangles`: 読み込みの時に割った列を渡す `polygon`。数百頂点の形を毎フレーム描く時に使う。耳切りは O(n²) なので、血鱗の魔女の場面は 1 コマ 84.6ms → 17.4ms になった。
- `Triangulate.fitsIndices`: 列が頂点の数に合っているかを見る。
- `DrawCmd.polygonTriangles`: 覚えた割り方があれば耳切りを通らない、単色の多角形の三角形の列。
