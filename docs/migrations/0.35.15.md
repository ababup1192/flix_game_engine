## 新しい口: z を「積んだ順」で決める ZStack と、画面全体の層の表 SortingLayer

重なり順（z）を数で選ぶ代わりに、部品の列を奥 → 手前の順に積む木（`ZStack`）と、画面全体の層を名前で
宣言する表（`SortingLayer`）が入った。表は根（画面全体）にだけ置き、層の中は木、部品の中は葉の中の小さな z（0..31）。
考え方と書き方は [docs/z-bands.md](../z-bands.md) の「表は根・中は木」。使わないゲームは何もしなくてよい。

```flix
instance SortingLayer[Layer] { pub def zRange(layer: Layer): (Int32, Int32) = match layer { ... } }
SortingLayer.compose(ctx, (Layer.Scene, sceneTree) :: (Layer.Talk, talkTree) :: Nil)
ZStack.of(ZStack.leaf(cards) :: ZStack.topLayer(Layer.Pointer, ZStack.leaf(tip)) :: Nil)
```

- 区画を越えたら天井で止めて描き続け、`ViewCtx#warnOnce` で層の名前ごとに 1 回だけ知らせる。
  描き出しで止めたいゲームは、ヘッドレスの ViewCtx を `{ warnOnce = 集める口 | ctx }` で差し替え、集まった文面で止める。
- `Depth.orderAt(足元の y)` を `ZStack.zIndex` に渡すと見下ろしの足元の順になる。`Depth.Bands` は非推奨。

## 直す物 1: `App.ViewCtx` に `warnOnce` が増えた

`App.viewCtxOf` / `viewCtxOfFonts` で作っているゲームは何もしなくてよい（既定は毎回 `Log.warn` する口）。
ViewCtx を record で直に作っている所（`{ atlas = …, fontOf = …, visible = … }`）は、型検査で止まるので欄を足す:

```flix
{ atlas = atlas, fontOf = _ -> atlas, visible = App.visibleOf(None, 1.0, design), warnOnce = Log.warn }
```
