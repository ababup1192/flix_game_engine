# engine 0.72.0 → 0.73.0 の手当て

3D の描き物に絵（テクスチャ・法線マップ・mip・glTF の材質ごとの部品）を足した。
Pass を窓の画素で作れるようにし（`RenderTarget.windowDescriptor()`）、1 より明るい値を持つ HDR の Pass
（`RenderTarget.withHdr`）と、トーンマップ・FXAA の部品（`PostProcess`）を足した。
今までの Pass は既定のまま 8bit で、絵は 1 bit も変わらない（gl-parity とテンプレートの絵で確かめた）。

## ゲームで直す物

- **`RenderTarget.Descriptor` をレコードで丸ごと書いているゲーム**は、欄（`basis`・`format`）が足りずに止まる。
  `{ scale = 0.5 | RenderTarget.defaultDescriptor() }` の形に直す。`RenderTarget.sizeOf` は
  `RenderTarget.texelSizeOf(design, pixelScale, d)` になった
- **`RenderTarget.Target` の handler を自前で書いているゲーム**（テストのモックを含む）は、
  `def beginTarget(name, w, h, clear, k)` を `def beginTarget(spec, k)`（`spec: RenderTarget.TargetSpec` =
  `{ name, width, height, format, clear }`）に直し、新しい op `def pixelScale(k)` を足す（描かないモックなら `k(1.0)`）
- **`Render.PassPlanIssue` を網羅 match しているゲーム**は `ScaleOutOfRange(name, scale)` の行を足す。
  範囲の外の scale（0 以下・1 より大きい）は、黙って 1 に直さずに知らせるようになった
- **`ShaderDoc.Field` を網羅 match しているゲーム**は `TexSize(_)`・`VertexColor(_)` の行を足す。
  `ShaderDoc.texNames` には TexSize だけが読む名前も入る。`withoutTextures` / `shadeWithoutTextures` は
  `materialTexReads` / `limitMaterialTexReads` に替わった
- **`Scene3d.Material3d` をレコードで組んでいるゲーム**（`{ spec, params, cutout, emission }`・`m#spec`）は、
  `Scene3d.material(spec) |> Scene3d.withParams(..) |> Scene3d.withCutout(..) |> Scene3d.withEmission(..)` と
  `Scene3d.materialFieldsOf(m)` に直す（材質は外から作らせない型になった）
- `Model3d.Model3d` に `parts`・`textures`、`Scene3d.Scene3dCmd` に `textures` が増えた。`Gltf.load` と
  `Scene3d.scene(..)` で作っていれば止まらない
- **描き出しを自前で組んでいるゲーム**だけ: `HeadlessRender.PassSpec` / `Render.PassSpecRec` の `scale`・`basis` は
  `target`（`RenderTarget.Descriptor`）1 つになり（`sp#target#scale`）、`HeadlessRender.targetOf` は消えた。
  Pass の絵（`extraImages`・`passImagesOf`・`renderPassImage*`・`renderPngWithImages`・`RenderCache.*`）は
  `BufferedImage` から `SoftRaster.PassImage`（`PassImage.Rgba8Unorm(img)` で包む・BufferedImage が要る時は
  `SoftRaster.toArgbImage`）になった。`SoftRaster.renderPassImageScaled` は `SoftRaster.renderPass` に、
  `ShaderEval.compile` の texEnv は `Map[String, ShaderEval.TexImage]` に、`compileMaterial` は `MaterialInput` を
  受ける形に、`evalCompiled3` / `evalMaterial3` の (world, normal) は `SurfacePoint` になった

## 振る舞いが変わる物（型は同じ）

- `ShaderEval.evalPixel` / `evalCompiled` の Rgb の場は 0..1 に切らなくなった（切るのは書く所。8bit の絵は変わらない）
- 3D の材質の `Tex` / `TexBlur` / `Uv` は、これまで 0 だったのが実際に絵を読むようになった。2D の面の Spec を
  3D の材質に流用していると見た目が変わる
- 3D の材質の emission は、HDR の描き先では 1 を超えて残る（負の値は 0）
- 面の GLSL の最後の行が「rgb は 0..65504・α は 0..1 に切る」形になった（GLSL の字を比べるテストに効く）
- sprite のシェーダーは読んだ絵の α を 0..1 に切る
- 絵を使わない `Gltf.load` でも、TEXCOORD_0 / TANGENT が壊れている時はその欄を使わずに読み、1 行知らせる

## 新しく使える物

- 3D の絵: 絵つきの .glb は `Gltf.loadTextured` → 部品は `model#parts`・絵は場面の `{ textures = model#textures | 場面 }`。
  コードの形は `Mesh3d.withBoxUvs` + `Scene3d.texturedMaterial` + `Scene3d.withNormalMap`
- Pass を窓の画素で: `RenderTarget.windowDescriptor()`
- 白飛びを抑える: 場面の Pass を `RenderTarget.withHdr(..)` → 本編の面を `PostProcess.tonemappedWith(..)` →
  8bit の Pass を `PostProcess.fxaaSpec(..)` の面で画面へ。露出の目安は engine の `docs/shader-doc.md` の
  「後処理（PostProcess）」（色をガンマのまま扱う今は、中間を保つなら −0.6 前後）
- Pass の画素の数を面で読む: ShaderDoc の `Field.TexSize`
