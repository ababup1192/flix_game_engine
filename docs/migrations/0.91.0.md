# engine 0.90.0 → 0.91.0 の手当て

ゲームパッドのスティックの値を足した変更に伴う手当て。`App` の関数でゲームを組み、handler を自前で書いていなければ、直す所は無い。

## ゲームで直す物

| 直す所 | 直し方 | 止める物 |
|---|---|---|
| `Platform.Input` の handler を自前で書いているコード（テストで入力を差し替える handler など） | op が 1 つ増えた。`def gamepadSticks(k) = k({ left = Vec2.zero(), right = Vec2.zero() })` を足す | 型検査（handler の op が足りない） |
| `App.Frame` を record で丸ごと組むコード（テストで欄を全部書いた所） | 欄が 2 つ増えた。`leftStick = Vec2.zero()` と `rightStick = Vec2.zero()` を足す | 型検査 |
| `Flow.Opt` を record で丸ごと組むコード | 欄が 2 つ増えた。`lstick = Vec2.zero()` と `rstick = Vec2.zero()` を足す | 型検査 |

## 絵とふるまい

- 絵は変わらない。視錐台の判定（`Frustum.intersectsBox`）は同じ結果を返す。
- スティックを使わないゲームの入力は変わらない（十字キーとボタンの割り当てはそのまま）。

## 足した物

- `frame#leftStick` / `frame#rightStick`: スティックを倒した量（長さ 0〜1・右が +x・上が +y。遊びの範囲は 0）。flow では `lstick=` / `rstick=` で書ける（[docs/modules/input.md](../modules/input.md)）。
- `TextDraw.wrappedSize`・`Flex.wrappedText`・`Flex.wrappedTextShowing`: 折り返した字の大きさを測り、窓の大きさを字から決める（[docs/modules/ui.md](../modules/ui.md)）。
- `Mat4.asRows`: 行列を Float64 の並びで受ける。
