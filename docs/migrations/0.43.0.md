## 新しく使える物

### 状態の持ち方の lint（`bin/fge state-shape`）

画面の操作や演出の状態を、ありえない組み合わせを作れる形で持っていないかを見る。止めるのは 4 つ（どれも gate。code は docs/check-codes.md）:

- `state-shape.bool-fields` — 型エイリアスの record に Bool の欄が 3 個以上（`boolFieldMin`）。今の数は歯止めの表で許し、増えたら止める。
- `state-shape.option-bool` — `Option[Bool]`（3 つの状態を名前の無い型で持つ）。
- `state-shape.catch-all` — ゲームが名指しした状態の enum への match の `case _ =>`（変数で受ける腕も。見張りつきの腕と、
  右辺が `true`・`false`・`None`・`Nil` の述語の形の腕は除く）。
- `state-shape.view-effect` — View のファイル（名前が `View` で始まるか `View.flix` で終わる）の def が決まった効果（IO など）を持つ。

`--json` で checkres の形（code・got・want・fix）。`--all` はリポの .flix を全部見て、もう鳴らない除外と今の数より緩い歯止めも止める。
`make lint-state-shape` はエンジンの Makefile の口なので、ゲームで使うなら Makefile に `lint-state-shape:` と `bin/fge state-shape --all` の 2 行を足す
（`lint:` の並びにも入れる）。

### 許す表の置き方（`bin/lint-rules/state-shape.local.json`）

エンジンの `bin/lint-rules/state-shape.json` に足して読む。書けるのは 3 つだけ:

```json
{
  "note": "この表の中身と理由",
  "stateEnums": ["Overlay", "src/Input.flix::InputLayer"],
  "boolFieldLimits": {
    "src/World.flix::World": 11
  },
  "exempt": {
    "src/Replay.flix::option-bool::Track.won": "None = 決着前。勝ち負けの enum を作る段でまとめる"
  }
}
```

- `stateEnums` — `case _ =>` を止める enum。`"名前"` か `"パス::名前"`。1〜2 個の case だけ見る match が普通の enum（Phase など）は入れない。
- `boolFieldLimits` — `"パス::型": 数`。今の数を書く（増えたら止まる・減らしたら下げる。`--all` は今より大きい数を止める）。
- `exempt` — `"パス::規則::名前": 理由`。規則は `option-bool`・`catch-all`・`view-effect`、名前は record の欄なら `型.欄`・ほかは持ち主の def。
  理由は「いつ・何に替えるか」を書く。

置いたら `bin/fge state-shape --all` が 0 件になることと、わざと崩す（欄を 1 つ足す・`case _ =>` を書く）と止まることを確かめる。
