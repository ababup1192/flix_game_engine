## 新しく使える物

### F8 のチケットを閉じる（`bin/fge tickets close`）

```sh
bin/fge tickets close <id|フォルダ> --fix <直したコミット> --regressed-by <コミット|ticket:<id>|none|unknown>
```

- ledger `reports/tickets/closed.jsonl`（1 行 1 件・git に入る）へ足し、フォルダを `debug/annotations/archive/` へ移して `close.json` を置く。
- `--regressed-by` を省くと、前の直しの候補を出して止まる（下の suspects と同じ物）。AI が推した値は `--by ai --confidence high|medium|low` と `--why "1 行"`。
- 後から regressedBy を付け直すのは `--amend`。フォルダの無い（git の履歴から拾う）チケットは `--created` と `--comment` を渡す。

### 前の直しの候補（`bin/fge tickets suspects`）

`bin/fge tickets suspects <id> --fix <直したコミット>` は、直したコミットが触った関数（無ければファイル）を、
チケットを切る前の 14 日（`windowDays`）に触ったコミットを並べる。ほとんどのコミットが触る関数（場面の一覧など）は外す。

### 直しが次の不具合を生んだ率（`bin/fge tickets stats`）

```sh
bin/fge tickets stats --since 2026-10-01 [--until …] [--by week|day|month] [--json]
```

作った日で期間に分け、件数・regressedBy の埋まった割合・前の直しが生んだ割合・多く生んだ直しを出す（checkres の形・code は
`tickets.filled` / `tickets.regressed` / `tickets.cause`。どれも advice で止めない）。決まりは `bin/lint-rules/tickets.json`。
