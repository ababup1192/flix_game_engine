# engine 0.62.1 → 0.62.2 の手当て

**ゲームで直す物は無い。** API は変わらない。`make sync-agents` で配り直すと、フックの配線と新しい bin/fge-go が入る。

## 変わったこと

- **セッションの始めに索引を裏で作る（hook-index-warm）。** 最初の `bin/fge refactor show`・`search` などが、索引を作るのを待たずに答える。
- **`search` は `///` コメントの言葉でも引く。** 名前を覚えていなくても、doc コメントに書いた言葉から宣言を探せる。
- **`usages` に `--write`・`--read`・`--what` を足した。** 使い方の種類で絞る。`--write` は書きと組み立て、`--read` は読み、
  `--what` は call・ref・read・write・construct・pattern・type・use から選ぶ。
- **`show` に `--head`・`--lines` を足した。** `--head` は doc コメントと頭の行（シグネチャ）だけ、`--lines N` は N 行まで。
- **op ごとに `--help` が出る。** `bin/fge refactor show --help` のように、その op の使い方だけを出す。
