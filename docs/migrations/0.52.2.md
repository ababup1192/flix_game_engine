# engine 0.52.1 → 0.52.2 の手当て

自動生成の一覧は [0.52.2.auto.md](0.52.2.auto.md)（「直す物」4 件は下の 1。ContentCache が engine_tools から engine へ移っただけ）。

入ったのは 3 つ。

1. **会話のプレビューを GPU で塗る**（gpushot）: 窓なしのゲームの 1 枚撮り（Studio の会話の `POST /step?view=shot`・`bin/fge talk shot`）を、
   見えない GL の面（GlOffscreen）で塗る `GpuShot`。窓なしのゲームの初めの World を `ContentCache` で覚え、1 枚ごとに Doc から組み直さない
   （Doc を書き換えた直後の 1 枚には変更が出る）。internet_dungeon で温まった後の 1 往復は GPU 0.037〜0.045 s・`FGE_GPU=off` 0.674〜0.690 s
   （0.50 の SoftRaster は 1.96〜2.0 s）。GPU が使えない時は理由つきの 1 行を出して SoftRaster に戻る。
2. **PNG の書き出しを速く**（pngspeed）: 動画のコマと gallery の PNG を書く前の色集めと詰めを速くした（書いた PNG はビット単位で同じ）。
3. **描き出しのキャッシュの鍵を作るのを軽く**（pngspeed）: 字のアトラスを畳んだバイト列を 1 回の描き出しの間覚え、コマごとに畳み直さない
   （鍵は同じ・internet_dungeon の reference-check 194 枚一致）。

## ゲームで直す物

1. **直さなくてよい**: `ContentCache`（`Cache`・`fresh`・`loadOrBuild`・`loadOrBuildWithDirs`）は engine_tools から engine へ移ったが、名前と型は同じ。
   ゲームは `use fge::{ContentCache}` のまま引ける（internet_dungeon の RenderKit は直さずに通った）。自動の一覧の「消えました」はこの移動。
2. **会話のプレビューを GPU で塗るには**、窓なしの入口（`E2e.serveHeadless` など）で `GpuShot` を使う（internet_dungeon は ababup1192/id-gpushot の
   2 ファイル: `src/E2e.flix`・`src/render/SceneRender.flix`。`GlOffscreen.connect` は入口の頭で呼ぶ — AWT を先に使うと CGL が 10017 で失敗する）。
   使わなければ今までどおり SoftRaster で撮る。

## 新しく使える物

| 口 | 中身 |
|---|---|
| `GpuShot`・`GlOffscreen` | 窓なしで GL の面に 1 枚塗る（環境変数 `FGE_GPU`: 既定の auto は GPU を試し、駄目なら SoftRaster に戻して 1 行知らせる・on は使えなければ止まる・off は SoftRaster） |
| `App.paintOnce`・`App.buildStartOn` | 1 枚だけ塗る・覚えた初めの World の上に始まりを組む |
| `DrawHash.AtlasCache`・`freshAtlasCache`・`computeKeyCached` | 字のアトラスを畳んだバイト列を覚えて鍵を作る |
