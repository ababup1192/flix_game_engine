# engine 0.49.0 → 0.50.0 の手当て（下書き）

使い方と鍵の中身の全文は [docs/render-cache.md](../render-cache.md)。

reference-check・make compare・動画のコマで、前に塗ったのと同じ絵は塗らずに写すようにした。
1 コマの描く命令と、命令に出ない入力（テクスチャと TTF の中身・atlas・シェーダーの Spec・pass の画像・
描き出しの設定・エンジンの fpkg・JVM と OS・PNG の書き方）を SHA-256 に畳んだ鍵（`DrawHash`）で、塗った PNG を
`~/.cache/flix-render-cache/` に取り置く（`RenderCache`）。塗る道（SoftRaster）はそのまま残る。

## ゲームで直す物

1. **直さなくても効く所**: `SoftRaster.render*`・`HeadlessRender.renderPng*` で書く絵（雛形の render-all）。
2. **動画のコマ・自前のギャラリー**で `Filmstrip.renderFrame(SoftRaster.renderToImageCached(req, …), path)` と
   書いている所は、`RenderCache.writeFramePng(session, req, …)` へ置き換える（書き先は `req#outPath`。バイト列は同じ）。

   ```flix
   let session = RenderCache.freshSession();          // コマ列の前に 1 本
   RenderCache.writeFramePng(session, req, surfaces, extraFonts, Map.empty(), warnLog, textures);
   println(RenderCache.statsLine(session))            // [render-cache] 塗った N・写した M・鍵なしで塗った K
   ```

   大きな関数（JVM のメソッドの大きさの上限が近い物）に行を足さず、コマを書く小さな関数の中で置き換える。
3. 使いたくない時・時間を比べる時は `FGE_RENDER_CACHE=off`。塗って取り置きと突き合わせたい時は `FGE_RENDER_CACHE=verify`
   （`make reference-update` はいつもこれで流れる）。
4. `SoftRaster.TextureCache` を match している所は 2 つ目の引数（画素の指紋の表）を足す（`freshTextureCache` で作っていれば直さなくてよい）。

## 新しく使える物

| 口 | 中身 |
|---|---|
| `DrawHash.computeKey(inputs, encoding, frame): Option[DrawHash.Key]` | 1 コマの鍵（純粋）。`DrawHash.toHex` で字に |
| `RenderCache.freshSession()` / `writeFramePng` / `statsLine` | 取り置きを通してコマを書く |
| `RenderCache.keyOf(session, encoding, frame, extraImages, textures)` | writeFramePng と同じ鍵だけを取る（指紋の取り方を写さない） |
| `SoftRaster.cachedTexture(cache, path)` | TextureCache から画像を引く（無ければ塗る時と同じ読み方で読んで入れる） |
| `bin/fge render-cache status` / `prune [--max-mb N]` | 置き場の大きさ・古い順に消す（既定 4096 MB。reference-check と compare の終わりに自動） |
| `make compare` の基準の写し | 基準のコミット・基準側エンジンの fpkg・描く口・lib・java と ffmpeg の版・描き出しが読む環境変数が同じなら、前に描いた基準を使う（`~/.flix_ge_studio/compare-cache/`・`FGE_COMPARE_NO_CACHE=1` で使わない） |
| `bin/fge use-engine <パス>` | 同じ版の字のエンジンへ向けた時、packages.lock のエンジンの行の指紋も向けた先の fpkg にそろえる（`--restore` で戻る。compare の `BASE_ENGINE=<パス>` の基準側も同じ） |
| `bin/headless-run` | **jar を作れない時は止める**（今までは黙って flix run の全量コンパイルに落ちていた）。作った時のエラーの最後 15 行を `build/headless/.failed` に残し、次からの回でも見せる。続けたい時だけ `FGE_HEADLESS_FALLBACK=1` |

## 実測（2026-10-19・Mac mini・internet_dungeon）

壁時計（`bin/fge heavy make …`・jar は温まった状態）。PNG はどの組もハッシュあり・なしでバイト一致。

| 測り | ハッシュなし | 1 回目（塗って取り置く） | 2 回目（写す） |
|---|---:|---:|---:|
| reference-check（194 枚） | 95〜137 秒 | 94〜116 秒 | **10〜17 秒** |
| make transition-video（910 コマ・mp4 の md5 も同じ） | 375 秒 | 366 秒 | **15 秒** |
| make compare BASE=master VIDEOS=transition-video | 857 秒 | 804 秒 | **19 秒**（基準は写し・今は取り置きから） |

- 文言を 1 か所変える（puzzle.json の deckFightLabel）: 9 枚だけ塗り直し・その 9 枚だけ NG（ハッシュなしと同じ顔ぶれ）・28.5 秒
- テクスチャの画像だけ変える（assets/card/icon-attack.png）: その画像を引く 38 枚を塗り直し・37 枚 NG（ハッシュなしと同じ）・47.5 秒
- `FGE_RENDER_CACHE=verify` で 194 枚を塗り直して突き合わせ: 違い 0
- 雛形 novel-starter は直さずに効く（4 枚）
