# engine 0.117.x → 0.118.0 の手当て

（手書きの節。版を上げる時に変わった所を足す。）

## 画面の上の SSAO（PostStack.withAmbientOcclusion）

家具の足元・部屋の隅を暗くする後がけが増えた。使わないゲームの絵は変わらない（`+ao` の変種のシェーダーは技を使う場面だけが組む）。

- `PostStack.withAmbientOcclusion(Some({ radius = 0.5 | PostStack.ambientOcclusion() }), stack)`・post.json の `"ambientOcclusion": { .. }`。
  掛かるのは一番大きい 3D の場面 1 つで、`Resolution.Native` の場面だけ（Design の場面は `Issue.AmbientOcclusionNeedsNative`）。
- **SSAO を使う場面では、霧（withHeightFog）と Physical の奥行きのぼかしの奥行きの絵が 1 枚（`ps_depth_far`・R32Float・near 0）にまとまる。**
  霧とぼかしの見え方は同じ式だが、奥行きの丸めが変わるので、霧かぼかしと SSAO を一緒に使う場面の基準の絵は撮り直す（`make reference-update`）。
  DepthBand の奥行きのぼかしは今までどおり自分の帯の絵を描き、霧だけが `ps_depth_far` を読む。
- `Scene3d.screenInputs` はゲームから呼ばない（PostStack が入れる。lint-forbid の `scene3d-screen-inputs-in-game` が止める）。
  SSAO を自分の Spec（`PostStack.withCustom`）で書かない（`ssao-custom-spec`）。

## ブラウザ版の 3D のシェーダーは書き出しの時に作る（web/shader-variants.json）

3D の入口（`WebLayer.withProject3d`）のゲームのブラウザ版は、シェーダーの字を書き出しの時に作って wasm へ埋める（wasm が約 100 KB 軽くなる）。
作るのはゲームの記録 `web/shader-variants.json` にある分だけ。2D だけのゲームと、ブラウザに出さないゲームは何もしない。

- engine-upgrade の後、ゲームのフォルダで `make run`（`fge run`）を流して 3D の場面を一度通す。`web/shader-variants.json` ができるので git に入れる
  （場面を足した時も同じ。新しい鍵を見た時だけ書き足す）。
- 記録が無いと `bin/fge export-web` は止まる（`--draft` の時だけ既定の一式で書き出し、draft の理由が付く）。
- 記録に無い場面の物はブラウザで描かれず、console に `shader: <鍵> は 描かない（web/shader-variants.json に無い。PC で fge run してその場面を一度通してから書き出し直す）` が 1 回出る。
- 遊ばずに出る場面の漏れは、テンプレートの `test/TestShaderVariants.flix`（`ShaderVariants.missingFrom("web/shader-variants.json", SceneRender.shaderScenes())`）を写すと止まる。
  `FLIX_GE_SHADER_VARIANTS=$PWD/web/shader-variants.json make test` で足りない鍵を書き足す。

## 型に増えた欄と case

- `Scene3d.Scene3dCmd` に欄 `screenInputs`（既定 None）。`Scene3d.scene(..)` から `{ .. | s }` で作っていれば何も要らない。
- `Scene3d.PreloadVariant` に欄 `ambientOcclusion`（鍵の `+ao`）。`Scene3d.preloadVariantOf(scene)` で作っていれば何も要らない。
  字で全部の欄を書いている所は `ambientOcclusion = false` を足す。
- `RenderTarget.Format` に case `R32Float`、`SoftRaster.PassImage` に case `R32Float`、`PostStack.DebugView` に case `AmbientOcclusion`、
  `PostStack.Issue` に case `AmbientOcclusionNeedsNative`。これらを全部の case で match している所は 1 行足す。
- `SoftRaster3dLight.lightAt`・`lightmapLightAt`（生成した CPU の光の関数）の後ろに `ao`・`aoDirect` の 2 つ（SSAO の無い画素は 1.0）。
