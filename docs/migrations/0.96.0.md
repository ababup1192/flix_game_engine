# engine 0.95.0 → 0.96.0 の手当て

ブラウザ版の書き出し（`bin/fge export-web`）の TeaVM を 0.14.1 から 0.16.0 へ上げた変更に伴う手当て。ゲームのコードで直す所は無い。

## 変わった所

| 何が | どう |
|---|---|
| TeaVM | 0.16.0。初回の書き出しで jar の一式（23 本）を Maven Central から取り直す（置き場は利用者のキャッシュの `flix_game_engine/teavm/0.16.0`）。`FLIX_GE_TEAVM_DIR` で手置きの jar を渡していたなら、0.16.0 の物に替える |
| TeaVM の呼び方 | 0.16.0 には CLI の jar が無いので、`fge-web-tools` の中の `fge.teavmfix.BuildWasm` が TeaVM の API を呼ぶ。最適化の強さ（ADVANCED）と難読化なしは今までと同じ |
| 付け替え | `Arrays.copyOfRange` の付け替えを外した（0.16.0 の classlib は直っている）。ほかの付け替えと classlib に無い類の手当ては今のまま |
| 書き出しの最後の段 | ⑨ としてヘッドレスの Chrome で頁を開き、wasm の compile と最初の 3 コマで止まれば exit 1 で止まる（TeaVM は通るのに頁が真っ白になる形を、配る前に見つける）。1 回およそ 1 秒。Chrome が無い機械では知らせて通す。飛ばすなら `--no-browser-check` |
| 絵 | rpg-starter と sound-novel-starter で、`?capture` の絵（題名の画面と、キーを入れた後の場面）が 0.14.1 とバイトまで同じ |
| 読めない時の頁の字 | 「Chrome 119 以降・Safari 18.2 以降」をやめ、「wasm の例外の新しい形（exnref）に対応していないか…最新の版にして開いてください」にした |
| wasm の大きさ | 4〜5% 増える（rpg-starter 7.9 MB → 8.2 MB） |

## engine の作業場

TeaVM の JSO の jar と `fge-web-tools` の組み直しが要る。engine の根で `make sync-engine-full-web` を流してから書き出す
（流さずに書き出すと ③ が「`fge.teavmfix.BuildWasm` が無い」で止まる）。

## ブラウザの下限

TeaVM 0.16.0 の wasm は、例外の命令に新しい形（`try_table`・exnref）を使う（0.14.1 は古い形の `try`）。この形を読めない古いブラウザでは
「wasm を読めません」で止まる。どの版から読めるかは手元で確かめていない（Chrome 137・Firefox 131・Safari 18.4 前後と見ている【推】）。
古い端末で遊ばせたいゲームは、配る前にその端末で開いて確かめる。

## JDK を 25 へ上げた

engine の devbox の JDK を 21 から 25（LTS）へ上げた。ゲームのコードで直す所は無い。

| 何が | どう |
|---|---|
| devbox | engine と 4 つのテンプレートの `devbox.json` が `jdk@25`。新しいゲームは 25 で作られる。今あるゲームは自分の `devbox.json` の `jdk@21` を `jdk@25` に替えて `devbox update jdk@25`（21 のままでも動く） |
| 配布物の JRE | `make dist-*` が同梱する JRE が Temurin 25.0.5+8。1 回目の書き出しで JRE を取り直す |
| java の旗 | `bin/flix`・`bin/headless-run`・配布物の起動が `--enable-native-access=ALL-UNNAMED` を付ける。java が 24 以上の時だけ `--sun-misc-unsafe-memory-access=allow` も付ける（LWJGL が起動時に出す WARNING の 8 行が消える）。headless-run は窓を開く経路だけに付ける |
| Windows の make | `mk/game.mk` の Windows の経路は `--enable-native-access=ALL-UNNAMED` だけを付ける。Studio が同梱する JRE 21 で起動を止めないため。java 25 で流すと Unsafe の WARNING は残る |
| 変わらない物 | Flix が出す class の版（65・Java 21）・GL の層の jar（`--release 17`）。jar は Studio が同梱する JRE 21 でもそのまま動く |
