# engine 0.61.1 → 0.62.0 の手当て

**ゲームで直す物は無い。** API は変わらない。

## 変わったこと

- **`bin/fge refactor` の本体を flixlint の `go/` へ移した。** 宣言を引く側を `flix-search`、書き換える側を `flix-refactor` に分けた。
  呼び方（`bin/fge refactor …`）は変わらない。
- **口を足した: `show`・`search`・`outline`・`trace`・`context`。** 宣言を名前で出す（show）、名前の一部とファイルで引く（search）、
  ファイルの宣言を並べる（outline）、呼ぶ先をたどる（trace）、直す前の調べを 1 回で返す（context）。
- **早見表に 2 行足した。**
- **ファイルを丸読みする案内を `show` と `outline` に向けた。**
