# engine 0.51.0 → 0.52.0 の手当て（下書き）

ノベルの試作で見つかったエンジンの足りない所を直した。

## ゲームで直す物

1. **`SoftRaster.FontEntry` に `textAntialias = Option[Bool]` が増えた**（字の縁のならしを本ごとに決める）。
   `{ ttf = …, atlas = … }` と書いている所は `SoftRaster.fontEntry(ttf, atlas)`（`textAntialias = None` = 絵全体の設定に従う）に置き換える。
   ドット絵の本だけ縁を切るなら `{ ttf = …, atlas = …, textAntialias = Some(false) }`。
2. px の台本で、ランプのある部品の色 `ink`・`shade`・`mid`・`light` が、同じ名前の色キー（legend か色票）とも読める時は止まるようになった
   （今までは黙ってランプの段に読んでいた）。ランプの段なら `ramp[i]`、色キーなら `key:名前` と書く。

3. `make run` / `make debug` は描き出しと同じ jar（`bin/headless-run --window main`）から流すようになった（src を変えていない 2 回目から
   コンパイルしない。internet_dungeon で窓が開くまで flix run 36.4 秒 → 0.49 秒）。入口はファイル直下の `def main(): Unit \ IO =`。
   jar を作れない時は今までどおり flix run で続ける。jar の dispatcher の関数は `FgeHeadlessMain.dispatch` に変わったので、1 回だけ jar を作り直す。

## 新しく使える物

| 口 | 中身 |
|---|---|
| `Fx.particles` / `particlesAt` / `particlesOfAll` / `touches` | 粒の番号と中心（絵と同じ式）・円と粒の重なり |
| `HeadlessRender.renderPngFull(cfg, scene, name)` / `renderGifFull` | pass・ShaderDoc の面・追加フォントを 1 枚に一緒に渡す（`HeadlessRender.Scene`） |
| `UiFocus.layoutRectsWith` / `hitTestUiWith`・`UiFocusNav.targetsOfUiWith` | 字を測った枠で当てる（描いた所と同じ枠。字だけの要素にも枠）。atlasOf は描く時と同じ物 |
| `SoftRaster.fontEntry(ttf, atlas)` | 絵全体の字の縁の設定に従う追加フォント |
| ui.json の `paletteFile` | 注記の鍵（`$schema`・`note`・`//…`）を読み飛ばし、`PaletteExport.build` の `{version, note, colors}` も読む |
| px の色 `key:名前` | 色キーを直に指す |
| `bin/headless-run --window <入口>` | 窓ありで同じ jar から流す（Darwin は -XstartOnFirstThread・headless にしない・環境変数はそのまま）。`main` は遊ぶ入口 |

| 常駐の終了コード 124 | 入口が GL を開こうとした（`x needs-gl`）。headless-run は GL の旗で流し直す（今までは headless の旗のまま流し直していた） |

| `Render.surfaceZShared(items)` | ShaderDoc の面の後ろに同じ z の描き物を並べた z（面は同じ z の中で必ず手前に描かれる。App は z ごとに 1 度知らせる） |
