# engine 0.51.0 → 0.52.0 の手当て

自動生成の一覧は [0.52.0.auto.md](0.52.0.auto.md)。

ノベルの試作で見つかったエンジンの足りない所を直した（engine-gaps）。入ったのは 11 個。

1. **粒の番号と中心**（`Fx.particles` ほか）: 絵と同じ式で粒の位置を取り、当たり判定に使える。
2. **配った版から `make new-game`**: Release の zip・Studio の同梱からそのまま通る（今までは fpkg の名前違いと go/ が無いことで止まった）。
3. **字の縁を本ごとに**（`HeadlessRender.Scene#fontAntialias`）・**字の縁を切った字は 2 色**（今までは切っても縁に中間色が出た）。
4. **UI のクリックを描いた所で当てる**（`UiFocus.hitTestUiWith` ほか）。今の `hitTestUi` は字の兄弟があるとずれる。
5. **ShaderDoc の面と同じ z のドット絵**: 面は同じ z の中で必ず手前（決まりは変えない）。後ろに並べると App が知らせる。
6. **px の色 `light` などが色票の同じ名前の色に化けない**（どちらとも読める時は止める・`key:名前` を足す）。
7. **ui.json の `paletteFile` が注記の鍵と色票の書き出しの形を読む**。
8. **描き出しに面と追加フォントを一緒に渡す**（`HeadlessRender.renderPngFull`）。
9. **遊ぶ起動も描き出しと同じ jar から**: `make run` で窓が開くまで flix run 36.4 秒 → 0.49 秒（internet_dungeon・変更の無い時）。
   Studio 向けに `headless-run --window` / `--build-only` / `--status`。
10. **jar の指紋に java と旗を混ぜない**: Studio のプレビューと端末の make render を交互に使っても jar を作り直さない（0.51.0 の不具合）。
11. **常駐が `x needs-gl` と答えた入口は GL の旗で流し直す**（Darwin は -XstartOnFirstThread）。

## ゲームで直す物

1. px の台本で、ランプのある部品の色 `ink`・`shade`・`mid`・`light` が、同じ名前の色キー（legend か色票）とも読める時は止まるようになった
   （今までは黙ってランプの段に読んでいた）。ランプの段なら `ramp[i]`、色キーなら `key:名前` と書く。

2. `make run` / `make debug` は描き出しと同じ jar（`bin/headless-run --window main`）から流すようになった（src を変えていない 2 回目から
   コンパイルしない。internet_dungeon で窓が開くまで flix run 36.4 秒 → 0.49 秒）。入口はファイル直下の `def main(): Unit \ IO =`。
   jar を作れない時は今までどおり flix run で続ける。jar の dispatcher の関数は `FgeHeadlessMain.dispatch` に変わったので、1 回だけ jar を作り直す。

3. `DrawHash.Frame` に `fontAntialias` の欄が増えた（自動の一覧の 1 件）。`RenderCache.keyOf` へ渡すために Frame を字面で組んでいる所だけ、
   `fontAntialias = Map.empty()` を足す（空の表なら鍵も絵も前と同じ）。`RenderCache.writeFramePng` などの関数を呼んでいるだけなら直さなくてよい
   （internet_dungeon は直す所が無い）。pxsrc.schema.json の変わり目は色の `key:名前` の説明だけ。

4. 直さなくてよい物: 今のゲームのコードはそのままコンパイルできる（`SoftRaster.FontEntry` は `{ ttf, atlas }` のまま。新しい口は足しただけ）。
   jar の指紋が変わるので、上げた後の最初の描き出しで 1 回だけ jar を作り直す。0.51.0 のうちに起きた常駐は 1 度だけ起こし直しになる
   （常駐を起こした java を `HEADLESS_JAVA` で見分けるようになったため）。

| 口 | 中身 |

| `Fx.particles` / `particlesAt` / `particlesOfAll` / `touches` | 粒の番号と中心（絵と同じ式）・円と粒の重なり |
| `HeadlessRender.renderPngFull(cfg, scene, name)` / `renderGifFull` | pass・ShaderDoc の面・追加フォントを 1 枚に一緒に渡す（`HeadlessRender.Scene`）。字の縁は本ごとの表 `Scene#fontAntialias`（テクスチャ名 → ならすか。表に無い本は `cfg#textAntialias`） |
| `UiFocus.layoutRectsWith` / `hitTestUiWith`・`UiFocusNav.targetsOfUiWith` | 字を測った枠で当てる（描いた所と同じ枠。字だけの要素にも枠）。atlasOf は描く時と同じ物。今の `hitTestUi` などは字の兄弟があるとずれる |
| 字の縁を切った字（`textAntialias = false`・本ごとの表で false） | 背景と字の色だけで描く（今までは切っても縁に中間色が出ていた。ならす字の絵は前と同じ） |

| `Render.surfaceZShared(items)` | ShaderDoc の面の後ろに同じ z の描き物を並べた z（面は同じ z の中で必ず手前に描かれる。App は z ごとに 1 度知らせる） |
