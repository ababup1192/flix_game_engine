# engine 0.37.1 → 0.38.0 の手当て

自動生成の一覧は [0.38.0.auto.md](0.38.0.auto.md)。

描く層と押せる当たりを 1 つの木で持つようにした。当たりの列を描く木と別に書くと、描く順を変えたときに
押せる順だけ古いまま残り、「確認の窓の奥が押せた」「確認のクリックを奥の物が横取りした」が作りとして起きる。
0.38.0 では当たりを木の葉の隣に積み、`SortingLayer.compose` と同じ道筋（層の底の順・積んだ順・zIndex・
topLayer の送り先・mapItems の変換）で手前から選ぶ。当たりの列（`SortingLayer.Hits`）は木からしか作れない。

ゲーム側で直さなくても今までどおり動く（`ZStack.Node[p]` は `Tree[p, Unit]` の別名として 0.38 の間だけ残す。
古い `SortingLayer.pick`（手書きの列）も 0.38 の間は残す。どちらも 0.39 で消す）。

## ゲームで直す物

| 前 | 後 |
|---|---|
| `ZStack.Node[Layer]` | `ZStack.Tree[Layer, 押せる物の enum]`（押せる物を持たない木は `ZStack.Tree[Layer, h]` と型変数のまま。`Node` は 1 版だけ別名） |
| `ZStack.Node.Leaf` など `Node` の case を書く・match で見る | `ZStack.Tree.Leaf` と書く（別名からは case に届かない）。match は増えた `Hit` / `Block` も受ける |
| 場面ごとの (名前, 矩形) の列を `SortingLayer.pick` へ | ボタンの葉の隣に `ZStack.hit(名前, 矩形)`・確認の窓は `ZStack.modal(層, 外を押した名前の Option, 木)` か `ZStack.blocking(外を押した名前の Option, 木)`・どこでも決定は `ZStack.hitAnywhere`・入力は `SortingLayer.pickFrom(点, View の層)` |
| HUD と場面の当たりを別々に引いて順を手で決める | `SortingLayer.over(hitsOf(HUD の層), hitsOf(場面の層))` → `SortingLayer.pickIn(点, hits)` |
| 入力の側で View を組む ctx が無い | `App.pickCtx(design)`（字を測らない ctx。当たりの矩形は字の幅から作らない） |
| テストで当たりの矩形を引く | `SortingLayer.toList(hits)` の `target`・`rect` |

手本は `templates/game-starter`（終了の確認の窓を `blocking` + `hit` でマウスで押せる。窓の中 = はい・外 = いいえ）。

## 気をつける所

- 入力の側（`Controls.tapAt` など）で当たりを引くと、そのたびに木を組む。押した瞬間だけなら軽い。
- 毎フレーム「指している物の光」を描くために、場面の側（`view`）で HUD の木の当たりまで引くと、HUD の木を
  1 コマに 2 回組む。internet_dungeon で測った値（描き出しの 18 場面・View.frame + View.hud の 1 コマ）は
  ほとんどの場面で +0.13ms 以下、HUD に場面の縮小（View.frame の入れ子）を持つ場面だけ +1.4ms（2.4 → 3.8ms）。
  入れ子に重い物を持つ HUD では、光を HUD の側で描くか、当たりを引く木を軽くする。

## 新しく使える物

- `ZStack.hit` / `hitAnywhere` / `blocking` / `modal`・`SortingLayer.hitsOf` / `pickFrom` / `pickIn` / `hitAt` / `over` / `toList`・`App.pickCtx`。
- 早見表の「押す物を見た目の手前から選ぶ」の行が新しい口へ（`make sync-agents` で配る）。agent-eval のお題 `click-front-layer` を直し、`hit-from-tree` を 1 本足した。

## エンジンの口（エンジンを直す人へ）

- `compose` と `hitsOf` は同じ道筋（`laidOut`）を通る。並べ方を変えるときは両方が一緒に変わる。
- テスト `engine_world/test/TestZStack.flix` に 7 本（窓の奥が押せない・同じ層の手前と zIndex・奥から開いた確認を間の層が横取りしない・塞ぐだけ・どこでも・mapItems で動く・over）。
