# engine 0.87.0 → 0.88.0 の手当て

## ゲームで直す物

| 直す所 | 直し方 | 止める物 |
|---|---|---|
| `handler Platform.Draw3d` を手で書いているテスト | `def preload3d(_cmd, k) = k(())` を足す。`Platform.runNoopDraw3d` を使う所は直さなくてよい | 型検査 |
| `Scene3dRenderer.Renderer` を手で組む描き手 | `Scene3dRenderer.none()` を土台にするか、`preload = (_, _, _) -> checked_ecast(())` を足す | 型検査 |
| 初めて出る物を視錐台の外へ毎コマ置いているゲーム | 直さなくても動く。その物を `App.withPreload3d` の `instances` へ、読む `tex3d:` の絵を `textures` へ移すと消せる。描く時は今まで通り場面の `textures` にも載せる | 無し |
| 3D の同じ平面に物を重ねているゲーム | 少しずらす。同じ形と材質の物をまとめて描くので、同じ深さの面の勝ち方が変わる場合がある | 絵 |

## 絵とふるまい

- 同じ形と材質の 3D の物は 1 本の draw でまとめて描く（インスタンス描き）。ゲームの変更は要らない。同じ深さの面の順は約束しなくなった（`docs/backend-parity.md`）。ほかの絵は変わらない。
- 骨の行列は joint texture へ移した。骨つきの物の数の上限が UBO の大きさで決まらなくなった。
- デスクトップで `FGE_INSTANCING=off` を付けると、全部の物を 1 体ずつ来た順に描く（絵の比べ用）。
- ブラウザ: 64 KiB の倍数の大きさの確保で起動の途中に頁が止まる不具合を直した。3D の絵を読み戻すゲームで起きていた。書き出し直すと直る。
- `web-capture` は頁が止まった時に待ち切らず、すぐ失敗を返す。

## 足した物

- `App.withPreload3d({ key, instances, textures }, app)`: 遊びの途中で初めて出る 3D の物を先に GPU へ上げる。骨つきの物は姿勢を外さず渡すと、骨つきの版も組める。
- `bench/crowd2d`（`make crowd2d-cpu`・`make crowd2d-bench`）: 2D の敵の群れで `SpatialGrid` と `FlowField` の得を測る。
