# engine 0.46.0 → 0.47.0 の手当て

自動生成の一覧は [0.47.0.auto.md](0.47.0.auto.md)。設計のメモは [flow.md](../flow.md)。

e2e の手順 flow（`e2e/<名前>.flow`・1 行 1 手）を足した。中身は実機と同じ 1 フレーム（`App.traceFrame`）で、
画面なしで流し（`make flow FLOW=…`・Flix を組み直さない）、書き間違いは JVM なしで止まる（`bin/fge flow check`）。
あわせて、好きな場面から起動する始まりの登録簿（`App.withStarts`）、DEBUG の起動の遊んだ記録（`debug/flow-record/latest.flow`）、
系の外へ出す出力の入口（`App.addOutput`・`App.withDocTable`・`App.withCursor`）を足した。

## ゲームで直す物（直さないと組めない・動きが変わる）

1. **`ActiveDocs.step` が無くなった。** update から外し、Doc の一覧表から配線する。World の `activeDocsWritten` の欄も消す。
   ```flix
   App.game({ init = …, update = (f, w) -> checked_ecast(Controls.step(f, w)), view = …,
              reloads = Nil })                       // 監視・F1・名乗りは下の 1 行が配線する
       |> App.withDocTable(Controls.docTable())      // App.reloadOn(Key.F1, Controls.reloadAll) も消す
   ```
2. **系の中でファイルに書かない。** セーブは `App.addOutput({ keyOf, write, onJump = App.OnJump.Skip })` に移す
   （書くのは実機のフレームが鍵を変えた後だけ。`/step`・flow・F8 で止めている間・`START`/`/start` で跳んだ先は書かない）。
   OS のマウスの矢印は `App.withCursor(w -> { icon = …, visible = … })`（F8 の間は App が十字に上書きする）。
3. **`App.Frame` を record の字面で組んでいる所**は欄 `padTouched = false` を足す（`App.frameOf` を使う所は直さなくてよい）。
   パッドに触ったかは `frame#padTouched`（ゲームが GLFW を直に読む `Gamepad.isTouched` の類は要らなくなる）。
4. **`Replay`（engine_world）と `ReplayScript`（engine_tools）が無くなった。** 決まった手順は flow、でたらめな手順は `PropertyTest`、
   フレームの列を流すだけなら `App.trace`。
5. **リモートの `POST /step` の本文は flow の文法**になった: `idle N` → `wait Nf`・`press K` → `tap K`・`hold K N` → `hold K Nf`
   （`hold K 30` は 30 秒）。古い書き方は書き換え先を言って断る。`/step` は固定刻み（`withFixedStep`）と時計も実機と同じに進める。
6. **`GameEngine.Game` を自前のハンドラで包んでいるゲーム**（テストのモックなど）は、op `isGamepadTouched` を足す（`def isGamepadTouched(k) = k(false)`）。
   `App.App` を record の字面で組んでいる所は、新しい欄（`cursor`・`outputs`・`starts`・`flow`・`fingerprint`）が要る —— `App.make` / `App.makeWith` から足していけば直さなくてよい。
   `App.RemoteDebug` の `parseScript`・`Script`・`keyOf`・`keyNames` は消えた（台本の読みは `Flow.Parse`・キーの名前は `InputMap.keyOf`）。
7. `launch` の効果に `Fs.FileWrite` が入った（`main` は既定のハンドラで足りる。`with Fs.FileWrite.runWithIO` があればそのまま）。
8. `App.withStarts` を繋いだゲームは、起動も登録簿を通る（`START` が無ければ先頭の始まり）。

## ゲームが書く物（flow を使う時）

App の組み立てを 1 つの関数にしておく（実機の `main`・flow の入口・テストが同じ App を使う。雛形は `src/Game.flix`）。

| 書く物 | 入口 | 中身 |
|---|---|---|
| 始まり | `App.withStarts(List[App.Start[w]])` | `{ name, doc, args（既定の引数）, build = (新しく作った初期の World, 引数) -> Result[String, w] }`。build は純粋。セーブを読む始まりは引数を `save=@saves/slot1.json` にすると App が中身を渡す |
| 役 | `App.withFlow({ roles = w -> InputMap.Table[String] … })` | 役の名前 → キー（表の先頭のキーを押す）。ゲームの役の enum の表は `Flow.rolesOf(名前, 表)` |
| 問い（probe） | `probes = List[{ name, doc, read }]` | `Flow.Probe.Num(w -> 数)`・`Text(w -> 文字)`・`Flag(w -> 真偽)`。`until`・`expect` で使う |
| 入力を受けられるか（readyOf） | `ready = Some(w -> Flow.Ready)` | `Ready` か `Busy(理由)`。宣言すると tap・hold の前に自動で待つ（10 秒まで）。今の World で問う |
| 返事 | `replies = Some(w -> Int64)` | 返事の通し番号。押した後に進まなければ、押した行の番号つきで失敗。規則の出来事を `Emit` で溜めているなら `Emit.countOf(w#events)` |
| 名前付きの操作（drive） | `drives = List[{ name, doc, act = (待った秒, w) -> Flow.DriveAct }]` | `Tap(役)`・`Idle`（待ち続ける）・`Restart`（待った秒を 0 に）。会話を読み終えて送る、のような手 |
| 指紋 | `App.withFingerprint(w -> 文字)` | 記録の再生が 60 フレームごとに比べる欄（場面・時計・盤・カーソル・種）。Doc の中身や絵は入れない |

```flix
// src/E2e.flix（雛形 tetris-starter・novel-starter に全文）
mod E2e {
    use fge::Flow
    pub def play(): Unit \ IO =
        run { Flow.Cli.main(Game.app(Controls.loadDocs())) } with Fs.FileRead.runWithIO with Fs.FileWrite.runWithIO
    pub def vocab(): Unit \ IO =
        run { Flow.Cli.writeVocabOf(Game.app(Controls.loadDocs())) } with Fs.FileRead.runWithIO with Fs.FileWrite.runWithIO
    pub def table(): Flow.Table[World.World] = { roles = …, probes = …, ready = Some(…) | Flow.emptyTable() }
}
```

- 流す: `make flow FLOW=e2e/<名前>.flow`（`bin/fge flow run` も同じ）。読むだけ: `bin/fge flow check`（引数なしで `e2e/*.flow` 全部）。
- 語彙 `e2e/vocab.json` は jar を作り直した回（`bin/headless-run` が `.vocab` で終わる入口を流す）と `make flow` のたびに書き直す。
- 好きな場面から起動: `START="stack gap=0" make debug`。走っているゲームへは `GET /starts`・`POST /start?name=…`。
  flow を組み直さずに流す: `POST /flow`（本文か `?path=`・`apply=1` で結果の World へ差し替え）。
- テストの場面: `App.startOrBug(Game.app(…), "名前", 引数)`（新しく作った初期の World から組む）。
- 遊んだ記録: DEBUG の起動で `debug/flow-record/latest.flow`（前の回は `previous.flow`・`FLOW_RECORD=0` で止める）。
  再生は `make flow FLOW=debug/flow-record/latest.flow`。最初に食い違った指紋の行で止まる。F8 のチケットには `record.flow` の写し。
- 記録と再生の決定性は、系が純粋なことに頼る（乱数は World の種・時刻は frame#dt と時計から）。
