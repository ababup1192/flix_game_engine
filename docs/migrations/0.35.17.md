## 直す物: 表の外の `SortingLayer.z` と `ZStack.leafAbsolute` がコミットで止まる（lint z-table）

場面を ZStack の木にするまでの間だけ使った 2 つの口（移行の口）を、表（`instance SortingLayer[`・`ZOrder.flix`）を
持つパッケージでは、表の外で呼ぶと止めるようにした。今までは `--all` で残りの数を出すだけで、コミット時も
新しく足した `SortingLayer.z` の行しか止めなかった。表を持たないパッケージ（表を作る前のゲーム・エンジン）は見ない。

| 今の形 | 直した形 |

| `ZStack.leafAbsolute(絵)`（絶対値の z の葉） | `ZStack.leaf(絵)`。中の z は葉の中の小さな前後（0..31）に直す |
| `def zX(): Int32 = SortingLayer.z(層, 段)` | 層へは木ごと `SortingLayer.compose` / `ZStack.topLayer` で送り、葉の中は `def zX(): Int32 = 段` |

描き上がった 1 フレームを丸ごと加工する演出のように、木に戻せない所だけ `bin/lint-rules/z-table.local.json` の
exempt に `"パス::SortingLayer.z"` か `"パス::leafAbsolute"` と理由 1 行で残す。
