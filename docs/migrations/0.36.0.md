# engine 0.35.39 → 0.36.0 の手当て

自動生成の一覧は [0.36.0.auto.md](0.36.0.auto.md)。

この版は、ドット絵の道具 `bin/fge px` の第 2・3 段を入れた。形の指定（`*.pxsrc.json`）に名前のある op を並べて
`bin/fge px build` で sprite.json と見本のシートを描き、同じ口で検査（座標と直し方つき）と色の門を通す。
ゲーム側で直さなくても今までどおり動く（Flix の API は変わっていない）。

## ゲームで直す物（px を使う・使い始めるなら）

| 前 | 後 |
|---|---|
| ゲームの Python の台本（`gen-*.py`・部品集）で sprite.json を描く | 形の指定 `art/<名前>.pxsrc.json` を `bin/fge px build` で描く。op の一覧は `bin/fge px ops`（`docs/px-ops.md`）・1 つの説明は `bin/fge px help <op>`・書式は `docs/pxsrc.schema.json` |
| 色の門をゲームの台本で見る | `bin/fge px check [--gate <名前>.colorgate.json] <sprite.json…>`（build の spec の `gate` でも通る） |
| 色の門の `files` に無い sprite.json は止まる（新しい絵のたびに `files` へ足す） | 門に `"default": "<画風の名前>"` を書くと、`files` に無い物はその画風で見る（省けば今までどおり止まる） |
| 描く周回をゲームの台本で残す | `bin/fge px snap <spec>`（見本を描いて `bin/fge rounds snap` に積む）・`px diff <spec> rA rB`・保存のたびに描く `px watch`。戻すのは `bin/fge rounds restore <名前> rN <spec>`、周の上限は rounds.json の 1 か所 |
| 絵の rules が `*.spritesrc.json` で読まれる | `*.pxsrc.json` で読まれる（`make sync-agents` で配る `.claude/rules/drawing.md` と gen-rules の対象） |

`spritesrc` という名前を使っていたゲームは `pxsrc` に名前を変える（中身の形は `docs/pxsrc.schema.json`）。

## 新しく使える物

- op: 光と陰（`directional`・`shade_parts`・`shade_mask`・`gradient_fill`）・線（`line`・`ring`・`curve`・`aa_corners`）・
  材質のレシピ `material`（metal・stone・wood・cloth・foliage）・ディザ `dither_pair`・質感 `scatter_clusters`（`wrap` でタイル）・
  奥行き `depth_fade` → `contrast`・アイコン（`emblem`・`glyph_rows`・`bevel` など）・動き（`sway`・`bob`・`squash`・`wave_shift`・`palette_cycle`）。
  早見表（描く物 → op → 仕上げ）は `docs/px-ops.md` の先頭。見比べで差が出なかった op（`rim_light`・`sel_out` など）は早見表に載せず、既定にしない。
- 部品の親子（`on`）: 揺れ・呼吸の op は子の部品も付いていく。部品の `rotate`・`pivot`、コマの `pose`（contact・down・passing・up）。
- 形は `shapes` の名前でも書ける（`{"ref": 名前}`）。
- 検査: pillow・light-dir・black-outline・value-sep・ramp-order・seam・style・flicker・margin・anim。違反には座標と直し方（fix）が付く。
  閾値は `bin/lint-rules/px.json`（どれも仮置き）。
- 機種の決まり: spec の `"style"` に gb4・nes・snes・pc98・modern（色の集合・1 コマの色数・升目ごとの色数・解像度）。
  これは門の画風への上乗せで、門の画風は外れない。
- `bin/fge px build` の `--sheet`（見本のシートだけ）と `--time`（op ごとの時間）。
- 早見表の「ドット絵（sprite.json）を描く・直す」の行に `bin/fge px build` が載った（`make sync-agents` で配る）。
  agent-eval のお題 `px-icon-gate` を足した。

## テンプレート（新しいゲーム）

`templates/game-starter/art/game.colorgate.json` を最初から持つ（色票 `assets/__NAME__.palette.json` の画風を `default` に・`#000000` を止める）。

## エンジンの口（エンジンを直す人へ）

- `make go-test-amd64`: arm64 の Mac で px・pxlib・anim を x86-64 として流す（Rosetta）。arm64 は `a*b+c` を FMA にまとめることがあり、
  包み忘れると境目の画素だけ Mac と Windows でずれる。px の積は `float64(…)` か dot で包む。
- ゲームの台本だった puzzle の 77 コマと relic の 3 コマを `go/internal/px/testdata` の指定で描き、assets とバイトで一致することを go test で守る。
- carve と px の重なっていた部品（点・色・PNG の読み書き・RenderDoc）は `pxlib` へ寄せた。読み込みの動詞は `Load*`。
