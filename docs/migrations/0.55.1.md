# engine 0.55.0 → 0.55.1 の手当て

自動生成の一覧は [0.55.1.auto.md](0.55.1.auto.md)（直す物 0 件）。Flix の pub は変わらない。
入ったのは不具合の直し 1 つ（internet_dungeon で 0.55.0 の版のノートどおりに追随して `make lint-flixlint` が落ちた）。

## 追随の手順

1. **flix.toml の engine の版を 0.55.1 にし、`make sync-agents`**（`bin/lint-rules/doc-refs.json` の上限の置き場が変わる）。
2. **doc-refs の上限 2 ファイルを新しい置き場へ移す**（中身はそのまま）:

   ```sh
   mkdir -p lint/doc-refs
   git mv lint/limits/doc-refs-flix.json lint/doc-refs/flix.json
   git mv lint/limits/doc-refs-callers.json lint/doc-refs/callers.json
   ```

   古い置き場に残っていると `make lint-doc-refs` が `git mv` の 1 行を出して止まる（両方は読まない）。
   0.55.0 を飛ばして 0.54.x から来るゲームは、[0.55.0.md](0.55.0.md) の手順 2 の上限を初めから新しい置き場に置く。

## 変わった物

1. **doc-refs の上限の置き場を `lint/limits/` から `lint/doc-refs/` へ移した**（`flix.json`・`callers.json`）:
   `lint/limits/` は flixlint の上限のフォルダ（ファイル名＝規則の id）で、flixlint 0.8.4 は知らない id の上限を
   「no rule has this id」で止める。置き場は `bin/lint-rules/doc-refs.json` の `flixLimitFile`・`callersLimitFile`、
   古い置き場は `movedLimitFiles`。engine 自身の上限も移した。

## 新しく使える物

無い。
