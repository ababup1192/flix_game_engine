# engine 0.71.0 → 0.72.0 の手当て

3D の描き物 `Render.Item.Scene3d` を足した（部屋・家具・骨で動くキャラを、2D の z の並びの中に描き物 1 つで置く）。
材質は ShaderDoc の `World` / `Normal` 場、影はスポット 1 本の shadow map、骨は Blender の .glb を `Gltf.load` で読む。
手本は `bench/scene3d`。あわせて Pass を連鎖でき、縮めた Pass を補間して読めるようにした。

## ゲームで直す物

- **`Render.Item` を網羅 match しているゲーム**は、`case Render.Item.Scene3d(_)` の行を足す（足さないと
  Non-exhaustive match で止まる）。z を持ち上げるだけの所なら、他の case と同じく z を足して返せばよい
  （`templates/sound-novel-starter/src/View.flix` の `liftedZ` が手本）
- **`ShaderEffect.Shader` の handler を自前で書いているゲーム**（テストのモックを含む）は、`drawScene3d` の op を
  足す。描かないモックなら何もしない `()` でよい
- `ShaderRenderCmd` の `texNames` → `texReads`、`params` の追加と、`HeadlessRender.PassSpec` / `Scene` /
  `SoftRaster.RasterReq` の欄の追加は、自前で組んでいる所だけ直す（直し方は `0.72.0.auto.md` の追随例）。
  1 本の Pass を組んでいた `Render.passSpecOf` は、連鎖を読む `Render.passSpecsOf(texInfo, plan)#specs` に替える

## 新しく使える物

- 3D の部屋: `Render.scene3d(at, Scene3d.scene(camera, size))`（`Mesh3d.fromObj` → `Scene3d.meshInstance`）
- 骨のアニメーション: `Gltf.load` → `AnimationClip3d.sample` → `Pose3d.compute` → `Scene3d.withPose`
- Pass を使う画面の GPU 動画: `VideoOut.writeFramesWithPasses`
