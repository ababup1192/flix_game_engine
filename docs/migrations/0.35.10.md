## 1. `bin/fge quadratic` がコミットを止める（足した行だけ）

`List.foldLeft` / `foldRight` に渡したラムダの中で、次の形を新しく書くと止まる:

- 蓄積（タプルで分解した別名・その欄も含む）を `List.append` の第 1 引数に置く
- 蓄積の文字列に 1 回ごとに足す（`"${acc}…"` / `String.concat(acc, …)` / 初期値が `""` の蓄積に `acc + …`）、
  または `String.concat` を fold に渡す

どれも 1 回ごとに蓄積を丸ごと作り直すので、要素数（文字数）の二乗になる。直し方:

```flix
// リスト: :: で先頭へ積んで、最後に 1 回だけ並べ直す
List.reverse(List.foldLeft((acc, x) -> x :: acc, Nil, xs))
// 文字列: 1 回で取れるなら String.take などを使う。組むなら List[Char] を積んで StringBuilder で 1 回だけ
```

今ある該当を全部見るのは `bin/fge quadratic --all`。N が決まっていて伸びない物は、
**ゲームの `bin/lint-rules/quadratic.local.json`** に除外を書く（`bin/lint-rules/quadratic.json` は
追従のたびにエンジンの物で上書きされるので、ゲームの除外はそちらに書かない）:

```json
{ "exempt": { "src/render/Probe.flix::runAll": "描き出しの道具で N は場面の数（数十）" } }
```

## 2. `bin/fge z-table` が z の付け替えも止める（表を持つパッケージだけ）

`ZOrder.flix`（z の表）を持つパッケージで、表の外から `Render.zMapped` で z を付け替えると止まる。
付け替えた後の z がどの層に入るかは表から読めず、`z -> z / 4` のように縮めると他の層を越える。
表の層・帯の段から z を作り直す。表を持たないパッケージ（テンプレと大半のゲーム）は見ない。
