## `App.App` の record に欄 `annotationContext` が増えた

`App.game` / `App.make` などの組み立て口と `App.with*` で App を作っているゲームは何もしなくてよい。
`App.App` の record を `{ init = …, … }` と手で全部書いているゲームだけ、`annotationContext = None` を足す。

## 新しい口: `App.withAnnotationContext`（任意）

F8 で囲って書き出す注釈チケットの README 冒頭と annotation.json の `"context"` に、
ゲームの「その瞬間の文脈」を載せられる。繋がなければチケットは今までと同じ形
（ただし README の描画物の一覧は、1 字ずつ置かれた字を 1 行の文字列に束ねて出すようになった。
annotation.json の hits は字ごとのまま）。

```flix
|> App.withAnnotationContext(w -> {
       facts = ("場面", "${w#phase}") :: ("台本", "assets/x.script.json scenes[id=${w#talkScene}].lines[${w#talkAt}]") :: Nil,
       layers = ZOrder.allowedRanges(w#phase),   // (名前, 底, 天井)。描画物の z の横に名前が付く
       hudLayers = ZOrder.hudRanges()            // HUD の中の z で書く（持ち上げはエンジンが戻す）
   })
```

z の範囲の表は、描き出しの z の見回りに使っている表をそのまま渡せばよい。表が無ければ `Nil` で z は数のまま。
