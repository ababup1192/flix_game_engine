## 新しい口: 動き・効果音・待ちを 1 本に書く時刻表（`Timeline.build`）

演出の時刻表を、絵と音が同じクリップを読む形で書けるようになった。長さは秒・拍・小節と、曲に合わせて
伸び縮みする `ToNextBar`（次の小節の頭まで）・`ToBeat(n)` で書き、秒はテンポ（譜面の bpm）から出る。
置き方は GSAP の timeline・DOTween の Sequence と同じ（`append` = 表の終わり・`join` = 直前の行の頭・
`atStartOf` / `atEndOf` = 名前のクリップを基準・`withDelay` = そこから遅らせる。負なら手前へ）。
書き方の全体は `engine_world/src/Timeline.flix` の冒頭。

```flix
let tl = Timeline.build(Timeline.tempo(175.0, 4), List#{
    Timeline.append(Intro.Flash, Duration.Seconds(0.32)) |> Timeline.withSound("whoosh"),
    Timeline.append(Intro.Hold, Duration.ToBeat(8.0))    |> Timeline.withSound("slam"),
    Timeline.append(Intro.Turn1, Duration.Beats(1.0))
});
Timeline.progressOf(Intro.Hold, Timeline.playheadAt(age), tl)                         // 描く側
Timeline.soundsOn(Playback.Play, Timeline.playheadAt(prev), Timeline.playheadAt(age), tl) // 鳴らす側
```

- 効果音はクリップの属性（`withSound`）。描く側と鳴らす側が同じ start を読むので、鳴らす時刻を別の所に書かない。
  音が鳴るフレームで `stateOf` はもう `Active` か `After` を返す。区間は今の `startedBetween` と同じ (prev, now]。
  場面の最初のフレームは `Playback.Enter`（頭ちょうどの音も鳴らす）、飛ばすときは `Playback.Seek`（鳴らさない）。
- `build` は `Result` を返す。同じ名前・まだ置いていない名前を基準にした・待ちに音・待ちより前へ置く・長さを合わせる音の
  食い違いは `Err`。並びはゲームのコードの物なので、場面ごとにテスト 1 本で止める（実行時は `bug!` でよい）。
- 長さの決まらない待ちは `waitFor`。World は決定キーで `Timeline.resume(wall, resumes, tl)` を呼んで解けた時刻を
  記録するだけで、再生位置は `Timeline.playheadOf(wall, resumes, tl)`（待ちに着く前の早押しは数えない）。
- 時計は場面に入ってからの秒 1 本を渡す。曲に乗せる場面は、はやさを掛けない時計を渡す。
- 毎フレームの探索: `stateOf` は O(log タグ数)、`soundsOn` は二分探索で O(log 音の数 + 鳴る数)。

今の `Clip` / `toClips` / `startedBetween` / `durationOf` / `startOf` と `Seg` / `at` はそのまま。組んだ表から
古い読み手へは `Timeline.clipsOf(tl)` で `Clip` の列を渡せる（名前は `toClips` と別。`durationOf` に当たるのは `endOf`）。
秒だけで書いた表の開始の時刻は、`toClips` で足した時刻とビットまで同じ。

## 新しい口: 曲の頭を 1 回だけ鳴らして輪だけを回す（WAV のループ点）

イントロのある曲を、頭と輪の 2 本の音に割らずに 1 本で鳴らせるようになった。ループ点は WAV の `smpl`
チャンクに入れる。考え方と書き方は [docs/audio.md](../audio.md) の「曲の頭を 1 回だけ鳴らして、後ろの輪だけを回す」。

```flix
SfxSynth.renderLooped(cfg(), "assets/sfx", "bgmFight", List.append(intro, body), List.length(intro))
```

- 実機（render_gl）は読み込みのときにループ点をバッファへ付ける（OpenAL Soft の `AL_SOFT_loop_points`）。
  `App.withSustained` で同じ名前を宣言し続ければ、頭は 1 回だけ鳴って輪の頭へ戻る。
- 動画の書き出しで同じ回り方をさせるなら、`AudioMixdown.mixdown` を `mixdownLooped` に替え、
  ループ点を `AudioMixdown.loadLoopStart(rate, path)` で読んで名前 → サンプル番号の表で渡す。
- `smpl` を読む口は `AudioUtil.loopPointsOf`、任意のチャンクを探す口は `AudioUtil.findChunkOffset`。

### 頭と輪を 2 本の音に割っているゲームの移り方

1. 書き出しで、頭と輪をつないだ 1 本を `renderLooped` で書く（頭の長さをループ点に）。
2. 頭の音の名前を project.json の `sounds` から消し、WAV も消す。
3. 「頭の長さを過ぎたら輪へ切り替える」宣言と、その長さを写した Doc のキーを消す。
4. 動画の書き出し（`AudioMixdown`）を使っていれば `mixdownLooped` へ。
