# engine 0.54.0 → 0.55.0 の手当て

自動生成の一覧は [0.55.0.auto.md](0.55.0.auto.md)（直す物 0 件）。Flix の pub は変わらず、flix.toml の版を上げるだけでコンパイルは通る。
手当てが要るのは、新しく止まる文書の検査（doc-refs）と、`bin/fge refactor` と `CHECKD_BACKEND=server` が求める flixlint の版。

minor を上げたのは、precommit と `make lint` に新しい gate（doc-refs）が入り、ゲームの .md と .flix のコミットや `make lint` が止まりうるため。

## 追随の手順

1. **flix.toml の engine の版を 0.55.0 にし、`make sync-agents`**（`bin/lint-rules` ごと受け取る。新しいのは `doc-refs.json`・`refactor.json`、
   `precommit.json` の doc-refs、`hooks.json` の `checkd.server`）。
2. **`.flix` のコメントの上限を 2 つ置く**（`lint/limits/` は sync で配らない。置かないと上限 0 として `make lint-doc-refs` が止まる）:
   - `make lint-doc-refs` の要約の行に「.flix のコメントの見つからない物 N 件」と「doc に書いた呼び手 N 件」が出る（場所の全部は `-v`）。
   - 前の数を `lint/limits/doc-refs-flix.json` に `{"limit": N}`（.flix のコメントが指す、見つからない名前・パス・行の数）。
   - 後の数を `lint/limits/doc-refs-callers.json` に `{"limit": N}`（.flix のコメントに書いた「X が呼ぶ・から呼ぶ・が読む・が使う・
     が組む・が受け取る・で受け取る」の数。doc-refs.caller）。
   - 測った時の internet_dungeon（master 8ff1b552 の clone）は doc-refs-flix 19・doc-refs-callers 50。その後 record の欄（`World#replay` など）も
     確かめるようになり、.flix のコメントの物が 10 件ほど増えた。数はゲームの今の中身で取り直す。
   - 数が減ったら `make lint-doc-refs` が「limit を N に下げる」と言って止まるので下げる（0 になったらファイルを消す）。
3. **文書（.md）の古い参照を片付ける**: .md の物は上限が無く 1 件でも止まる（`make lint` は全部・コミットは触った .md だけ）。
   `make lint-doc-refs` の候補を見て、次のどれかにする（書き方の全部は engine の `docs/doc-conventions.md` の
   「文書（.md）と .flix のコメントの中で名前・パスを書く記法」）:
   - 今の名前・パスへ直す（候補が出る。行の番号でなく名前で指すと古びない）
   - 計画の文書の「これから作る名前」は名前の直後に `（予定）`（表は語の直後）。作ったら外す
   - 消した物を記録に残すなら `~~` の消し線で囲む
   - 文書ごと古い記録（`notes/<年-月>.md` など）は `bin/lint-rules/doc-refs.local.json` の `{"skip": ["notes/"]}`
4. **ゲームの Makefile の `lint:`**: engine の `mk/game.mk` が `lint: render-lint lint-doc-refs` を持つようになった。
   ゲームの `lint:` が前提だけの行（`lint: lint-view lint-palette …`）ならそのままで engine の分が足される。
   `lint:` にレシピ（タブで始まる行）を書いていたら makefile-dup が止めるので、レシピを `lint-<名前>:` へ移し、
   `lint: lint-<名前>` の前提だけの行にする。
5. **flixlint の版を確かめる**（ゲームの submodule `flixlint/` か `refactor.local.json` の flixlint）:
   - **0.8.3 以上が要る所**: `hooks.json` の `checkd.server` を受け取ると、`bin/fge refactor` は索引を作る flixlint に
     `--shim`・`--heap-mb`・`--idle-minutes` を渡す（`make check` と同じ常駐を分け合うため。版で分けていない）。
     それより古い flixlint のゲームは、refactor の索引が作れなくなるので上げる（internet_dungeon は 0.8.4）。
     `CHECKD_BACKEND=server` の check の常駐は hooks.json の版（0.8.3）の shim の jar を道具が取ってくるので、submodule の版によらない。
   - 操作ごとの下限: `rewrite`・`extract-function` は 0.8.0（汎用の AST）・`remove-use` は 0.7.2・`change-case-shape`・`change-signature` と
     lint と分け合う索引（`--resident`）は 0.7.1・ほかは 0.6.5。
6. **`CHECKD_BACKEND` は選ばなくてよい**（既定は今まで通り `repl`）。`make check` を速くしたいゲームだけ `CHECKD_BACKEND=server` を
   環境に置く（heavy の中では `CHECKD=1` も）。初回は flixlint のリリースから shim の jar を取る（ネットが要る・sha256 が合う時だけ置く）。
   常駐はヒープ 3072 MB・寿命 30 分なので、メモリの少ない機械では repl のままにする。答えの版がディスクと合わなければ頼み直し、
   3 回の後は素の flix check に落ちる（古い答えは使わない）。

## 変わった物

1. **doc-refs（文書が指す名前・パス・行の実在）を足した**（`bin/fge doc-refs`・`make lint-doc-refs`・precommit の gate）:
   - 見る物: `docs/**/*.md`・`NOTES.md`・`AGENTS.local.md`（engine は agents-pack も）の ` ` の中と表の行、
     `src`・`test` の `.flix` のコメント（`///` と `//`）の ` ` の中と地の文の `Mod.name`・`/` を含むパス・`path:行`。
   - record の欄（`Mod.Alias#欄`・`World#scene`）も確かめる。
   - 自動で外す物: 頭の 5 行に「手で直さない」「手で編集しない」「DO NOT EDIT」のある文書（生成物）・` ` の中の `'…'`
     （コンパイラの誤りの文の引用）・Flix の標準ライブラリの名前（`bin/flix.jar` の `src/library` から引く。このリポ → ENGINE → git の主の
     作業場の順に探す）・頭のモジュールがこのリポに無い名前。
   - コミットの時、触った `.flix` は HEAD の中身より増えた物だけで止める（古い件のあるファイルを触っただけのコミットは止めない）。
2. **`bin/fge refactor` を足した**（Flix の名前の位置の索引で数える・書き換える。操作の全部は `bin/fge refactor --help`）:
   - 読むだけ: `usages`（`--callers`・`--depth`・`--unused`）・`refs`・`match-sites`・`field-sites`・`index`
   - 書き換える: `expand-wildcard`・`remove-dead`・`field-to-accessor`・`remove-field`・`fix-construction`・`add-field`・
     `change-case-shape`・`change-signature`・`remove-param`・`make-private`・`remove-use`・`move`・`rewrite`・`extract-function`・`extract-type-alias`
   - 書き換える操作は既定で dry-run（`build/refactor/last.diff`）。`--apply` で書いて確かめの口（`refactor.json` の `verify`・remove-dead は
     `verifyTests`）を流し、落ちたら書く前の中身へ戻す。書く前の中身は `build/refactor/before/<時刻>/<パス>` に回ごとに控える（新しい 10 回分）。
     前の回が revert-failed のままなら次の `--apply` は断る（控えに戻すか、見比べて直した後に `REVERT-FAILED.txt` を消すと通る）。
   - 呼ぶ所に書く式は、同じ値の局所の名前があればそれを書く（型だけ同じ候補は `--prefer-local`）。
   - `rewrite`・`extract-function` で呼び手が 0 になる pub でない def は同じ patch で消す。`move` は .flix のコメントの古い名前も書き替える。
   - 索引は `make check`（`CHECKD_BACKEND=server`）と同じ flixlint の常駐で作り、heavy の枠を取らない。`--apply` の後の確かめの
     `make check` は heavy の外で `CHECKD=1 CHECKD_BACKEND=server` として流す（internet_dungeon の写しで change-signature 1 回の全体が
     中央値 13.61 → 8.86 秒、うち確かめが 10.15 → 4.95 秒。Mac mini・load average 28〜39）。
   - 設定は `bin/lint-rules/refactor.json`（engine が配る）と `refactor.local.json`（ゲームの上書き。`rewrites` に型紙の組を名前ごとに足せる）。
3. **checkd C-2: `CHECKD_BACKEND=server` を足した**（既定は repl のまま）: flixlint の常駐が頼まれた時にソースを読み、
   答えに検査したソースの版を付ける。保存直後の約 11 秒の待ちが無くなる（Mac mini・internet_dungeon の写しで make check の中央値
   repl 15.15 → server 5.11 秒。古い答えは 200 回で 0）。置き場と予算は `hooks.json` の `checkd.server`、仕組みは engine の `docs/checkd.md`。
4. **道具の答えを短い形にそろえた**（`checkres.Brief`。今は `bin/fge refactor` の全部の操作と `bin/fge doc-refs`）:
   数行の要約・場所の上位 10 行・全部は `build/<道具>/last-<操作>.txt`・終わりに `next:`。`-v` は今までの全文、`--json` は機械向け
   （engine の `docs/check-results.md` の「道具の答えの短い形」）。
5. **headless-run の鍵を直した**: pid の無い鍵（`build/headless/.lock`）が残ると 15 分止まっていた。鍵は pid を書いた一時フォルダを
   rename(2)（perl）で 1 回で取り、pid の無いまま 60 秒を過ぎた鍵・作り手の居ない鍵は外す。待つ間は 30 秒ごとに鍵の pid と年齢を出し、
   上限は `HEADLESS_LOCK_WAIT_SECONDS`（既定 900）。止める文の「unbound variable」（`$lock` の直後の全角の字）も直した。
6. **agent-eval のお題を足した**（`agents-pack/agent-eval/engine.json`）: doc-refs と refactor の各操作を、道具の名前を書かない依頼で
   選べるか（usages・match-sites・expand-wildcard・remove-dead・field-to-accessor・remove-field・fix-construction・add-field・
   change-case-shape・change-signature・move・make-private・remove-use・remove-param・rewrite・extract-function・extract-type-alias）と、
   常駐の描き出し（resident-render）。
7. **AGENTS.core.md の早見表**に doc-refs と refactor の行を足した（sync-agents で配られる）。

## 新しく使える物

| 口 | 中身 |
|---|---|
| `make lint-doc-refs`・`bin/fge doc-refs [文書.md …]` | 文書と .flix のコメントが指す名前・パス・行の実在。`-v` で全部・`--json` |
| `make lint` | engine の軽い検査の束（`render-lint`・`lint-doc-refs`）＋ゲームが `lint: 口` で足した検査 |
| `bin/fge refactor <操作>` | 使われ所・呼び手の階層・使われない pub と use・`case _` の書き出し・欄と case と引数の足し引き・移す・式の書き替え・関数と型 alias に出す（`--help`） |
| `CHECKD_BACKEND=server make check` | flixlint の常駐で check する（試しの道・既定は repl） |
| `HEADLESS_LOCK_WAIT_SECONDS` | headless-run が jar を作る鍵を待つ上限の秒 |
