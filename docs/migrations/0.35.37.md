# engine 0.35.36 → 0.35.37 の手当て

自動生成の一覧は [0.35.37.auto.md](0.35.37.auto.md)。

この版は、0.35.36 に続いてエージェントに毎回読ませる文書を減らした 2 周目。機械で止めた決まりは文書から消し、
AGENTS.md の後半は「判断の向き（機械では止められない物）」の 1 節だけになった（記録は [../rule-defenses.md](../rule-defenses.md)）。
ゲームは `make sync-agents GAME=…`（engine-upgrade）で受け取る。フックは配るときに足される（0.35.36 の仕組み）。

- **新しいフック hook-asset-guard**: ゲームの `assets/` の素材（sprite・anim・chip・sfx の JSON と png・wav・ogg・mp3・ttf・otf）へ
  Write / Edit / apply_patch で書く・Bash で書き込む（リダイレクト・`sed -i`・`cp` の行き先・スクリプトの `open(P, 'w')` など）と止まり、
  `atelier/` の同じ名前を返す。読むだけ・読んで atelier/ へ書く・パスを書かない生成スクリプトの実行は止めない。
  `atelier/` を持たないリポジトリでは何もしない。
- **新しいフック hook-read-guard**: 300 行を超える `.flix` を Read で `limit` 無し（か 300 を超える limit）で読む・
  パイプ無しの `cat` で出すと止まる。`grep -n` か `make src Q=` で位置を引き、範囲を決めて読む。
- **新しい lint（コミットで止まる）**:
  - `doc-shape`: ステージした `assets/` の Doc に整数の `version`・`note`（か `//`）・同じ種類の `<種類>.schema.json`
    （engine の `docs/` も探す）。スキーマの各項目の `label` か `description` は、そのスキーマを触ったときだけ見る。
  - `makefile-dup`: `mk/game.mk` を include する Makefile が共通の口（render など）にレシピを書くと止まる。値を変えるのは変数で。
  - `verb-names`: `is*`/`has*`/`can*` が Bool を返さない・`get*` が IO などの効果を持つと止まる。
- **forbid に view-text-literal**: `*View.flix` に `text = "文言"` を直に書くと止まる。文言は Doc の欄に置いて `doc#欄` で引く。
  forbid の規則に `rawLine`（.flix でも文字列の中身を見る）が足された。
- **エンジンの奥の索引は `docs/modules/engine.md`**: `docs/engine-module-index.md` は無くなり、`make module Q=<語>` で engine/src の
  行も引ける。分野の目次は今までどおり `docs/module-index.md`。
- **`make module` は engine/src の下請けの行（docs/modules/engine.md）を最後に出す**。
- **agent-eval の採点**: 最後の文に JSON が無い時（答えた後に裏の処理の知らせへ 1 文返した時）は、JSON を持つ最後の
  答えの文で採点する。前の記録と比べる時は `--rescore` でそろえる。
- **AGENTS.md の早見表に 1 行**: 「AI が素材（絵・音）を作る・直す → `atelier/` に書く」。
- **proposal の help に 1 行**: 返事の「決定: A2 B1」は `decision.picks` へ・選び続ける調整値は knob に `"keep": true`。
- **engine の release**: `make release` の前に `studio-parity`（Studio の clone で `check-agents-parity` をこの engine で流す）。
  sync-agents の出力の形を変えたら Studio の `server/src/NewGame.flix` も同じ変更にする。clone が無い所は `STUDIO=none`。

ゲーム側で直す物は無い（今の internet_dungeon と templates 6 本で、新しい lint・フック・forbid の当たりは 0 件）。
