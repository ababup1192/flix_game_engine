# engine 0.94.0 → 0.94.1 の手当て

テープの置き場を Pages の /docs から配る形にしてゲームごとの一覧を作り、テープの頁が動画を取る間に起動画面を出す変更に伴う手当て。
ゲームのコードで直す所は無い。

## 置き場で一度だけする物

| 直す所 | 直し方 | 止める物 |
|---|---|---|
| テープの置き場のリポジトリ（GitHub Pages が枝の / を出している所） | Settings → Pages を、枝の /docs を出す形に変える。そのあと `bin/fge tape publish --reindex --repo <owner/name> --seed-from <published.jsonl> --yes` で、根の tapes/ を docs/tapes/ へ移し、README・games/・tapes.json を作る（公開の URL は変わらない） | `bin/fge tape publish --yes` が Pages の設定を見て止める |

## 変わった所

| 何が | どう |
|---|---|
| 置き場の README.md | publish が tapes.json から毎回作り直す（手で書き足した分は消える） |
| テープの頁 | 動画を取る間、ゲームのブラウザ版と同じ起動画面（ロゴ・ゲージ・loading の一行）を出す。頁を作り直すには `bin/fge tape --dir` / `--group` を流し直す |
