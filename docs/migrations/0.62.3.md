# engine 0.62.2 → 0.62.3 の手当て

**ゲームで直す物は無い。** API は変わらない（`GamepadMap.kindOfVendor` が増えただけ）。

## 変わったこと

- **ゲームパッドを SDL3 で読む。** ウィンドウと GL は GLFW のまま、パッドの読み取りだけを SDL3（LWJGL の `lwjgl-sdl` 3.4.1）へ移した。
  Steam なしの Steam Controller（2 代目を含む）は本体がキーボード・マウスのふり（lizard mode: A = Enter・B = Esc）をして、
  GLFW では gamepad として見えなかった。SDL3 はこれを gamepad として読み、開いている間は lizard mode を止める。
- **SDL3 を始められない時は GLFW へ戻る。** GLFW の時も 1 番だけでなく全部の joystick から gamepad を探す。
- **パッドのログ。** 起動の時に `[gamepad] SDL3 x.y.z で読む`、使うパッドが変わるたびに名前とベンダーを stderr に出す。
  パッドが効かない時はまずこの行を見る（`docs/gamepad.md`）。
- 配る jar に SDL3 の native（5 OS 分）が増える。
