# engine 0.58.0 → 0.59.0 の手当て

ゲームパッドの Start と Select を、ほかのボタンと重ならない別々のキーへ渡し直した。あわせて、つないだパッドの機種
（Xbox 配置の一般・Steam Input を通した物・つないでいない）を `Frame#padKind` に置く。設計は [gamepad.md](../gamepad.md)。

## ゲームで直す物（直さないと組めない・動きが変わる）

1. **パッドの Start は `Enter` でなくなった。Start は `Key.Menu` を押す。**
   前は Start が `Enter` を押していて、`Enter` を決定にしているゲームでは Start と決定を見分けられなかった。
   - Start でメニュー・ポーズを開いていたゲーム（`Enter` をポーズや「始める」にしていた所）は、`Key.Menu` を足す。
     ```flix
     pause = Key.P :: Key.Enter :: Key.Menu :: Nil              // KeysDoc の既定
     App.justPressed(Key.Space, f) or App.justPressed(Key.Enter, f) or App.justPressed(Key.Menu, f)
     ```
     キーの割り当ての Doc（`*.keys.json`）にも `"Menu"` を足す。Studio のキーの欄で選べるよう、`keys.schema.json` の
     `enum` にも `"Backspace"` と `"Menu"` を足す（templates の game・novel・platformer はこの版で足した）。
   - パッドで決定するのは A（`Key.Z`）。`Enter` だけを決定にしていたゲームは、パッドで決定できなくなるので `Key.Z` を並べる。
   - 確かめ方: `grep -rn "Key.Enter" src` の所ごとに、パッドの Start で押されていてほしいかを見る。
2. **パッドの Select（Back / View）は `Key.Backspace` を押す。** 前はどのキーにもならなかった。`Backspace` を
   文字の削除などに使っているゲームは、Select でも消えるようになる（使っていなければ何も変わらない）。
3. **`App.Frame` を record の字面で組んでいる所**は欄 `padKind = GamepadMap.PadKind.Unknown` を足す
   （`App.frameOf` を使う所は直さなくてよい）。その mod の `use fge::{…}` に `GamepadMap` も足す。
   テストの入力のフレームを字面で組んでいるゲームに多い（`grep -rn "padTouched = false }" src test`）。
4. **`GameEngine.Game` を自前のハンドラで包んでいるゲーム**（テストのモックなど）は、op `gamepadKind` を足す
   （`def gamepadKind(k) = k(GamepadMap.PadKind.Unknown)`）。

## 新しく使える物

- `frame#padKind`: `GamepadMap.PadKind.Generic` / `Steam` / `Unknown`。Steam Deck の内蔵パッドや Steam から起動した時は
  `Steam`（USB のベンダーが Valve `28de`）。案内のボタンの絵を替える判断に。
- `GamepadMap.table()`: パッドのボタンとキーの対応表（1 ボタン = 1 キー）。案内に「Start: メニュー」と出す時の元に。

## 配布物を作る口（新しく使える物）

- `make dist-linux` / `make dist-macos` / `make dist-windows` / `make dist-all`: ゲームの jar・版を固定した JRE（SHA-256 を照合）・
  起動（run.sh・.app・run.bat）を 1 つにまとめ、ファイル名にゲームのコミットを入れる。Steam Deck は linux-x64。
  置き方と実機で確かめる項目は [steam-deck.md](../steam-deck.md)、3 つの起動の仕方は [dist.md](../dist.md)。
- ゲームで直す物は無い（使う時に `make dist-all` を流すだけ）。
