# engine 0.96.0 → 0.97.0 の手当て

（手書きの節。版を上げる時に変わった所を足す。）

## サウンドノベルのテンプレートから作ったゲーム

| 何が | どう |
|---|---|
| 会話の語彙 | 標準の命令の表は `assets/talk/vocab.std.json`（テンプレートの持ち物・追随で上書き）、ゲームの `assets/talk/vocab.json` はゲームの命令と Doc の場所と tags だけになった。追随の後に古い `vocab.json` のままだと、両方に同じ命令があって `bin/fge yarn build` が「命令 … が vocab.json と vocab.std.json の両方にある」で止まる。`make talk-vocab` を 1 回流すと直る |
| ゲームの口 | `GameRes`・`GameBoot`・`GameView.backdrop`・`GameView.hud`・`GameView.objects`・`GameCommands.backdropSwitch` を足した。ゲームの持ち物（`src/GameCommands.flix`・`src/GameView.flix`・`src/GameRes.flix`・`src/GameBoot.flix`）はテンプレートの物を写して、自分の中身を移す |
| 移行の門 | `make migrate-baseline`・`migrate-new`・`migrate-diff`・`migrate-video FLOW=`（と `flow-video`）を足した。古い版のゲームと新しい版の記録を `bin/fge migrate diff` で突き合わせる（使い方は engine の `docs/migrate-diff.md`）。使わないゲームは何もしなくてよい |
| `<<tween>>` | 台本の `<<tween 鍵 値 …>>` の鍵は `game.` を付けずに書く（`<<tween lair.arrive 1>>` は `game.lair.arrive` を動かす）。`game.` を書くと実行の時に誤りになる |

## engine_world

| 何が | どう |
|---|---|
| `YarnRunner.ranSourcesSince` | 同じ実行器の前と後の間に流した文の所（ファイルと行）を返す口を足した。溜めるだけで、今までの動きとセーブは変わらない。start・resume で作り直した実行器は before に `YarnRunner.closed()` を渡す |

## 描き手（WebGPU を試す時だけ）

3D の場面も `FLIX_GE_BACKEND=webgpu` で描くようになった（不透明・頂点の色・光 1 つ）。材質の絵・骨・影・lightmap・半透明・空・奥行きの書き出しはまだ描かず、種類ごとの回数を起動から 300 コマ目と終わりに 1 回知らせる。何も付けなければ今までどおり GL で、ゲームの絵は変わらない。
