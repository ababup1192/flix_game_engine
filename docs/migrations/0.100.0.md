# engine 0.99.0 → 0.100.0 の手当て

（手書きの節。版を上げる時に変わった所を足す。）

## PC の既定の描き手が WebGPU になった

ゲームのコードで直す所は無い。`make run` の窓は、何も付けなければ WebGPU（Dawn）で描く。

| 何が | どう |
|---|---|
| 窓（`LwjglLayer.withProject`・`withLwjgl`） | `FLIX_GE_BACKEND` を置かない・空・`webgpu` は WebGPU。`FLIX_GE_BACKEND=gl` で今までの GL。知らない字は 1 行言って WebGPU |
| WebGPU を使えない機械 | 起動の時に `[backend] WebGPU を使えない: <理由> — GL で起動する` を 1 行言って GL で描く（止まらない）。Dawn のネイティブは今は macOS arm64 だけを配っているので、Windows・Linux・Intel の Mac はこの道で GL になる |
| 窓なしの 1 枚撮り（`GpuShot.shotOf`。Studio の会話のプレビュー・`bin/fge talk shot`） | 窓と同じ `FLIX_GE_BACKEND` で選び、既定は WebGPU。開けなければ 1 行言って GL、GL も無ければ今までどおり SoftRaster。`GpuShot` の呼び方は同じ |
| 動画（`VideoOut`） | 今は GL のまま（`frames.json` の painter も `gl`） |
| F8 の注釈 | WebGPU の窓でも書く（前は WebGPU では書かずに 1 回知らせていた）。置き場と中身は GL と同じ |
| 起動の後に出た字 | WebGPU の窓も GL と同じく、出そうとした時に字を作ってアトラスへ足す（前は WebGPU では足さず、起動の時の字の決め方を used に寄せていた）。足せなかった字（フォントに無い・アトラスが満杯）は欠けの表に「起動の後に足せなかった字」と出る |
| 絵の差 | 同じ場面でも GL と数画素・丸めの差が出る所がある（MSAA の 2 と 8 は 4 に丸める・cutout の縁・3D の縮んだ Pass の横の縁など。`docs/backend-parity.md`）。前の版の GL で撮った絵とバイトで比べている物は、GL で撮り直すか `FLIX_GE_BACKEND=gl` で撮る |
| 比べの絵（`reference-check`・`make render`・flow の動画の比べ） | 変わらない（SoftRaster で描く） |
| ゲームの Makefile の窓を開く口 | GL の絵を前提にした比べ（自前の撮り比べ・GL の呼び出しの記録）を持っていたら、その口に `FLIX_GE_BACKEND=gl` を足す |

## ブラウザも既定が WebGPU になった

ゲームのコードで直す所は無い。`bin/fge export-web` で書き出した頁は、何も付けなければ WebGPU（`navigator.gpu`）で描く。

| 何が | どう |
|---|---|
| 頁の URL | 何も付けない・`?backend=webgpu`・知らない字は WebGPU。`?backend=webgl2`（`?backend=gl` も同じ）で今までの WebGL2 |
| WebGPU を使えないブラウザ | console に `[backend] WebGPU を使えない: <理由> — WebGL2 で起動する` を 1 行出して WebGL2 で描く（止まらない）。`navigator.gpu` が無い時は起動の前に、device・pipeline（WGSL）・絵とフォントを上げる所で落ちた時はその場で WebGL2 へ移る。canvas の webgpu の文脈を取った後に落ちた時だけ、頁を `?backend=webgl2` で開き直す |
| `bin/fge export-web` の ⑨（ヘッドレスの Chrome で開く確かめ） | 既定の頁と `?backend=webgl2` の頁の 2 つを開く（書き出しが数秒延びる） |
| `?fps=1` の表示・ベンチの頁（`make bench-web`）の表示 | 末尾・2 行目の頭に、実際に描いている描き手（`webgpu` / `webgl2`）を出す。`make bench-web` は既定で WebGPU を測る。WebGL2 を測るなら `ARGS='…&backend=webgl2'` |
| `web-capture` の `?capture=<n>` | 既定は WebGPU の絵（renderer は `webgpu: <adapter>`）。WebGL2 の絵と比べている物は URL に `&backend=webgl2` を足す |

## Flix のコンパイラが 0.80.0 になった

engine とテンプレートはソースを直さずに 0.80.0 で通る。ゲームも、まず版だけ上げて `make check` を回す。

1. `flix.toml` の `flix` を `"0.80.0"` に、engine の依存の `version` を `"0.100.0"` にする
2. `devbox.json` の flix を `"github:ababup1192/flix_game_engine?dir=nix/flix#flix_0_80_0"` にして `devbox install`
   （Studio だけで作っているゲームは Studio が同梱の flix を使うので、ここは飛ばしてよい）
3. 0.78.0 で取った物を捨てて取り直す: `rm -rf build lib/github` → `make check`
   （`lib/cache` の Maven の jar は版に依らないので残す。`lib/github` の engine の fpkg は engine の版ごとに取り直される）
4. flixlint を submodule で持っているなら v0.9.0 へ（`git -C flixlint fetch --tags && git -C flixlint checkout v0.9.0`）。
   `make sync-agents` で hooks.json を受け取ると、`bin/fge checkd` と `bin/fge refactor` が flixlint 0.9.0（0.80.0 用の shim）を使う。
   0.78.0 用の shim のままだと常駐が `NoSuchMethodError: ...Options.copy$default$14()` で落ちる
5. `make check` → `make test` → `make reference-check`

## Scene3dCmd に groups が増えた（動かない物の集まり）

`Scene3d.Scene3dCmd` を record の字で組み立てているゲームは、`groups = Nil` を足す（足さないと型の誤りで止まる）。動かない物（床・壁・家具など）が多い場面は、`Scene3d.staticGroup("名前", 物の列)` でまとめて `groups` に入れると、WebGPU で毎コマの計画と描く命令を持ち越す（スマホのブラウザで 12,000 個が 1.6 fps → 60 fps）。GL は今までどおり毎コマ描く。

`SoftRaster.Internal.Surface.drawSurface` の引数が 1 つ増えたが、engine_tools の中だけで使う物で、ゲームが呼ぶ所は無い。
