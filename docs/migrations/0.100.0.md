# engine 0.99.0 → 0.100.0 の手当て

（手書きの節。版を上げる時に変わった所を足す。）

## PC の既定の描き手が WebGPU になった

ゲームのコードで直す所は無い。`make run` の窓は、何も付けなければ WebGPU（Dawn）で描く。

| 何が | どう |
|---|---|
| 窓（`LwjglLayer.withProject`・`withLwjgl`） | `FLIX_GE_BACKEND` を置かない・空・`webgpu` は WebGPU。`FLIX_GE_BACKEND=gl` で今までの GL。知らない字は 1 行言って WebGPU |
| WebGPU を使えない機械 | 起動の時に `[backend] WebGPU を使えない: <理由> — GL で起動する` を 1 行言って GL で描く（止まらない）。Dawn のネイティブは今は macOS arm64 だけを配っているので、Windows・Linux・Intel の Mac はこの道で GL になる |
| 窓なしの 1 枚撮り（`GpuShot.shotOf`。Studio の会話のプレビュー・`bin/fge talk shot`） | 窓と同じ `FLIX_GE_BACKEND` で選び、既定は WebGPU。開けなければ 1 行言って GL、GL も無ければ今までどおり SoftRaster。`GpuShot` の呼び方は同じ |
| 動画（`VideoOut`） | 今は GL のまま（`frames.json` の painter も `gl`） |
| F8 の注釈 | WebGPU の窓でも書く（前は WebGPU では書かずに 1 回知らせていた）。置き場と中身は GL と同じ |
| 起動の後に出た字 | WebGPU の窓も GL と同じく、出そうとした時に字を作ってアトラスへ足す（前は WebGPU では足さず、起動の時の字の決め方を used に寄せていた）。足せなかった字（フォントに無い・アトラスが満杯）は欠けの表に「起動の後に足せなかった字」と出る |
| 絵の差 | 同じ場面でも GL と数画素・丸めの差が出る所がある（MSAA の 2 と 8 は 4 に丸める・cutout の縁・3D の縮んだ Pass の横の縁など。`docs/backend-parity.md`）。前の版の GL で撮った絵とバイトで比べている物は、GL で撮り直すか `FLIX_GE_BACKEND=gl` で撮る |
| 比べの絵（`reference-check`・`make render`・flow の動画の比べ） | 変わらない（SoftRaster で描く） |
| ゲームの Makefile の窓を開く口 | GL の絵を前提にした比べ（自前の撮り比べ・GL の呼び出しの記録）を持っていたら、その口に `FLIX_GE_BACKEND=gl` を足す |
