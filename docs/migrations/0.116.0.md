# engine 0.115.x → 0.116.0 の手当て

（手書きの節。版を上げる時に変わった所を足す。）

## 欄が増えた 3 つの record（字で全部の欄を書いて作っている所だけ直す）

ゲームが普段の書き方（`App.withPreload3d`・`FrameDiagnostics` を読むだけ・`LoadProgress` を handler から受けるだけ）なら直す所は無い。
テストのモックなどで record を字で全部の欄を書いて作っている所だけ、次の欄を足す。

| record | 足す欄 | 値 |
|---|---|---|
| `App.Rec`（engine_world） | `autoPreload3d` | ゲームは作らない（App のビルダーで組む）。engine の外で字で作っている所があれば、ビルダーで組む形へ替える |
| `LoadProgress.AssetDownloads`（engine） | `preparsedOf` | モックなら `_ -> None`（後から届く glb を Worker で解いた結果が無い = 今までどおりメインで解く） |
| `FrameDiagnostics.Scene3dCounts`（engine） | `shadowMapsReused`・`shadowMapsRedrawn` | 数を作るモックなら `0` |

## View に初めて出た staticGroup を engine が先に作る（auto-preload）

`App.withPreload3d` で宣言しなくても、View に初めて出た staticGroup は engine が先に作り、済むまで黒で覆う。一度描いた集まりは 30 秒は描き手に持たせ、
戻った時に黒くしない。暗転を自分で描いていたゲームは、そのままでも動く（engine の覆いが重なるだけ）。起動の暗転の間に全部を作りたい時は、今までどおり `App.withPreload3d` で宣言する。

## ブラウザで後から届く glb を Web Worker で解く

`web.deferred` の glb は頁が Web Worker で解き、`Model3d.decode` は組むだけになる。ゲームのコードは変えない。効かせるには、ゲームの `bin/fge-go` を engine から配り直す
（`make engine-upgrade` が配る。古い `bin/fge-go` の書き出しは Worker の js を置かず、頁はメインで解く前の道へ戻る）。比べるのは頁の URL の `?fge=noworker`。

## 動かない物の影の地図を控えて使い回す

GPU の描き手は、staticGroup の持ち越した物の影の地図を一度だけ描いて控え、毎コマは写して動く物だけを描く。ゲームのコードは変えない。絵は前と同じ。
切って比べるのは環境変数 `FLIX_GE_SHADOW_CACHE=off`。
