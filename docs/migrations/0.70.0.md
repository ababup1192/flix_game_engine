# engine 0.69.0 → 0.70.0 の手当て

Doc と描く元（アトラス・シェーダーの Spec・音の Mixer）を World の外に持つ `Resources` を engine_world に足した。
あわせて、World を遊びの状態だけにする形（Doc は `Res`・画面は enum）を `bin/fge record-wrap` が止めるようにした
（[flix-conventions.md](../flix-conventions.md) の「World は遊びの状態だけを持つ」）。手本は `templates/game-starter`（1 画面）・
`tidepool-starter`（題名・遊び・終わり）・`sound-novel-starter`（場面の enum と、Doc の束を Res に）。

## ゲームで直す物

**コンパイルで直す物は無い。** ただし World に Doc や描く元を平らに持つゲームは、`src/World.flix`（か、World の欄の
型を書いたファイル）を触ったコミットと `make lint` で、record-wrap の次の規則に止められる:

- **world-resource** — World の欄（型エイリアスと 1 case の enum の中まで）に `*Doc.Doc`・`ShaderDoc.Spec`・
  `PxSpriteAtlas.Baked`・`AudioMixer.Mixer`・`Yarn.Program` などがある
- **world-fields** — World の一番上の欄が多すぎる（上限は `bin/lint-rules/record-wrap.json` の `worldShape.maxTopFields`）

手で流すなら `make lint-record-wrap`（`make lint` にも入った）。

止まった時は 2 つのどちらか:

1. **手本どおりに移す**: Doc と描く元を `src/Res.flix` へ、App の w を `Resources.With[Res, World]` へ、
   Doc の読み直しを `Controls.docTable` の `Resources.reloadRow` へ。画面ごとの値は画面の enum の payload へ
2. **今は移さない**: ゲームの `bin/lint-rules/record-wrap.local.json` の `exemptRules` に理由つきで 1 行
   （`"src/World.flix::world-resource": "理由"`）。移した後に除外が鳴らなくなると、`make lint` が古い除外として知らせる

## 引退したテンプレート

`templates/tetris-starter`（落ち物パズル）と `templates/novel-starter`（ノベル・推理）を消した。パズルは
`tidepool-starter`、ノベルは `sound-novel-starter` を雛形にする。前にこの 2 本から作ったゲームは、そのまま動く
（ゲームはテンプレートを写した後はエンジンのテンプレートを読まない）。

## 自前の Resources を持つゲーム

`mod Resources` を自前で持つゲームは、そのファイルを消して `use fge::{Resources}` に替えられる（口と型は同じ）。
違いは読み直しの行の settle が純粋な `(res, w) -> w` になったことだけで、`checked_ecast` の手伝いは消せる。
forbid の `pair-construct`（組を record で直に作らない）をゲームの `forbid.local.json` に持っていたら、
エンジンの forbid.json に入ったので消せる。
