# engine 0.93.0 → 0.94.0 の手当て

テープが台本のノードをまたげるようにし、結末ごとに撮ったテープを分岐のカードでつなぐ変更に伴う手当て。
エンジンの core は変わっていない。テープの仕組みをテンプレートから写したゲームだけが、写し直す所を持つ。

## ゲームで直す物

| 直す所 | 直し方 | 止める物 |
|---|---|---|
| テンプレートから写した `src/render/TapeOut.flix` | テンプレートの今の物に写し直す（ノードをまたいでも作る・`lines[行].node`・`choices`・`question`）。ゲームの表（tapeTable）はそのまま | 写さなければノードをまたぐ flow で tape.json を作らない（今までどおり） |
| テンプレートから写した `src/ScriptEdits.flix` と Starts | `ScriptEdits.fileRows` の形に写し直す（直しが始めたノード以外の行にも当たる） | 写さなければ、別のノードの行の直しは当たらない |
| 写した「直した台本」の帯（View） | テンプレートの `View.bannerRows` に写し直す（縦の狭い画面で両端が切れない） | 目で見て |

## 使い始めるなら

| したいこと | 書く所 |
|---|---|
| 結末ごとに撮ったテープを分岐のカードでつなぐ | `make tape FLOWS="e2e/a.flow e2e/b.flow"`（撮ってから `bin/fge tape --group`） |
| つないだテープをまとめて Pages に置く | `bin/fge tape publish <フォルダ>…`（1 つの乱数のフォルダの下に並ぶ） |
