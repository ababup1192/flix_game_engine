# engine 0.85.0 → 0.86.0 の手当て

## ゲームで直す物

| 直す所 | 直し方 | 止める物 |
|---|---|---|
| `Platform.Services` の handler の組を自分で重ねている所（テンプレ・ゲームには無い。engine の LwjglLayer・GlOffscreen・WebLayer だけ） | `Platform.Tasks` が Services に入った。仕事を重ねない組なら `Platform.runTasksInPlace(() -> …)` を 1 段足す | コンパイル |
| `FrameDiagnostics.Scene3dCounts` を字で全部の欄を書いて組んでいる所 | 欄 `meshUploads`・`meshEvictions`・`texture3dUploads`・`mipCopies`・`materialBuilds`・`jointUploads`・`targetRebuilds`・`cpuPhases` を足す（`FrameDiagnostics.empty()` の欄から組んでいれば要らない） | コンパイル |
| `App.Rec` を字で全部の欄を書いて組んでいる所 | 欄 `pipelinedRendering = false` を足す（`App.game` / `App.make` から始めていれば要らない） | コンパイル |
| ゲームの src で `App.App(…)` を直に組んでいる所 | `App.game` / `App.make` から始めて `with*` でつなぐ（効果のある App に重ねる旗を立てられないように、lint-forbid の `game-app-direct` が止める） | lint-forbid |

## 絵とふるまい

**変わらない**（`App.withPipelinedRendering` を付けたゲームだけ、画面が 1 コマ前の World になる）。
- 3D の材質のプログラムの置き場は、同じと確かめた材質の参照を鍵ごとに 8 個覚える（絵は同じ・1 体ごとの木の比べが減る）。
- `Mat4.mul` / `toColumns`・`Skin3d.jointWorlds`・`AnimationClip3d.sample` を軽くした（出る数はビット単位で同じ）。
- `Mip.build` を速くした（出力はバイト一致）。使わない間に追い出したモデルを上げ直す跳ねを、追い出しの判定を予算に寄せて消した。

## 足した物

- `App.withPipelinedRendering(app)`（効果の無い `App[w, {}]` だけ）: 実機のループで、次のコマの World を別のスレッドで進めながら 1 つ前の World を描く（Bevy の pipelined rendering）。
  入力が画面に出るまでが 1 コマ遅れ、音は絵より 1 コマ早い。F8 で止めた画面とリモートの撮影は画面より 1 コマ先の World を描く。trace・台本・/step・描き出しは変わらない。
  ヒッチの記録の `updateNs` は、重ねた App では描いた後に World を進め終わるのを待った時間。
- `Platform.Tasks`（`startTask` / `finishTask`）と `Platform.runTasksInPlace`: 重ねる仕事を預ける機種の口。デスクトップは専用のスレッド 1 本（CPU が 1 個ならその場で）、
  ブラウザ版と窓の無い描き手はその場で順に走らせる。
- 環境変数 `FLIX_GE_NO_VSYNC`（置けば値を問わず入る）: 見える窓のまま垂直同期を待たない（60 fps より上の 1 コマの時間を測る）。
- `FrameDiagnostics.Scene3dCounts` の上げ直し・追い出し・材質のビルド・CPU の段の時間（`cpuPhases`）と、`FrameDiagnostics.uploadsText` / `cpuPhasesText` / `addScene3dCounts`。ヒッチの記録にも載る。
- `Pose3d.keyOf`（姿勢の鍵）・`ShaderGen.isSameEmission`。
