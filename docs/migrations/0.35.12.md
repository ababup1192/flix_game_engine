## `bin/fge record-wrap` がコミットを止める（0.35.9 からは警告だけだった）

`.flix` をステージしたコミットで、`World.World` の欄に展開すると 16 欄以上になる record を
包まずに置いていると止まる。大きさは入れ子の record と `List[...]`・`Option[...]` の中の record まで数える。
record の型エイリアスは使われるたびに中身のまま展開されるので、World を取る全 def の型検査が重くなる。

直し方は 1 case の enum で包む（[docs/flix-conventions.md](../flix-conventions.md)「World が直接持つ大きな record は enum で包む」）:

```flix
mod ReplayTrack {
    pub type alias Track = { ... }
    pub enum Boxed(Track)
    pub def box(track: Track): Boxed = Boxed.Boxed(track)
    pub def unbox(boxed: Boxed): Track = match boxed { case Boxed.Boxed(track) => track }
}
// World の欄: replayTrack = Option[ReplayTrack.Boxed]
```

今ある該当は `bin/fge record-wrap --all` で見る。残すなら `bin/lint-rules/record-wrap.json` の `exempt` へ
`"World.World::欄名": "理由"`。
