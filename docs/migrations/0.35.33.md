自動生成の一覧は [0.35.33.auto.md](0.35.33.auto.md)。API の非互換は無い。ゲーム側で直す物は無い（`make upgrade-game` で AGENTS.md・お題が配り直される）。

## `bin/fge heavy` の長い物の枠を 2 本に

- 枠は既定 3 本（`FGE_HEAVY_SLOTS`）。長い物（render-all・動画・compare・Makefile の `HEAVY_LONG`）は枠 1〜2 の **2 本まで**、
  枠 3 は check・test など短い物だけ。長い物の本数は `FGE_HEAVY_LONG_SLOTS`（既定 2）で変えられ、何本にしても短い物だけの枠を 1 本残す。
- 理由: 長い物が枠 1 だけだと 2026-10-16 の夕方に長い物が 5 本並び、0.35.32 の release が 47 分待った。長い物 2 本の同時は JVM 19.6GB（64GB の 1/3・heavy3 の測定）。
- `bin/fge heavy --status` の 1 行目に長い物の枠の本数、枠ごとに「長い物も短い物も / 短い物だけ」が出る。
- 前の版との混ざり: heavy の作りの版（`heavy.Revision`）は 4。0.35.30 からの作業場の `bin/fge heavy` は、
  `~/.flix_ge_studio/engines/0.35.33` があればこの版へ委ねて新しい決まりで並ぶ。0.35.29 以前の heavy と、委ねない `fge compare`・`fge use-engine` の中の鍵は、
  前の決まり（長い物は枠 1 だけ・短い物は枠 2 から）のまま取るので、版が混ざっても長い物が 3 本重なったり、枠 3 を長い物が取ったりはしない。
