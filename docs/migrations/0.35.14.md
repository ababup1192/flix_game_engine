## 描き出し（SoftRaster）が速くなった・絵は変わらない

シェーダー面（宣言シェーダーで塗る面）を、面ごとに 1 回だけ組み立ててから全コアで評価するようになった。
動画・`make render-all`・GIF のスナップショット・Studio の描き出しは、どれもこの経路を通るので何も変えずに速くなる
（internet_dungeon の実測: 全場面 173 枚 801 → 156 秒・チュートリアル動画 120 コマ 409 → 61 秒）。
描き出す画素は前の版と 1 バイトも変わらない（上の 2 つで全枚バイト一致を確かめた）ので、reference/ を描き直す必要もない。

- 描き出し中は CPU の全コアを使う。遊びながら描き出して重いときや、速さを前と比べたいときは
  `FGE_SOFT_SERIAL=1` を立てると 1 本で評価する（絵は同じ）。
- 解像度を下げる・`*_FRAMES` で範囲だけ描き直す、などの回り道はもう要らないことが多い。

## 新しい口: `ShaderEval.compileSpec`（任意）

自前の画素ループで `ShaderEval.evalPixelAlphaTex` を画素ごとに呼んでいるなら、`compileSpec(spec)` で
1 回組み立てて返ってきた関数を呼ぶと、木をたどり直す手間が無くなる（返す値は同じ）。

```flix
let eval = ShaderEval.compileSpec(spec);              // 面ごとに 1 回
let (color, alpha) = eval(uv, time, texEnv);          // 画素ごと
```
