# engine 0.94.1 → 0.95.0 の手当て

テープの頁に PC・タブレット向けのレイアウトを足した変更に伴う手当て。ゲームのコードで直す所は無い。

## 変わった所

| 何が | どう |
|---|---|
| テープの頁のレイアウト | 幅 720px 以上かつ高さ 500px 以上の画面では、動画編集ソフトに近い並びになる。横長で幅 1024px 以上なら 3 列（左にチャプター・真ん中に動画とタイムライン・右にインスペクタと注釈の一覧）、それ以外は 2 列。スマホ（幅 720px 未満か高さ 500px 未満）は今までどおりの縦 1 列 |
| キーボード | マウスのある画面で使える。Space / K で再生と停止、J / L で戻し再生と早送り、← → で 1 コマ、[ ] で前後の行、N / M で注釈、E で台詞を直す、⌘/Ctrl + S で書き出し（2 回押しで保存） |
| タイムラインのズーム | ルーラーの右のスライダー・⌘/Ctrl + ホイール・指のピンチ |
| シートのボタン | 「やめる」「付ける」をやめ、右上の ✕ と右下の確定（＋ 追加 / ✓ 適用 / ↓ 保存）にした。スマホの形も同じ |
| タイムラインの終わり | どの画面でも最後の秒まで送れる（今までは終わりの数秒へ送れなかった） |

## 頁を作り直す

前の版で作った頁は古いレイアウトのまま動く。新しいレイアウトにするには `bin/fge tape --dir <フォルダ>`（分岐があれば `--group`）を流し直し、
置き場へは `bin/fge tape publish` で置き直す。tape.json・書き出す .md・localStorage の形は変わっていないので、付けた注釈はそのまま残る。
