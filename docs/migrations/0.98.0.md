# engine 0.97.0 → 0.98.0 の手当て

（手書きの節。版を上げる時に変わった所を足す。）

## サウンドノベルのテンプレートから作ったゲーム

| 何が | どう |
|---|---|
| ゲームの flow の問い | ゲームの持ち物に `src/GameE2e.flix`（`GameE2e.probes()`）を足した。テンプレートの `E2e.table` は自分の問いの後ろにこれを並べる。追随では、テンプレートの `src/GameE2e.flix` を写してから自分の問いを移す（**写さないと `make check` が `GameE2e` を知らないで落ちる**）。今までテンプレートの `E2e.flix` の probes に問いを足していたゲームは、その行を `GameE2e.probes()` へ移す（作例の `ownPace`・`sharedTiredness` もそちらへ移った。物語に無いなら消してよい）。名前がテンプレートの問いと重なると TestTape の `testGameProbesDoNotShareANameWithTheTemplates` が落ちる |
| 押すと明ける待ち | `Commands.Out.WaitOrTap(秒)` を足した（押すと明ける・明けた時はゲームが持つ背景の切り替えも終わりの形）。`World.Pause` に `tappable` の欄が増えたので、テストで `Pause` を直に組んでいたら `tappable = false` を足す。`GameCommands.backdropSwitch` が秒を返す切り替えの待ちは、押すと明ける待ちになった（前は押しても明けなかった） |
| セーブの形 | 書くセーブの `version` が 4 になった。読むのは version 4・どの枠も `"stage"` を持つ version 3（0.96.0・0.97.0 のテンプレートが書いた物はこの形なので、そのまま読める）・version 2 まで。`"stage"` の無い枠がある version 3 と、5 以上は読まずに起動し、タイトルで `novel.story.json` の labels の `savesRefused` を知らせる。テンプレートの外で自分の Saves を version 3 にしていたゲーム（廃屋配信）のセーブはここで断られる。labels に `savesRefused` が無ければ既定の言葉が出る（自分の言葉にするなら足す） |
| `Saves.load`・`Game.app` | `Saves.load` は `Saves.Opened`（`{ saves, refused }`）を返す。Main は `Game.appFrom(res, World.opened(Saves.load(res#kind), 時刻))` で起動する（テンプレートの `Main.flix` を写せば済む）。`Game.app(res, saves, 時刻)` はそのまま使える |
| 縦の design の描き出しと flow | `SceneRender.design()` は project.json の `designWidth`・`designHeight` を読む（前は 960×540 の決め打ち）。縦の design のゲームでも flow の動画・tape.json・移行の記録がその大きさと縦の並べ方で撮れる。`SceneRender.cfgOf` は先頭に design を取る（`cfgOf(SceneRender.design(), 出力先, 絵)`）。横の 960×540 のゲームは描き出しの絵が変わらない |
| 撮るコマの上限 | `FlowVideo` の上限は、環境変数 `FLOW_FRAME_CAP`（正の整数）があればその数、無ければ flow の手が取りうる秒（wait・hold の長さ・until と drive の max・tap の前に入力を待つ 10 秒）から決める。長い flow で「フレームの上限に当たった」と出たら、flow の `max` を見直すか `FLOW_FRAME_CAP` を渡す |
