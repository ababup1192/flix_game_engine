# engine 0.97.0 → 0.98.0 の手当て

（手書きの節。版を上げる時に変わった所を足す。）

## サウンドノベルのテンプレートから作ったゲーム

| 何が | どう |
|---|---|
| ゲームの flow の問い | ゲームの持ち物に `src/GameE2e.flix`（`GameE2e.probes()`）を足した。テンプレートの `E2e.table` は自分の問いの後ろにこれを並べる。追随では、テンプレートの `src/GameE2e.flix` を写してから自分の問いを移す（**写さないと `make check` が `GameE2e` を知らないで落ちる**）。今までテンプレートの `E2e.flix` の probes に問いを足していたゲームは、その行を `GameE2e.probes()` へ移す（作例の `ownPace`・`sharedTiredness` もそちらへ移った。flow で待たないなら消してよい）。名前がテンプレートの問いと重なると TestTape の `testGameProbesDoNotShareANameWithTheTemplates` が落ちる |
| 押すと明ける待ち | `Commands.Out.WaitOrTap(秒)` を足した（人の送りで明ける・明けた時はゲームが持つ背景の切り替えも終わりの形・続けて押すと明ける待ちがあれば 1 回押すとまとめて明けて次の台詞の字まで出す・オートでは明けない）。`World.Pause` に `tappable`・`passInstant` の欄が増えたので、テストで `Pause` を直に組んでいたら `tappable = false, passInstant = false` を足す。`GameCommands.backdropSwitch` が秒を返す切り替えの待ちは `Commands.Out.SwitchWait`（押すと明け、待ちの間も後ろの時間を取らない命令 `<<audio>>` などは先に流し、台詞・選択肢・`<<wait>>`・時間を取る命令で止まる）になった（前は押しても明けず、後ろの命令も全部待った）。flow の reader は命令が出した待ち（Wait・WaitOrTap・SwitchWait）の間は押さない。`Shots` が場面を組む時の読み進め（`Shots.readThrough`・`toChoices`）も `WorldRead.advance` を通るので、歩いて替わる背景の途中で押すと、そこで歩きを飛ばして着いた形になる（場面の絵が前と替わりうる） |
| 命令の表 | `Res` に `commands`（`Commands.Table`。読み進める時に当てる命令の表）の欄が増えた。`Controls.loadRes` が `Commands.tableOf(Commands.table())` を入れるので、テンプレートの `Controls.flix` を写せば済む。`Res` を直に組んでいたテストは `commands` を足す |
| セーブの形 | 書くセーブの `version` が 4 になった。読むのは version 4・どの枠も `"stage"` を持つ version 3（0.96.0・0.97.0 のテンプレートが書いた物はこの形なので、そのまま読める。枠が 1 つも無い version 3 も今の形として読む）・version 2 まで。`"stage"` の無い枠がある version 3 と、5 以上は読まずに起動する。テンプレートの外で自分の Saves を version 3 にしていたゲーム（廃屋配信）のセーブはここで断られる |
| 断ったセーブ | 断った `saves/novel.json` は、遊び始めて最初の未読の行を読んだ時か設定を変えた時に書き直され、古い枠は消える。その前に、起動の時に元のファイルを `saves/novel.refused-v<版>.json`（版は元のファイルの version）へ写して残す（同じ名前のファイルが既にあれば書かない）。タイトルで labels の `savesRefusedKept`（写せなかった時は `savesRefused`）を知らせる。知らせの長さはほかの知らせと同じ `novel.kind.json` の `toastSeconds`（残したファイルは消えないので、読み逃しても失わない）。labels に無ければ既定の言葉が出る |
| `Saves.load`・`Game.app` | `Saves.load` は `Saves.Opened`（`{ saves, refused, keptAs }`）を返し、`Fs.FileWrite` も使う。Main とブラウザ版の WebMain は `Game.appFrom(res, World.opened(Saves.load(res#kind), 時刻))` で起動する（テンプレートの `src/Main.flix`・`web/WebMain.flix` を写せば済む）。`Game.app(res, saves, 時刻)` はそのまま使える |
| 縦の design の描き出しと flow | `SceneRender.design()` は project.json の `designWidth`・`designHeight` を読む（前は 960×540 の決め打ち。読めなければ 1 行言って 960×540）。縦の design のゲームでも flow の動画・tape.json・移行の記録がその大きさと縦の並べ方で撮れる。縦の design では `small-*` の場面を撮らない（縦の並べ方が選ばれ、同じ絵になる）。`SceneRender.cfgOf` は先頭に design を取る（`cfgOf(SceneRender.design(), 出力先, 絵)`）。横の 960×540 のゲームは描き出しの絵が変わらない |
| ゲームの口の字の本 | `View.Env` に `fonts`（`View.Fonts` = `{ atlas, fontOf }`）の欄が増えた。`GameView.draw`・`backdrop`・`hud` は `env#fonts#fontOf("名前")` で project.json の fonts の本を引ける（実機は `GameBoot.app` で `App.withFonts` に名前を宣言する）。描く所の Env は `View.envOfCtx(ctx, res, w)`、字を描かない所（当たり・テープの物）は今までどおり `View.envOf` で、fonts は字の形を持たない（`View.emptyFonts`）。テストで Env を直に組んでいたら `fonts = View.emptyFonts()` を足す。描き出しと flow も、`GameBoot.app` の `App.withFonts` で宣言した名前の本だけを混ぜる（宣言していない名前は実機と同じく本文の本。`SceneRender.extraFontsOf`・描き出しは `HeadlessRender.renderPngFull`。テンプレートの絵は変わらない）。`FlowVideo.objectsOf`・`objectsUsing` は先頭に本（`View.Fonts`）を取る |
| 頁の行の話し手 | `Page.Line` に `speakerId`（台本の話し手の id）の欄が増えた。話し手の色はこの id で引く（呼び名に replace が当たっても色が外れない）。行を直に組んでいたら `Page.plainLine(字, 所)` を使うか `speakerId = ""` を足す。セーブの頁にも書く（前のセーブの行は呼び名から引く） |
| 台本の字の置き換え | `novel.story.json` に `replace`（台本の字 → 画面の字）を足した。台詞・選択肢・話し手の呼び名・バックログに当たる。`StoryDoc.Rec` に欄が増えたので、Rec を直に組んでいたら `replace = Map.empty()` を足す。移行の記録（tape.json の events と lines）の字は台本の字のまま |
| BGM の音量 | 設定に BGM の音量（`musicVolume`）の行を足し、bgm のバスに掛ける（前は環境音の音量を掛けていた）。既定は `novel.kind.json` の `musicVolume`（0.7）と `musicVolumeSlider`、言葉は labels の `musicVolume`。セーブの config にも書く（前のセーブは既定の値）。設定の画面が 1 行増える |
| 縦の画面の下の帯 | `novel.theme.json` の windows の型に `portrait`（`page` = 頁に上から積む・`band` = 画面の下の帯に今の行だけ）と `bandHeight`（帯の高さ px・既定 236）を足した。書かない型は今までどおり page。`ThemeDoc.Window` を直に組んでいたら `portrait = ThemeDoc.PortraitText.Page` を足す |
| 撮るコマの上限 | `FlowVideo` の上限は、環境変数 `FLOW_FRAME_CAP`（正の整数。読めなければ 1 行言う）があればその数、無ければ flow の手が取りうる秒（wait・hold の長さ・until と drive の max・tap の前に入力を待つ 10 秒）と記録が書いたフレームの数から決める。長い flow で「フレームの上限に当たった」と出たら、flow の `max` を見直すか `FLOW_FRAME_CAP` を渡す |
| テストが読む Doc と台本 | 規則のテストは、ゲームの Doc と台本ではなく作例の写し `test/fixtures/sample/`（`assets/novel.*.json` と `assets/talk/yukidoke.yarn` と、それを `--no-vocab` で組んだ `dialogue.json`）を読む。`TestKit.res()` は `Controls.loadResIn(TestKit.sampleRoot())` に命令の表をテンプレートの物だけ（`Commands.tableOf(Commands.all())`）にした物（`Controls.loadRes()` は `loadResIn("")` と同じ。`SoundLength.loadIn(フォルダ)` も足した）。追随では `test/fixtures/sample/` を丸ごと写し、`test/TestKit.flix`・`src/Controls.flix`・`src/SoundLength.flix` と test/ の直下のテストを写す。台本や Doc を書き換えたゲームでも、写しを書き換えなければ規則のテストは緑のまま（**写しをゲームの台本と Doc に合わせて書き換えない**）。ゲームの Doc と台本と project.json を見るテスト（写真・音・立ち絵の登録・言葉の鍵・変数の表示名・語彙・場面が組めるか・台本のコマンドが当たるか）は `Controls.loadRes()` を読むので、ゲームの物が検査される |
| 作例を確かめるテスト | 作例の筋（どの選択肢でどの結末か）・作例の Doc がコードの既定と同じ・縦の design・描き出しの見本の立ち絵・写しが作例と同じか、は `test/sample/TestSample.flix` へ移した。`make new-game` はこのフォルダを消す。追随では写さない（写したら消す）。前に作例の台本や Doc に頼るテストを写して落ちていたゲーム（廃屋配信）は、テンプレートの test/ を写し直し、`test/sample/` を消せば落ちなくなる |
| 命令の表のテスト | `TestCommands.testEveryCommandInTheTableRunsWithItsRequiredArguments` はテンプレートの命令（`Commands.all()`）だけを見る。ゲームの命令の必須の引数はゲームのテストで見る |
| 重ねた環境音の登録のテスト | `TestDocs.testEverySoundTheGameCanPlayIsRegistered` は `<<audio ambience a,b>>` を `a` と `b` の 2 つとして登録を見る（前は `a,b` を 1 つの名前として数えて落ちた）。空の `titleAmbience`（タイトルで環境音を鳴らさない）は見ない |
| セーブとロードの場面の枠 | 描き出しの save・load の場面が 1 ページ目に書いておくセーブは、`novel.shots.json` の `slots`（`[{ "node": …, "say": … }]`。上の枠から。say を省けば 0）になった（前は作例のノード名をコードに書いていた）。`ShotsDoc.Rec` に `slots` の欄が増えた。追随では `src/ShotsDoc.flix`・`src/Shots.flix`・`assets/shots.schema.json` を写し、ゲームの `novel.shots.json` に自分の台本のノードで `slots` を書く（書かなければ枠は空。知らないノードを書くと `TestRules.testEveryShotBuildsFromTheApp` が知らせで落ちる） |
| 作例を名前で指す注釈 | テンプレートの src/ と test/ のコメント・`AGENTS.local.md` は、作例のファイル（`assets/talk/yukidoke.yarn`・立ち絵の見本の PNG・`art/cast/` の道具）とノード名を名前で指さなくなった。ほかの doc-refs の赤（無い名前・doc に書いた呼び手）も直した。追随で src/ と test/ を写したら、`bin/lint-rules/doc-refs.local.json` の skip に入れていたテンプレートのファイルを外す。シナリオが読めない時の画面の字も「assets/talk の .yarn を直して…」になった |
