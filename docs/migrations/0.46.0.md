# engine 0.45.0 → 0.46.0 の手当て

自動生成の一覧は [0.46.0.auto.md](0.46.0.auto.md)。設計のメモは [clock.md](../clock.md)。

時刻を「どの時計で測ったか」の型つきで持つ仕組みを足した: `Clock.Time[c]` / `Clock.Clock[c]`、ゲームの時計を
App が進める `App.addClock`、実時間を配る `frame#realNow`。違う時計（遊び・物語・実時間）の時刻を混ぜると
型検査が止める（E7491）。止まらない書き方は lint-forbid の 4 本（`clock-*`）が止める。
今までの秒の Float64 の API（`Lifetime.fire`・`Timeline.soundsBetween` / `soundsSince` など）はそのまま残る。

## ゲームで直す物

1. **`App.Frame` を record の字面で組んでいるテスト**は、欄 `realNow` を足す（無いと E7463 の Missing label）。
   値は `Clock.zero()` でよい（`App.trace` / `PropertyTest` / 実機は App が実時間に置き直す）。
   ```flix
   { down = Set#{}, justPressed = Set#{}, dt = 1.0 / 60.0, …, wheel = 0.0, realNow = Clock.zero() }
   ```
   `App.frameOf` で組んでいるテストは直さなくてよい。
2. **`App.StepState` を字面で組んでいるテスト**は、欄 `real` を足すか `{ carry = …, pending = … | App.freshStepState() }` にする。
3. ほかは何もしなくても今までどおり動く。時計を使い始めるのは、ポーズ・メニュー・ヒットストップで
   「止めて戻すと音が鳴り直す」「止めている間も動く物がある」を直したくなったときでよい（下）。

## 新しく使える物

### 遊びの時計と実時間を分ける（`Clock` + `App.addClock` + `frame#realNow`）

```flix
pub enum Play                                  // 時計の名前（pub が要る。中身は要らない）
pub enum Halt { case PauseMenu }               // 止める理由

// World: play = Clock.Clock[Play]・hitAt = Clock.Time[Play]（初期値 Clock.never()）・realNow = Clock.Time[Clock.Real]
pub def paceOf(w: World): Clock.Pace[Play, Halt] =
    Clock.paceOf(if (isPaused(w)) Clock.Run.Paused(Halt.PauseMenu) else Clock.Run.Running)
        |> Clock.withSlow(w#hitAt, hitstopPlan(w))

app |> App.addClock({ clockOf = w -> w#play, withClock = (c, w) -> { play = c | w }, paceOf = World.paceOf })
```

- App が系より先に、実フレームにつき 1 回だけ時計を進める。遊びは `Clock.dtOf(w#play)` で進め、今は `Clock.nowOf(w#play)`。
- 実時間は `frame#realNow`。View で読むなら系で World の欄へ写す。
- 寿命は `Lifetime.Span[c]`・`Lifetime.fireOn(今, 秒)` / `progressOn` / `aliveOn` / `remainingOn`。
- 時刻表の音は `Timeline.soundsOnClock(時計, 起点, 表)`、描く側は `Timeline.progressOn(時計, 起点, タグ, 表)`。
- 系を直に呼ぶテストは先に `App.tickClocks(app, dt, w)`。

### lint-forbid の新しい規則（ゲームの src/ を見る）

| id | 止める物 | 代わり |
|---|---|---|
| `clock-advance` | `Clock.advance` / `App.tickClocks`（test/ は見ない） | `App.addClock` で宣言 |
| `clock-real-clock` | `Clock[Real]` を持つ | `frame#realNow` |
| `clock-seconds-leak` | `secondsOf` で秒へ戻して引く・比べる・`after` で包み直す | `Clock.since`・`Time` のまま比べる・`Clock.after` |
| `clock-old-sounds` | `App.addClock` のあるプロジェクトの `soundsBetween` / `soundsSince` / `progressSince` | `soundsOnClock` / `progressOn` |

forbid の規則に `skipDirs`（パスのどの段のフォルダでも外す）と `whenProject`（いちばん近い flix.toml の
プロジェクトの .flix に当たるときだけ有効になる）を書けるようになった（forbid.local.json でも使える）。

## 雛形の変化

- platformer-starter: 遊びの時計 `play` と実時間 `realNow`。ポーズ（キーは player.keys.json の `pause`）で遊びの時計を止め、
  踏みつけのヒットストップは `Clock.withSlow`。白い光とポーズの字の点滅は実時間。描き出しに `hitstop` の場面。
- novel-starter: 物語の時計 `storyClock` と実時間 `realNow`。メニュー（キーは新しいキーの Doc）で物語の時計を止め、
  雨・炎・埃とメニューの点滅は実時間。灯りの演出の音は `soundsOnClock`。
