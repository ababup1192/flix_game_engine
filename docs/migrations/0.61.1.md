# engine 0.61.0 → 0.61.1 の手当て

**ゲームで直す物は無い。** API は変わらない。

## 変わったこと

- **ステレオの音を左右そのまま出口へ流す（AL_SOFT_direct_channels）。** これまで OpenAL Soft はステレオのバッファの左右を
  仮想の 2 本のスピーカーとして鳴らし直していて、ヘッドホンで HRTF が効くと片側だけの音がもう片側へ半分ほど漏れていた
  （右だけで鳴るこだまが主旋律に重なり、WAV を直接聞くと平気なのにゲームの中では二重に聞こえる）。
  音源を作る所（`RenderAudio.loadAudioRegistry`）で立てるので、実行中にバッファを差し替えても（reloadAudio）残る。
  拡張が無い環境では何もしない。モノラルの音には効かない。
