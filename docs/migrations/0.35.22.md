# engine 0.35.21 → 0.35.22 の手当て

自動生成の一覧は [0.35.22.auto.md](0.35.22.auto.md)。Flix の API は変わらない。`make engine-upgrade` で
`bin/fge`・`mk/game.mk`・AGENTS.md の早見表・status の規約が配り直される。

## 新しい口: `make agent-eval-release`（任意・リリースの後に 1 回）

全部のお題を 3 回（`REPEAT=`）流し、`agent-eval/history/<版>.json` に版ごとの記録を残して 1 つ前の版と比べる。
平均点が 15 点以上下がった・入力トークンの平均が 1.5 倍を超えたお題を「下がった」と出す。
heavy の鍵は取らない（claude -p は待ちが主で、鍵を取るとほかの check・test を 20 分止めるため）。
同時に走る claude -p の本数は、いくつの作業場から流してもマシン全体で 3 本まで（`/tmp/fge-agent-eval.slots`・
`FGE_AGENT_EVAL_SLOTS` で変える）。`bin/fge heavy make agent-eval` と包む必要も無くなった。約 20 分・$18（API 換算）。`agent-eval/history/` はコミットする。

`make status` に 1 行増える（記録が無いゲームでは出ない）:

```
agent-eval v0.35.22: 平均 100 点（18 題×3 回・入力 248k tok/題・$17.65） ▼v0.35.21 より下がった: hud-timer
```

## `make agent-eval` に `REPEAT=`

`make agent-eval REPEAT=3` で同じお題を 3 回流し、表は最小・平均・最大になる。記録は `<お題>.<回>.jsonl`。
何回か流した記録どうしの `make agent-eval-compare` は平均で比べる。

## 採点の直し

正しい答えが減点されていた 2 つの形を直した（`--rescore` で付け直すと点が上がることがある）。

- 「`let _ =` は使えない」のような「使えない」を打ち消しとして読む
- 読んだファイルの一覧（`files_read`・`読んだファイル`）に並んだ語は、選んだ物として数えない

ぶれの大きさと、点が見ていない物は [docs/agent-eval.md](../agent-eval.md)。
