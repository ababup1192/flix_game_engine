自動生成の一覧は [0.35.34.auto.md](0.35.34.auto.md)。描き出し（動画の連番・ギャラリー・1 枚だけ）を速くした。

## 1. 描き出しの口が jar を使い回す（コンパイルは src か lib が変わった時だけ）

`make render-all` と `make render SHOT=…` は `$(HEADLESS_RUN) 入口` で流すようになった。
`HEADLESS_RUN` は `bin/headless-run` を叩き、`build/headless/headless.jar` を 1 回だけ作って使い回す
（入口は src の `pub def 名前(): Unit \ IO =` を 1 行で書いた物から自動で拾う。引数あり・別の効果つき・
複数行・mod が 2 つ以上あるファイルの入口は拾えず、今までどおり `flix run` で流れる）。

- ゲームの Makefile に自前の `HEADLESS_RUN = … $(FLIX) run --entrypoint` があれば**消す**（残すと毎回コンパイルする）。
- ゲーム固有の描き出しの口（動画など）も `$(HEADLESS_RUN) 入口` で書くと同じく速くなる。
  `HEADLESS_RUN` は game.mk の `?=` なので、ゲームの Makefile で `HEADLESS_RUN = …` と書くとそちらが勝つ。
- `build/` が `.gitignore` に入っているかを確かめる。
- jar を作り直させたい時（おかしいと思った時）は `rm -rf build/headless`。

## 2. コマ列ではテクスチャを 1 回だけ読む

`SoftRaster.renderToImageFonts` / `renderToImageFull` は 1 コマごとに texturePath の PNG を全部読み直す。
コマ列（動画 1 本・ギャラリー 1 周）の前に `SoftRaster.freshTextureCache()` を 1 本作り、
`SoftRaster.renderToImageCached(req, surfaces, extraFonts, extraImages, warnLog, cache)` で描く。

| 今 | 置き換え |
|---|---|
| `SoftRaster.renderToImageFonts(req, surfaces, fonts)`（コマ列の中） | `SoftRaster.renderToImageCached(req, surfaces, fonts, Map.empty(), SoftRaster.freshTexWarnLog(), cache)` |
| `SoftRaster.renderToImageLogged(req, surfaces, fonts, images, warnLog)`（コマ列の中） | `SoftRaster.renderToImageCached(req, surfaces, fonts, images, warnLog, cache)` |

キャッシュの寿命は 1 回の描き出しの間だけにする（長く持つと、保存し直した絵に気づかない）。
**描き出しの途中で、texturePath が指す PNG を同じパスへ書き直すなら、書き直すたびに新しいキャッシュを作る**
（例: 案ごとに面の PNG を書き出してから貼る動画。使い回すと 1 本目の案の絵を貼り続ける）。
HeadlessRender の GIF（renderGifFonts / renderGifWith / renderGifWithPasses）は中で使うようになった。
