# engine 0.33.5 → 0.34.0 の手当て

自動生成の一覧は [0.34.0.auto.md](0.34.0.auto.md)（API の非互換は 0 件）。
ここには、ゲーム側の `flix.toml` の直し方を書く。

## なぜ変わったか

engine 同梱の Flix コンパイラが 0.77.0 になった。0.77.0 は新しいパッケージ管理
（flix/flix#13346）で、古い `flix.toml` の書き方を受け付けない。

## 1. flix.toml の `[package]` を 3 キーだけにする

```toml
# 前
[package]
name        = "my_game"
description = "..."
version     = "0.1.0"
flix        = "0.75.1"
authors     = ["you <you@example.com>"]

# 後
[package]
version     = "0.1.0"
flix        = "0.76.2"
```

`name` / `description` / `authors` は書くとエラーになる。`flix` を `0.77.0` にしないのは、
0.77.0 の jar が自分を 0.76.2 と名乗るため（0.77.0 と書くとバージョン不足で落ちる）。

## 2. 依存の行と engine の指し先を 0.34.0 へ

```toml
"github:ababup1192/flix_game_engine" = { version = "0.34.0", security = "unrestricted" }
```

`local.mk` で `ENGINE` を書いているなら、その指し先も 0.34.0 の engine へ。

## 直し方の手順

1. 上の 2 つを直して `make check`
2. 緑になったら `make test` と `make reference-check`
