# engine 0.38.0 → 0.39.0 の手当て

自動生成の一覧は [0.39.0.auto.md](0.39.0.auto.md)。

ステレオ（2ch）の WAV を、鳴らす・動画の音に混ぜる・調べる・比べるの全部で左右のまま扱えるようにした。
今までの取り決め「16bit モノラルの WAV（要れば smpl 1 本）」はそのまま有効で、モノラルは今までどおり両耳に同じ音で鳴る。

## ゲームで直す物

ありません。モノラルの素材は何もしなくても今までどおり鳴る。

- ステレオの素材（16bit・smpl のループ点つきでもよい）は、そのまま `assets/` に置いて project.json の `sounds` に書けば鳴る。
  左右を足してモノラルに落としてから入れる手当ては要らない（落としていた素材は元のステレオに戻してよい）。
- サンプルレートは WAV ごとに違ってよい（実機は OpenAL が合わせ、`AudioMixdown` は読み込みで読み直す）。
- `make sync-agents` で配る `precommit.json` は、ゲームのリポ直下の `assets/` の画像を通すようになった。
  ゲーム側で `stagedImages.allowedPrefixes` に `"assets/"` を足していたなら、その 1 行は消してよい。

## 新しく使える物

- 動画の音をステレオで書き出す: `AudioMixdown.loadWavStereo` → `AudioMixdown.mixdownStereo` → `SfxSynth.wavBytesStereo`。
  モノラルの素材は左右に同じ音で入る。ループの頭・鳴り直し・バスの倍率・ローパスは左右の同じサンプルに効く。
  `loadWav` / `mixdown` は今までどおりモノラル（ステレオの素材は左右の平均）。
- ステレオの曲を合成して書く: `SfxSynth.wavBytesStereo` / `wavBytesStereoLooped` / `renderLoopedStereo`（smpl は左右 1 組の番号）。
- `fge waveform`（`make gallery-sounds`）: ステレオは波形の欄の上が左・下が右。見出しに左右のピーク（l / r）と
  `side`（左右の差の大きさ。0 = 左右が同じ）を書く。`--json` に `channels`・`peakLeft`・`peakRight`・`sideToMid`。
  左右で打ち消し合う音を「全部無音」と見誤らない。
- `make compare` の音の差: バイト数に加えて「1ch 22050Hz 93.33 秒 ピーク 0.891 → 2ch 44100Hz …」を出す。

## 気をつける所

- 左右の振り（パン）をゲームから付ける口は無い（今回も足していない）。音量（`setVolume`・バス）・高さ（`setPitch`）・
  ローパスはステレオの素材にも同じに効く。
- 44.1kHz のステレオは 22050Hz のモノラルの 4 倍のメモリーを使う（音は起動時に全部読む）。長い曲を何本も持つなら大きさを見る。
- 0.38.0 のノートで「0.39 で消す」とした `ZStack.Node` の別名と `SortingLayer.pick` は、この版では消していない（次の版で消す）。

## エンジンの口（エンジンを直す人へ）

- WAV の形式は `AudioUtil.formatOf`（fmt チャンクを探す。fmt の前に LIST がある WAV も読む）・
  組の数は `AudioUtil.framesOf`。実機（`RenderAudio.loadWavToALBuffer`）と `AudioMixdown` の両方がこれを通る。
- `AudioMixdown` の混ぜる芯はチャンネル数つき（`mixChannels`）。モノラルの口も同じ芯を 1 本で通る。
- Go の WAV の読み込みは `go/internal/wavfile`（`fge waveform` と `fge compare` が使う）。
- テスト: `TestAudioUtil`（fmt の前に LIST・ステレオの組の数）・`TestSfxSynth`（左右の交互の並び・smpl が組の番号）・
  `TestAudioMixer`（左右が混ざらない・ループの頭が左右で同じ・モノラルだけなら mixdown と同じ・ステレオの読み込みと読み直し）・
  `go/waveform_test.go`・`go/internal/wavfile`・`go/internal/compare`（モノラル → ステレオの差）・
  `go/internal/precommit`（直下の assets/ を通す）。
