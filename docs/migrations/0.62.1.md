# engine 0.62.0 → 0.62.1 の手当て

**ゲームで直す物は無い。** API は変わらない。`make sync-agents` で配り直すと、skill とフックの配線が入る。

## 変わったこと

- **release の Studio の置き場を自動で探す。** `STUDIO` の既定を、engine の clone の隣（`../flix_ge_studio`）→
  `~/Desktop/flix_ge_studio` の順で Makefile がある方にした。見つからない時は探した所を並べて止まる。
- **skill に探す道具とその理由を足した。** flix-docs の「書く前に読む・探す」に、`bin/fge refactor` の show・search・outline・
  context（trace）・usages と、字で探して丸ごと読むと何に困るかを並べた。critique-code と compile-fix の読む手順もそこへ向けた。
- **hook-search-nudge を足した。** `.flix` の名前（def の行・`Mod.名前`・camelCase）を grep・rg で `src/`・`test/` の下や `.flix` から探した時に、
  `refactor search`・`show`・`usages`・`context` を 1 回だけ案内する。止めない（文書の言葉や JSON の値は grep が正しい）・
  セッションに 1 回。文言は `bin/lint-rules/hooks.json` の `searchNudge`。
