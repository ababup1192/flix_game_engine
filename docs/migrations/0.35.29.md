## 新しい口

- `Timeline.insert(at, tag, length)` — 表の頭から決まった時刻（`Duration.Seconds` か `Beats`）に置く（DOTween の Insert）。
  重ねて置くクリップ（`Timeline.clip(tag, start, dur)` を並べていた所）はこれで書く。
- `Timeline.soundsBetween(前の秒, 今の秒, 表)` — 待ちの無い表で、このフレームに鳴らす音（`soundsOn` の Play と同じ (prev, now]）。
- `Timeline.buildOrBug(名前, テンポ, 行)` — 並びをコードが書く表を組み、書き間違いなら名前と一覧を出して止める。
- `Timeline.noTempo()` — 拍を書かない表（秒だけ）に渡すテンポ。

## 置き換え（1 行 1 件）

| 止まった名前 | 置き換え |
|---|---|
| `Timeline.toClips((tag, 秒) :: …)` | `Timeline.buildOrBug(名前, Timeline.noTempo(), List#{ Timeline.append(tag, Duration.Seconds(秒)), … })`（開始の時刻はビットまで同じ） |
| `Timeline.clip(tag, start, dur)` を並べた列 | `Timeline.insert(Duration.Seconds(start), tag, Duration.Seconds(dur))` を build の行に（同じ物を何本も並べる所は tag に番号: `Tick(i)`） |
| `Timeline.startedBetween(t0, t1, clips)` で鳴らす | 音を行に `Timeline.withSound("名前")` で付け、鳴らす側は `Timeline.soundsBetween(t0, t1, 表)`（境目は同じ） |
| `Timeline.startOf(tag, clips)` | `Timeline.clipOf(tag, 表) \|> Option.map(c -> c#start)` |
| `Timeline.durationOf(clips)` | `Timeline.endOf(表)`（一部のクリップだけの終わりなら `Timeline.clipsOf(表)` を絞って `start + dur` の最大） |
| `Timeline.Seg`・`Timeline.seg(名前, 秒)`・`Timeline.total(列)` | `Timeline.append(tag, Duration.Seconds(秒))` で並べ、全体の秒は `Timeline.endOf` |
| `Timeline.at(列, t)` | `Timeline.stateOf(tag, Timeline.playheadAt(t), 表)`（`Active(u)` の u は 0..1。秒が要るなら `t - clip#start`） |
