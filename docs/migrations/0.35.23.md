## 新しい口: `Timeline.Duration.ToPickup(n)` — 次の小節の頭の n 拍前（弱起）まで

「曲の本編の頭の 1 拍前にターン 1 を置く」のように、小節線の少し前に置きたい所を 1 行で書ける。
今の位置から n 拍以上の余裕がある次の小節線を探し、その n 拍前まで（余裕が n 拍未満の小節線は飛ばす）。
長さにも `withDelay` にも使える。

```flix
// 前: 足場の行と負の遅らせ
Timeline.append(Beat.Lead, Duration.ToNextBar) |> Timeline.withDelay(Duration.Beats(n)),
Timeline.atEndOf(Beat.Lead, Beat.TurnOne, Duration.Seconds(0.0)) |> Timeline.withDelay(Duration.Beats(0.0 - n))
// 後: 1 行（組んだ時刻はビットまで同じ）
Timeline.append(Beat.TurnOne, Duration.Seconds(0.0)) |> Timeline.withDelay(Duration.ToPickup(n))
```

`Duration` を網羅の `match` で読んでいるゲームは、case が 1 つ増えるので型検査で止まる（`ToNextBar` と同じ扱いでよい）。
