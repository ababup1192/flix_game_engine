自動生成の一覧は [0.45.0.auto.md](0.45.0.auto.md)。設計のメモは [design-trace-and-events.md](../design-trace-and-events.md)。

画面なしで実機と同じ経路を流す `App.trace` と性質テストの `PropertyTest`、規則の出来事を出す `Emit`、
起点から測る `Timeline.soundsSince` / `progressSince`、番号で選ぶ `Hash01.indexOf` / `pickBy` を足した。
どれも足しただけで、今ある API の型は変えていない。

## ゲームで直す物

1. **何もしなくても今までどおり動く**。
2. World に「このフレームの出来事」の欄を置いて毎フレーム置き換え、audio がそれを読んでいるゲームで、
   `App.withFixedStep` を使っているなら直す（刻みが 0 回のフレームに前の音がもう一度鳴る・2 回以上のフレームは
   前の刻みの出来事が消える）。欄を `Emit.Events[Event]` に替え、系は `Emit.collectInto`・audio は `Emit.since` で読む（下）。
3. 雛形を写して作ったゲーム（tetris-starter・novel-starter）は、雛形と同じ形へ寄せると性質テストの手本がそのまま使える
   （寄せなくても動く）。

## 新しく使える物

### 規則の出来事で鳴らす（`Emit`）

```flix
def lock(w: World): World \ Emit[Event] = { Emit.emit(Event.Locked); ... }
def update(f: App.Frame, w: World): World =
    let (next, events) = Emit.collectInto(() -> rules(f, w), w#events);
    { events = events | next }
app |> App.addSystem(update)
    |> App.withAudio(ws -> Emit.since(ws#before#events, ws#after#events) |> List.map(soundName))
```

- World の初期値は `events = Emit.empty()`。規則を直に呼ぶテストは `Emit.collect(() -> …)` で包む（出来事の列が隣に出る）。
- 制限（Flix 0.78.0）: 1 つの関数の中で Emit を 2 つの型に使えない（E6795）。

### 性質テスト（`PropertyTest` + `App.trace`）

```flix
let cases = { seeds = 12, length = 600, spec = { taps = List#{Role.Left, Role.Drop}, idle = 4 | PropertyTest.emptySpec() } };
let rule = (step: App.TraceStep[World]) -> if (決まりが保たれている) None else Some("説明");
Assert.assertEq(expected = None, PropertyTest.forAll(app, setup, cases, start, rule))
```

- `Setup` = `{ keyOf = (役, World) -> Key, viewport, dt }`。入力は `Input`（Idle・Tap・Hold・Release・Move・Press・Drag・Up・Wheel）。
- 崩れたら「seed 3・120 フレーム目（入力 98 個目）: 説明」が返る。列そのものは `generate`・崩れた所は `firstBroken`・全フレームは `traceOf`。
- 決まりは数が保たれる形で書き、空振りでないことを確かめるテストを 1 本添える（手本は雛形の `test/TestTrace.flix`）。

### 起点から測る時刻表（`Timeline.soundsSince` / `progressSince`）

途中で始まる演出（起点の時刻を World に持つ）の音を `soundsSince(起点, ws#before#t, ws#after#t, 表)`、
描く側の進みを `progressSince(起点, w#t, タグ, 表)` で同じ表から引く。待ちの無い表に限る（soundsBetween と同じ）。

### 番号で選ぶ（`Hash01.indexOf` / `pickBy`）

`Hash01.pickBy({ index = 敵の番号, channel = 0 }, 技の列)` は同じ番号なら毎回同じ 1 つ（空なら None）。乱数の状態を持たない。

## 雛形の変化

- tetris-starter・novel-starter: 規則が出来事を出し、音は出来事から導く。`test/TestTrace.flix` に性質テスト。
  音の案は台本 `art/sfx.snd.star`（`bin/fge snd build` で `atelier/sfx/` へ）。採用して project.json の `sounds` に載せるまでは
  鳴らすと名前ごとに 1 回 warn が出るだけ。
- novel-starter: 疑って灯りが消えるとき、炎が 0.5 秒細ってから消える（`src/LampFx.flix` の時刻表を音と絵が読む）。
  消せる灯りが残っていない疑いでは、演出も音も出ない。
