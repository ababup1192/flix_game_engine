# engine 0.112.0 → 0.113.0 の手当て

（手書きの節。版を上げる時に変わった所を足す。）

## 動かない物の集まりを先に作る（withPreload3d の groups・scenes）と進み具合

`App.withPreload3d` に groups（集まり）と scenes（描く場面）を渡すと、描かずに先に作る。済んだかは View で
`Scene3d.isPreloaded(ctx#preload3d)` を見る。済むまでは集まりを groups に載せず、暗転などを描く（手本は docs/scene3d.md）。
作り直した集まりは、前の控えを描きながら 1 コマ 8 ms ずつ作るようになった（items の値が替わった時だけ）。

| 直す所 | 前 | 後 |
|---|---|---|
| テストで `Platform.Draw3d` の handler を自分で書いている `preload3d` | `k(())` | `k(Scene3d.noPreload())` |
| テストで ViewCtx を全部の欄で作っている所 | — | `preload3d = Scene3d.noPreload()` を足す |
| `App.Preload3d` / `Scene3d.PreloadCmd` を全部の欄で作っている所 | — | `groups = _ -> Nil, scenes = _ -> Nil` を足す |
| `ImageData.ImageDecoder` を自分で作っている所 | — | `platformImageOfBytes = _ -> None` を足す（デスクトップは画素へ戻す道のまま） |

## 絵つきの glb を key から読む

`Gltf.fromGlbTexturedKeyedUsingOptions` を足した。key（`decoder#versionedKey(道)`）を渡すと形の SHA-256 を取らず、
ブラウザでは glb の中の絵を画素へ戻さず GPU へ上げる。key が None の時は今までの関数を呼ぶ。
