# engine 0.35.23 → 0.35.24 の手当て

自動生成の一覧は [0.35.24.auto.md](0.35.24.auto.md)。古い z の書き方を消したか `ZLegacy` へ移した。
上げたあと `make check` が「名前が無い」で止まった所を、下の表の左の列で引いて右へ置き換える。
lint（forbid の `depth-place`・z-table の付け替えと移行の口）は型検査が止めるので外した。
ゲームの `bin/lint-rules/z-table.local.json` に `パス::zShiftedAll` / `パス::SortingLayer.z` /
`パス::leafAbsolute` / `パス::zMapped` などの除外があれば消す。`bin/lint-rules/forbid.local.json` の
`パス::depth-place` も消す（どちらも、もう見ないので残すと古い除外として止まる）。

新しい forbid の規則が 2 つ: `zlegacy`（ゲームから `ZLegacy.` を呼ぶと止まる。残すなら forbid.local.json の exempt に
`"パス::zlegacy"` と「なぜ木で書けないか」を 1 行）と `engine-internal`（ゲームから `EngineInternal.` を呼ぶと止まる）。
z-table.local.json に書いていた理由は、forbid.local.json の `パス::zlegacy` へ移す。

## ZLegacy について

`ZLegacy` は「z の数を直に書く古い書き方」を 1 か所に集めた名前。Flix 0.77.0 の `@Deprecated` は呼んでも警告を
出さないので、印は付けたうえで、古い書き方であることを名前で表している。呼ぶ所は forbid の `zlegacy` が止めるので、除外に「なぜ木で書けないか」を 1 行書く。
エンジンの中だけで使う z の書き換え（`SortingLayer.compose`・`App.composeScene`・`UiRender`）は `EngineInternal.zMapped`
にある。ゲームからは呼ばない。
