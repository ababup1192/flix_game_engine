# engine 0.116.x → 0.117.0 の手当て

（手書きの節。版を上げる時に変わった所を足す。）

## `HeadlessLoad.imageIoDecoder` は `HeadlessLoad.stbDecoder` へ改名した（engine_tools）

画面なしの絵の読み込みも、実機の窓（LwjglLoad）と同じ stb_image で解くようになった。テストや描き出しの入口で
`HeadlessLoad.imageIoDecoder` を名指ししている所だけ `HeadlessLoad.stbDecoder` へ替える（引数と返す型は同じ）。
古い名前は lint-forbid の `headless-imageio-decoder` が止めて代わりを出す。`HeadlessLoad.handle` で張っているだけのゲームは直す所は無い。

JPEG の画素は ImageIO の時と少し違う（同じ版どうしでは決まった値）。glb の中の JPEG を CPU で描き出して基準の絵を持っているゲームは、
`make reference-update` で撮り直す。PNG は画素も同じ。

## デスクトップの絵の読み込みが stb_image になった（render_gl）

glb の中の絵を LwjglLoad が stb で解く。ゲームのコードは変えない。絵の多い場面の起動が縮む（Bistro の glb の読み込み 10.6 → 7.0 秒）。

## 窓なしの描き出し・テープの比べ・常駐の JVM が SerialGC になった

`bin/headless-run` の窓なしの道と常駐は `-XX:+UseSerialGC` で起きる。並べて流してもメモリが溢れにくい。ゲームのコードは変えない。
窓ありの `make run` は今までどおり。自分の旗を足すのは `HEADLESS_JAVA_OPTS`（後ろが勝つ）。

## 自前の 2D の剛体の物理が入った（engine_world・engine/src/core）

新しい口: `PhysicsWorld2d`・`RigidBody2d`・`Collider2d`・`PhysicsMaterial`・`CollisionEvent2d`・`SensorEvent2d`・`PhysicsDoc2d`（engine_world）と、
`Rot2`・`PortableMath`・`StateHash`（engine/src/core）。App は `App.addPhysics2d` で物理を固定刻みで回す（使い方は docs/physics.md）。
使わないゲームは直す所は無い（呼ばなければ 1 コマの仕事もブラウザ版の大きさも増えない）。今の `Physics2D`・`CollisionShape2D` はそのまま並ぶ。

自分で作っている所だけ直す物:

- `App.ViewCtx` に欄 `fixedAlpha`・`physicsAlpha`（Float64）が増えた。ViewCtx を字で全部の欄を書いて組んでいるテストは `fixedAlpha = 0.0, physicsAlpha = 0.0` を足す
  （`App.viewCtxOf` か `{ 欄 = 値 | App.pickCtx(design) }` の形なら直す所は無い）。
- `App.StepState` に欄 `physicsCarry`（Int64）が増えた。字で組んでいる所は `physicsCarry = 0i64` を足す（`App.freshStepState()` なら直す所は無い）。

新しい lint: `physics-step-direct`（ゲームが `PhysicsWorld2d.step` を呼ぶと止める）・`physics-portable-math`（engine の物理のファイルの三角関数）・
`rot2-from-num`（`Rot2.fromCosSin(Num.` を知らせるだけ）。`app-internal` は `PhysicsWorld2d.Internal` も止める。
