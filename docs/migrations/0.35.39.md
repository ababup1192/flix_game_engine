## 1. `$(HEADLESS_RUN)` で流す時に java の旗を足せる（`HEADLESS_JAVA_OPTS`）

描き出しでない長い計算（バランスのシミュレーション・ラボなど）も `$(HEADLESS_RUN) 入口` で流すと、
描き出しと同じ jar（`build/headless/headless.jar`）を使い回すので、src が変わった後の 1 回しかコンパイルしない。
深い再帰でスタックが足りない口は、旗を前に置いて足す（既定の `-Xss32m` の後ろに付くので上書きになる）:

```make
LAB_RUN = LAB_RUNS=$(LAB_RUNS) HEADLESS_JAVA_OPTS=-Xss64m $(HEADLESS_RUN) BalanceLab.main
```

口ごとに `flix build-fatjar` で別の jar（例: `build/lab.jar`）を作っていたなら、その規則を消して
`$(HEADLESS_RUN)` へ寄せると、jar 作りが 1 回にまとまる。旗が効くのは jar から流す時だけで、
入口を拾えずに `flix run` へ回った時は `bin/flix` の旗のまま。
