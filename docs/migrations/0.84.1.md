# engine 0.84.0 → 0.84.1 の手当て

## ゲームで直す物

| 直す所 | 直し方 | 止める物 |
|---|---|---|
| `App.ViewCtx` をレコードの字で組んでいる所（テストの `quiet()` など） | 欄 `diagnostics = None` を足す（パッチ版だが、ここはコンパイルが止まる）。`{ warnOnce = … \| App.viewCtxOf(…) }` のように既存の ctx から作り直している所は直さなくてよい | コンパイル |
| 系で `frame#diagnostics` を World へ写し、View で `w#diagnostics` を描いている所 | 写すのをやめ、View か HUD で `ctx#diagnostics` から描く（下の例）。World には出すかどうかの切り替え（F3 で開け閉めする `Bool` など）だけを置く | `frame-diagnostics-in-system`（lint-forbid） |

0.84.0 で、系が `frame#diagnostics` を読んで World へ写すのを lint-forbid が止めるようにした（遊んだ記録に残らず、再生と食い違うため）。
ただ View と HUD には診断を読む口が無く、F3 の行を描くゲームは World へ写すしか道が無かった。0.84.1 で `ViewCtx#diagnostics` を足して、その道を開けた。

```flix
// Main（か Game.app）: 診断を集める宣言は今までどおり
app |> App.withDiagnostics

// World: 出すかどうかだけ（F3 で反転）。診断の値そのものは持たない
pub def update(frame: App.Frame, w: World): World =
    if (App.justPressed(GameEngine.Key.F3, frame)) { showDiagnostics = not w#showDiagnostics | w } else w

// View（か hudView）: ctx から読んで描く
def diagnosticsLines(ctx: App.ViewCtx, w: World): List[String] =
    if (not w#showDiagnostics) Nil
    else ctx#diagnostics |> Option.map(FrameDiagnostics.summaryLines) |> Option.getWithDefault(Nil)
```

lint-forbid の `frame-diagnostics-in-system` は `ctx#diagnostics` だけを見逃す。ViewCtx を受ける引数の名前は `ctx` にする（`c#diagnostics` などは系の読みと見分けられないので止まる）。逆に、系で Frame を `ctx` と名付けない（`ctx#diagnostics` と書くと lint をすり抜け、再生と食い違う）。

## 絵とふるまい

**変わらない**。テンプレの reference・ギャラリー・gl-parity の行と絵・実機の GL の絵（gl-capture）は前の版と同じ。

## 足した物

- `App.ViewCtx#diagnostics: Option[FrameDiagnostics.Diagnostics]`: 前のフレームを描いた診断（CPU・GPU の時間・3D の数）。
  実機で `App.withDiagnostics` を宣言した間だけ `Some`（F8 で止めている間は止める前の値）。宣言していない時・画面なしの描き出し（`App.viewCtxOf`・`App.viewCtxOfFonts`）・`App.pickCtx` では `None`。
  view・hudView・視差レイヤ（`App.addParallaxLayer`）のどれにも同じ値が入る
- `App.buildSceneItems(app, design, base, world, toItems)`: 実機が 1 コマの絵を組む所の、窓の要らない側。`base` の `visible` だけを層ごとに置き換え、ほかの欄はそのまま view・hudView・視差レイヤへ渡す。
  テストで「この ctx から組むと何が出るか」を窓なしで確かめる時に使う

## 気をつける事

- F8 のリモートの `/scene`（`App.RemoteDebug` の当たりの一覧）と、窓なしで GPU に塗る 1 枚撮り・`/perf` の塗り直しでは `ctx#diagnostics` は `None`。F3 の行を出すかどうかで当たりの一覧が変わるゲームは、実機の画面と一覧が 1 行ぶん食い違う
