# engine 0.101.0 → 0.102.0 の手当て

（手書きの節。版を上げる時に変わった所を足す。）

## 点光源が 8 本を超えた時の選び方（`Scene3d.pickLights`）

| 何が | どう |
|---|---|
| 選び方 | 目に近い 8 本 → range の球が画面に掛かる光から、画面の真ん中に近い 8 本。range か intensity が 0 以下の光は枠を取らない（engine の `docs/scene3d.md` の「点光源」） |
| 強さ | 7・8 番目の光は 9 番目へ向けて暗くなる（入れ替わりでぱっと点いたり消えたりしない）。8 本以下の場面は何も変わらない |
| `Scene3d.pickLights(eye, cmd)` | `Scene3d.pickLights(cmd)` に（目は `cmd#camera` から読む）。ゲームが呼ぶ口ではないが、呼んでいたら目の引数を消す |
| 新しい口 | `Frustum.sphereInsideRatio(frustum, center, radius)`（球が視錐台へ入っている度合い 0〜1） |
| ゲームの手当て | 無い。ゲームの側で 8 本を選び直していたら、選び直しを消して全部 `pointLights` に入れる |

## 時刻表（`Timeline.Timeline`）を外から組み立て・分解できなくした

| 何が | どう |
|---|---|
| `Timeline.Timeline[a]` | 中身を隠した型に（`pub type alias`）。`Timeline.Timeline.Timeline({..})` で組む・match で中を開く書き方は E0459 で止まる。作るのは `Timeline.build` / `buildOrPanic`、読むのは `clipOf`・`clipsOf`・`endOf` などの口 |
| `Timeline.buildOrBug` | 消した（0.35.38 から旧名）。`Timeline.buildOrPanic` に（引数は同じ） |
| ゲームの手当て | 無い（呼び手 0 を確かめた）。forbid の deprecated-name に当たっていたら名前を替える |

## 作る関数と既定値の関数を足した（光・後がけ）

| 何が | どう |
|---|---|
| `Scene3d.pointLight(position, range)` | 白・intensity 1 の点光源。`{ intensity = 2.0 \| Scene3d.pointLight(p, 6.0) }` の形で書く（`PointLight` の欄を字で全部書かない） |
| `PostStack.bloom()`・`vignette()`・`colorGrade()`・`distortion()`・`heightFog()`・`fogNoise()` | 効果ごとの既定値（post.json で効果の欄を書いた時の出発点と同じ値）。`{ density = 0.05 \| PostStack.heightFog() }` の形で書く |
| intensity の doc | `PointLight`・`SpotLight`・`DirectionalLight` の intensity を、Legacy（倍率）と Physical（点・スポットは 1 m の所の照度 = cd・太陽は lux）の両方で書き直した。値の意味は変わっていない |
| ゲームの手当て | 無い。欄を字で全部書いている所は、次に欄が増える前に作る関数の形へ替えておく |

## 3D の診断にビルボードの行の数を足した（`FrameDiagnostics.Scene3dCounts`）

| 何が | どう |
|---|---|
| `Scene3dCounts` | 欄 `billboardRuns`（場面の pass のビルボードの行 = 来た順で続く同じ絵の板の並びの数）・`billboardImages`（その行が貼る絵の種類の数）を足した。`summaryLines` の 3D の行に「billboard runs N / images M」 |
| 作る関数 | `FrameDiagnostics.emptyScene3dCounts()`（`{ instances = 3 \| FrameDiagnostics.emptyScene3dCounts() }`）。字で全部の欄を書いているテストは止まるので、この形へ替える |
| 知らせ | 置いた物が 2,000 個を超え groups（staticGroup）の無い場面が 120 回続くと 1 回「動かない物は staticGroup に」 |

## CPU の光の開発用の口を 1 本に（`SoftRaster3d.lightAt`）

| 何が | どう |
|---|---|
| `SoftRaster3d.lightAt(env, points, spots, p, n)`・`lightWithUnitsAt`・`lightWithSunAt` | `SoftRaster3d.lightAt(probe, p, n)` 1 本に。材料は `SoftRaster3d.lightProbe(env, points, spots)`（Legacy・unitsPerMeter 1・太陽なし）を `{ units = .., unitsPerMeter = .., sun = Some({ toward, color, lit }) \| .. }` で替える |
| ゲームの手当て | 無い（engine の開発用の口。呼び手は engine_tools のテストと bench/gl_parity だけ） |

## 影の重さを端末の区分で・先に上げる宣言で変種のプログラムも組む

| 何が | どう |
|---|---|
| `Scene3d.pointShadowMapFor(sizeClass)`・`Scene3d.directionalShadowFor(sizeClass)` | 端末の区分ごとの影の既定値（Small = 点光源の影 1 本・256 / 太陽 1024・Medium = 2 本・512 / 2048・Large = 4 本・512 / 2048）。`pointShadowMap()`・`directionalShadow()` は Large の値のまま |
| `App.withPreload3d` の宣言 | 型 `App.Preload3d[w]` に欄 `variants`（`w -> List[Scene3d.PreloadVariant]`）を足した。作る関数 `App.preload3d(key, instances)`（textures と variants は空）を添えた。`{ textures = .., variants = w -> Scene3d.preloadVariantOf(場面) :: Nil \| App.preload3d(key, instances) }` の形で書く |
| `Scene3d.PreloadCmd` | 欄 `variants` を足した。作る関数 `Scene3d.preloadCmd(key, instances)`（描き手のテストが組む形） |
| ゲームの手当て | `withPreload3d({ key = .., instances = .., textures = .. })` と字で全部の欄を書いた所は止まる。`{ textures = .. \| App.preload3d(key, instances) }` に替える |
## カメラの写す範囲をずらす（`Camera3d.lensShift`）・閉じたレコードに欄が増えた

`Camera3d.Camera3d`・`Scene3d.Scene3dCmd` は閉じたレコード。欄を足したので、**レコードを丸ごと書いているゲームはコンパイルが通らなくなる**。

| 何が | どう |
|---|---|
| `Camera3d.Camera3d` に `lensShift = Vec2.Vec2` | 写す範囲を画面の上下左右へずらす（Unity の Lens Shift・Blender の Shift X/Y）。単位は画面の幅と高さに対する比で、既定は `Vec2.zero()`。水平のカメラで y を負にすると、縦の線は平行のまま地面だけ奥へすぼまる（HD-2D の町のカメラ） |
| `Scene3d.Scene3dCmd` に `pointShadows = Option[Scene3d.PointShadowMap]`・`lightUnits = Scene3d.LightUnits` | 点光源の影（`Scene3d.withPointShadows`）と光の量の読み方（`Scene3d.withLightUnits`・既定は `Legacy`） |
| ゲームの手当て | `{ eye = …, yaw = …, pitch = …, fovY = …, near = …, far = … }` のように Camera3d を丸ごと書いていたら `lensShift = Vec2.zero()` を足すか、`{ near = …, far = … \| Camera3d.camera(eye, yaw, pitch, fovY) }` の形にする（今の見え方のまま）。Scene3dCmd を丸ごと書いていたら `pointShadows = None, lightUnits = Scene3d.LightUnits.Legacy` を足すか、`{ … \| Scene3d.scene(camera, size) }` の形にする。`{ … \| Camera3d.camera(..) }`・`{ … \| Scene3d.scene(..) }` で替えているゲームは何も要らない |
| ビルボード | 読む口の `Scene3d.billboardFieldsOf` の返す欄に `shadowCasterScale`（`Scene3d.withShadowCasterScale` の値・既定 (1, 1)）が増えた。欄を丸ごと書いて作っていなければ手当ては無い |

## この版で増えた口（手当ては無い・使う時に engine の docs を見る）

| 口 | 中身 |
|---|---|
| `Scene3d.withLightUnits(Scene3d.LightUnits.Physical, 場面)` | 光の量を物理の形で読む（逆二乗・拡散の 1/π）。今の値のままだと拡散が暗くなるので、使う時は intensity と ambient を決め直す |
| `Scene3d.withPointShadows(Scene3d.pointShadowMap(), 場面)` | 点光源の影（6 面の atlas・`maxShadowedLights` で本数を絞る） |
| `Scene3d.withShadowCasterScale(Vec2.v2(幅, 高さ), 板)` | ビルボードの影の板だけを細く短くする（見えている板は変えない） |
| `PostStack.withHeightFog(Some(…))` | 地面を這う高さの霧（Unreal の Exponential Height Fog と同じ式・街灯のにじみ・流れるむら） |
| `PostStack.DistortionMask.Texture(名前)` | 画面の歪みを掛ける範囲を、project.json の絵か Pass（`PostStack.withCustom` で足した型紙の Pass）の r で決める |
| project.json の `web.virtualPad.stick` | ブラウザ版のスマホの画面のスティック。値は実機のパッドと同じ `frame#leftStick` に入る |
| ビルボードの instanced draw | GL と WebGPU の描き手は、来た順で続く同じ絵の板を 1 回の draw で描く（ゲームの手当ては無い。draw を減らすなら同じ絵の板を続けて並べる） |
| `templates/hd2d-starter` | 5 本目のテンプレート（タイルの地図から組んだ立体の町を、ドット絵の 3 人で歩き回る HD-2D の町）。`make new-game TEMPLATE=hd2d-starter` |
