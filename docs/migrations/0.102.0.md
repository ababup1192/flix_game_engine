# engine 0.101.0 → 0.102.0 の手当て

（手書きの節。版を上げる時に変わった所を足す。）

## 点光源が 8 本を超えた時の選び方（`Scene3d.pickLights`）

| 何が | どう |
|---|---|
| 選び方 | 目に近い 8 本 → range の球が画面に掛かる光から、画面の真ん中に近い 8 本。range か intensity が 0 以下の光は枠を取らない（engine の `docs/scene3d.md` の「点光源」） |
| 強さ | 7・8 番目の光は 9 番目へ向けて暗くなる（入れ替わりでぱっと点いたり消えたりしない）。8 本以下の場面は何も変わらない |
| `Scene3d.pickLights(eye, cmd)` | `Scene3d.pickLights(cmd)` に（目は `cmd#camera` から読む）。ゲームが呼ぶ口ではないが、呼んでいたら目の引数を消す |
| 新しい口 | `Frustum.sphereInsideRatio(frustum, center, radius)`（球が視錐台へ入っている度合い 0〜1） |
| ゲームの手当て | 無い。ゲームの側で 8 本を選び直していたら、選び直しを消して全部 `pointLights` に入れる |

## 0.101.0 から外のゲームを壊す変更（型の欄・enum の case・引数）

確かめ方: `git diff v0.101.0` と `bin/fge migration-notes --from v0.101.0` の出力。どれもコンパイルエラーで出るので、出た所だけ直せばよい。

| 何が | どう壊れる | 手当て |
|---|---|---|
| `Camera3d.Camera3d` に `lensShift = Vec2.Vec2` | 欄を全部字で書いたカメラ（`{ eye = …, far = 100.0 }`）がコンパイルできない | `Camera3d.camera(eye, yaw, pitch, fovY)`（near 0.1・far 100・lensShift 0）から `{ far = 60.0 \| Camera3d.camera(…) }` の形で作る。字で書き続けるなら `lensShift = Vec2.zero()` を足す |
| `Scene3d.Scene3dCmd` に `pointShadows = Option[PointShadowMap]`・`lightUnits = LightUnits` | 場面を字で全部書いた所がコンパイルできない | `{ instances = … \| Scene3d.scene(camera, size) }` の形で作る（既定は影なし・`LightUnits.Legacy` で、今までの絵と同じ）。字で書くなら `pointShadows = None, lightUnits = Scene3d.LightUnits.Legacy` を足す |
| `Scene3d.BillboardFields` に `shadowCasterScale = Vec2.Vec2` | `BillboardFields` を字で組み立てた所（テストの期待値など）がコンパイルできない | `Scene3d.billboard(…)` で作る（既定 `Vec2.one()`）。影の大きさを替えるのは `Scene3d.withShadowCasterScale` |
| `LightModel3d.ScalarInput` に `PointShadowLit`・`PhysicalUnits`・`InverseUnitsPerMeterSquared` | `ScalarInput` を網羅して `match` している所が Non-exhaustive match になる | 3 つの case を足す（自分で式を評価しているなら `PointShadowLit` は 1・`PhysicalUnits` は 0・`InverseUnitsPerMeterSquared` は 1 で今までと同じ値） |
| `SoftRaster3d.ShadowMaps.BillboardCasters` の `casters` が `(BillboardFields, TexData, Vec3)` の 3 要素 | 2 要素の tuple で組み立て・分解している所がコンパイルできない | 3 つ目に板の横の向きを入れる（今までと同じ絵なら `Scene3d.billboardShadowRightOfScene(scene)`） |
| `SoftRaster3dLight.lightAt`・`lightmapLightAt`・`pbrAt` に引数 | 4 番目に `pointLit: Vector[Float64]`、末尾に `physicalUnits`・`inverseUnitsPerMeterSquared` が増えた | 影なしで今までと同じ値なら `Vector.repeat(Scene3d.maxPointLights(), 1.0)` と、末尾に `0.0, 1.0` を渡す |
| `LightModel3d.lightingModel()`・`lightmapLightingModel()`・`pbrModel()` | 壊れない（Legacy・点光源の影なしの変種の木を返す） | 変種を選ぶなら `lightingModelFor(LightModel3d.variantOf(scene))` など |
| `PostStack` の `Distortion`・`HeightFog` | 壊れない（新しい型と `withDistortion`・`withHeightFog`・`withTime`。post.json に `distortion`・`heightFog` の欄が増えたが、書かなければ今まで通り） | 無い |
