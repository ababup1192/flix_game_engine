# engine 0.101.0 → 0.102.0 の手当て

（手書きの節。版を上げる時に変わった所を足す。）

## 0.101.0 から外のゲームを壊す変更（型の欄・enum の case・引数・隠した型）

確かめ方: `git diff v0.101.0` と `bin/fge migration-notes --from v0.101.0` の出力。どれもコンパイルエラーで出るので、出た所だけ直せばよい。
欄を字で全部書かず、作る関数（`Camera3d.camera`・`Scene3d.scene`・`App.preload3d` など）から `{ 欄 = .. | 作る関数(..) }` の形で書いているゲームは、下の表のほとんどで何も要らない。

| 何が | どう壊れる | 手当て |
|---|---|---|
| `Camera3d.Camera3d` に `lensShift = Vec2.Vec2` | 欄を全部字で書いたカメラ（`{ eye = …, yaw = …, pitch = …, fovY = …, near = …, far = … }`）がコンパイルできない | `{ far = 60.0 \| Camera3d.camera(eye, yaw, pitch, fovY) }`（near 0.1・far 100・lensShift 0）の形で作る。字で書き続けるなら `lensShift = Vec2.zero()` を足す（今の見え方のまま） |
| `Scene3d.Scene3dCmd` に `pointShadows = Option[Scene3d.PointShadowMap]`・`lightUnits = Scene3d.LightUnits` | 場面を字で全部書いた所がコンパイルできない | `{ instances = … \| Scene3d.scene(camera, size) }` の形で作る（既定は影なし・`LightUnits.Legacy` で、今までの絵と同じ）。字で書くなら `pointShadows = None, lightUnits = Scene3d.LightUnits.Legacy` を足す |
| `Scene3d.BillboardFields` に `shadowCasterScale = Vec2.Vec2` | `BillboardFields` を字で組み立てた所（テストの期待値など）がコンパイルできない。読む口 `Scene3d.billboardFieldsOf` の返す欄にも増えた | `Scene3d.billboard(…)` で作る（既定 `Vec2.one()`）。影の大きさを替えるのは `Scene3d.withShadowCasterScale` |
| `App.Preload3d[w]` に `variants`（`w -> List[Scene3d.PreloadVariant]`）・`Scene3d.PreloadCmd` に `variants` | `withPreload3d({ key = .., instances = .., textures = .. })` と字で全部の欄を書いた所がコンパイルできない | `{ textures = .. \| App.preload3d(key, instances) }` の形で作る（textures と variants は空）。描き手のテストが組む `PreloadCmd` は `Scene3d.preloadCmd(key, instances)` |
| `FrameDiagnostics.Scene3dCounts` に `billboardRuns`・`billboardImages` | 字で全部の欄を書いているテストがコンパイルできない | `{ instances = 3 \| FrameDiagnostics.emptyScene3dCounts() }` の形で作る |
| `Timeline.Timeline[a]` を隠した型に（`pub type alias`） | `Timeline.Timeline.Timeline({..})` で組む・match で中を開く書き方が E0459 で止まる | 作るのは `Timeline.build` / `buildOrPanic`、読むのは `clipOf`・`clipsOf`・`endOf` などの口（engine の外の呼び手 0 を確かめた） |
| `Timeline.buildOrBug` を消した（0.35.38 から旧名） | Undefined name | `Timeline.buildOrPanic` に（引数は同じ。forbid の deprecated-name にも当たる） |
| `LightModel3d.ScalarInput` に `PointShadowLit`・`PhysicalUnits`・`InverseUnitsPerMeterSquared` | `ScalarInput` を網羅して `match` している所が Non-exhaustive match になる | 3 つの case を足す（自分で式を評価しているなら `PointShadowLit` は 1・`PhysicalUnits` は 0・`InverseUnitsPerMeterSquared` は 1 で今までと同じ値） |
| `SoftRaster3d.ShadowMaps.BillboardCasters` の `casters` が `(BillboardFields, TexData, Vec3)` の 3 要素 | 2 要素の tuple で組み立て・分解している所がコンパイルできない | 3 つ目に板の横の向きを入れる（今までと同じ絵なら `Scene3d.billboardShadowRightOfScene(scene)`） |
| `SoftRaster3dLight.lightAt`・`lightmapLightAt`・`pbrAt` に引数 | 4 番目に `pointLit: Vector[Float64]`、末尾に `physicalUnits`・`inverseUnitsPerMeterSquared` が増えた | 影なしで今までと同じ値なら `Vector.repeat(Scene3d.maxPointLights(), 1.0)` と、末尾に `0.0, 1.0` を渡す |
| `SoftRaster3d.lightAt(env, points, spots, p, n)`・`lightWithUnitsAt`・`lightWithSunAt`（CPU の光の開発用の口） | 3 本を `SoftRaster3d.lightAt(probe, p, n)` 1 本にした | 材料は `SoftRaster3d.lightProbe(env, points, spots)`（Legacy・unitsPerMeter 1・太陽なし）を `{ units = .., unitsPerMeter = .., sun = Some({ toward, color, lit }) \| .. }` で替える（呼び手は engine_tools のテストと bench/gl_parity だけ） |
| `Scene3d.pickLights(eye, cmd)` | `Scene3d.pickLights(cmd)` に（目は `cmd#camera` から読む） | ゲームが呼ぶ口ではないが、呼んでいたら目の引数を消す |

壊れない物: `LightModel3d.lightingModel()`・`lightmapLightingModel()`・`pbrModel()`（Legacy・点光源の影なしの変種の木を返す。変種を選ぶなら `lightingModelFor(LightModel3d.variantOf(scene))` など）、`PostStack` の `Distortion`・`HeightFog`（post.json に `distortion`・`heightFog` の欄が増えたが、書かなければ今まで通り）。

## 点光源が 8 本を超えた時の選び方（`Scene3d.pickLights`）

| 何が | どう |
|---|---|
| 選び方 | 目に近い 8 本 → range の球が画面に掛かる光から、画面の真ん中に近い 8 本。range か intensity が 0 以下の光は枠を取らない（engine の `docs/scene3d.md` の「点光源」） |
| 強さ | 7・8 番目の光は 9 番目へ向けて暗くなる（入れ替わりでぱっと点いたり消えたりしない）。8 本以下の場面は何も変わらない |
| ゲームの手当て | 無い。ゲームの側で 8 本を選び直していたら、選び直しを消して全部 `pointLights` に入れる |

## この版で増えた口（手当ては無い・使う時に engine の docs を見る）

| 口 | 中身 |
|---|---|
| `Scene3d.withLightUnits(Scene3d.LightUnits.Physical, 場面)` | 光の量を物理の形で読む（逆二乗・拡散の 1/π）。今の値のままだと拡散が暗くなるので、使う時は intensity と ambient を決め直す。intensity の doc は Legacy（倍率）と Physical（点・スポットは 1 m の所の照度 = cd・太陽は lux）の両方で書き直した（値の意味は変わっていない） |
| `Scene3d.withPointShadows(Scene3d.pointShadowMap(), 場面)` | 点光源の影（6 面の atlas・`maxShadowedLights` で本数を絞る） |
| `Scene3d.pointShadowMapFor(sizeClass)`・`Scene3d.directionalShadowFor(sizeClass)` | 端末の区分ごとの影の既定値（Small = 点光源の影 1 本・256 / 太陽 1024・Medium = 2 本・512 / 2048・Large = 4 本・512 / 2048）。`pointShadowMap()`・`directionalShadow()` は Large の値のまま |
| `App.preload3d(key, instances)` の `variants` に `Scene3d.preloadVariantOf(場面)` | 点光源の影と Physical の場面の変種のプログラムも先に組む（最初のコマの跳ねを消す） |
| `Scene3d.withShadowCasterScale(Vec2.v2(幅, 高さ), 板)` | ビルボードの影の板だけを細く短くする（見えている板は変えない） |
| `Scene3d.pointLight(position, range)` | 白・intensity 1 の点光源。`{ intensity = 2.0 \| Scene3d.pointLight(p, 6.0) }` の形で書く（`PointLight` の欄を字で全部書かない） |
| `PostStack.bloom()`・`vignette()`・`colorGrade()`・`distortion()`・`heightFog()`・`fogNoise()` | 効果ごとの既定値（post.json で効果の欄を書いた時の出発点と同じ値）。`{ density = 0.05 \| PostStack.heightFog() }` の形で書く。欄を字で全部書いている所は、次に欄が増える前にこの形へ替えておく |
| `PostStack.withHeightFog(Some(…))` | 地面を這う高さの霧（Unreal の Exponential Height Fog と同じ式・街灯のにじみ・流れるむら） |
| `PostStack.DistortionMask.Texture(名前)` | 画面の歪みを掛ける範囲を、project.json の絵か Pass（`PostStack.withCustom` で足した型紙の Pass）の r で決める |
| `Frustum.sphereInsideRatio(frustum, center, radius)` | 球が視錐台へ入っている度合い 0〜1 |
| 3D の診断 `billboard runs N / images M` | `FrameDiagnostics.summaryLines` の 3D の行に、来た順で続く同じ絵の板の並びの数と絵の種類の数。置いた物が 2,000 個を超え groups（staticGroup）の無い場面が 120 回続くと 1 回「動かない物は staticGroup に」と知らせる |
| ビルボードの instanced draw | GL と WebGPU の描き手は、来た順で続く同じ絵の板を 1 回の draw で描く（ゲームの手当ては無い。draw を減らすなら同じ絵の板を続けて並べる） |
| project.json の `web.virtualPad.stick` | ブラウザ版のスマホの画面のスティック。値は実機のパッドと同じ `frame#leftStick` に入る |
| `templates/hd2d-starter` | 5 本目のテンプレート（タイルの地図から組んだ立体の町を、ドット絵の 3 人で歩き回る HD-2D の町）。`make new-game TEMPLATE=hd2d-starter` |
