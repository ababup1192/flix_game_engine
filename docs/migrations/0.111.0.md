# engine 0.110.0 → 0.111.0 の手当て

（手書きの節。版を上げる時に変わった所を足す。）

## ゲームのコードで直す所は無い

この版の変化はどれも道具の側で、`src/` と `test/` は触らなくてよい。

## bin/fge で make 無しに打てる口が増えた（Windows でも同じ形）

| 何が | どう |
|---|---|
| 新しい口 | `bin/fge run`・`render`（`--all`）・`check`・`test`・`task <名前>`・`reference update` / `check`。make を呼ばない |
| 案内の形 | `make status` や `make help`・new-game の最後の案内は、Windows では `bin/fge …`、macOS・Linux では今まで通り `make …` で出す |
| project.json | ゲームの `shots`・`prebuild`・`tasks`・`lint`・`precommit` を読む。`bin/fge task <名前>` は `tasks` の名前で流す |
| Windows | 前提は Git for Windows。make と perl は要らない。PowerShell からは `bin\fge.cmd` |

## ダッシュボード（AI の案を見て選んで返す）

| 何が | どう |
|---|---|
| 人が開く | `make dashboard`（ゲームの頁 `http://127.0.0.1:8790/<名前>/`）。全体の fge から `fge dashboard` でも同じ所が開く |
| AI が見せる | `bin/fge dashboard post <post.json>`（proposal.json の形に `author` を足した物。素材ごと main の作業ツリーの `debug/dashboard/posts/` へ写す。worktree から打っても main 側へ入る） |
| AI が拾う | `bin/fge dashboard inbox` が人の返事（選んだ案・自由文）を `<id>@<at>` つきで出す。直したら `bin/fge dashboard resolve <id>@<at>` |
| 見張り | `make status` に「ダッシュボードに返事 N 件」の 1 行（0 件なら出ない） |
| proposal の頁 | 静的な頁をメールなどで渡す時だけ `fge proposal build`。人に選んでもらうなら dashboard post |

## flixlint 0.9.2

`bin/lint-rules/hooks.json` の flixlint が 0.9.2 になった。初回の `make lint-flixlint`（か pre-commit）で取り直す。
Windows でも lint-flixlint が流れる（0.110.0 までは Windows で飛ばしていた）。

## Studio は凍結

new-game の最後の案内から「Studio で開く」を外し、`make dashboard` の行にした。`reference/title.png` を git に入れる例外はそのまま。
