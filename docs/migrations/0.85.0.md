# engine 0.84.1 → 0.85.0 の手当て

## ゲームで直す物

| 直す所 | 直し方 | 止める物 |
|---|---|---|
| `RenderTexture.loadTextureFromPixels` / `updateTexturePixels` / `deleteTexture` を呼んでいる所（テンプレ・engine_world は呼ばない。bench/texture_upload だけ） | 頭の引数に GL の値を渡す。窓の中で GL の文脈が付いている時に `let gl: GlContext = checked_cast(new LwjglGl())`（`import fge.gl.GlContext`・`import fge.gl.LwjglGl`）を作って渡す（状態を持たないので呼ぶたびに作ってよい） | コンパイル |
| `RenderTexture.loadTexture` / `loadTextureRegistry` を呼んでいる所 | 消えた（画像のデコードは機種ごとの読み込みへ移った）。絵は project.json の `textures` に載せて名前で引く。生成した画素は `Platform.GpuResources.ensureTexture` で上げる | コンパイル |

ほかの pub（`LwjglLayer.withProject`・`ensureMainThread`・`GlOffscreen` の口）の形は変わらない。

## 絵とふるまい

**変わらない**。実機の GL の絵（gl-capture の 9 場面 54 枚）・gl-parity の行と GL の絵は前の版とバイトまで同じ。

- フォントの焼き上がりの取り置き（`~/.cache/flix_game_engine/font`）は、ファイルの長さが書いた形と 1 バイトでも違うと読まずに焼き直す（前は末尾の余りを見なかった）。

## 足した物

- jar `fge-gl-<版>.jar`（render_gl の `[jar-dependencies]`。engine の Release に添える）: render_gl の描き手が呼ぶ GL の関数の集まり `fge.gl.GlContext`（Java の interface）と、
  その LWJGL 版 `LwjglGl`・呼び出しを控える版 `RecordingGl`・定数 `GlConst`。ゲームの flix.toml に書かなくても、engine の依存として取りに行く。
  engine の作業コピーでは `make gl-jar`（`make sync` の前に走る）が組んで各 `lib/external` へ置く。
- `RenderTexture.uploadBytes(gl, { width, height, alpha }, bytes)`（画像のバイト列を上げる）・`RenderTexture.uploadAlphaMask(gl, side, pixels)`（字の距離場を上げる）。デコードと生成は呼ぶ側がする。
- 環境変数 `FLIX_GE_GL_LOG=<ファイル>`（と `FLIX_GE_GL_LOG_FRAMES`・既定 6）: 実機（窓あり・`GlOffscreen`）の GL の呼び出しを起動の分と頭のコマだけ 1 行ずつ控える。
  描き手を直した前後で並びを diff する用。控える間は起動画面を描かない（時刻で間引くので並びが揺れる）。置いていなければふるまいは変わらない。
