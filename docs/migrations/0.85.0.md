# engine 0.84.1 → 0.85.0 の手当て

## ゲームで直す物

| 直す所 | 直し方 | 止める物 |
|---|---|---|
| `RenderTexture.loadTextureFromPixels` / `updateTexturePixels` / `deleteTexture` を呼んでいる所（テンプレ・engine_world は呼ばない。bench/texture_upload だけ） | 頭の引数に GL の値を渡す。窓の中で GL の文脈が付いている時に `let gl: GlContext = checked_cast(new LwjglGl())`（`import fge.gl.GlContext`・`import fge.gl.LwjglGl`）を作って渡す（状態を持たないので呼ぶたびに作ってよい） | コンパイル |
| `RenderTexture.loadTexture` / `loadTextureRegistry` を呼んでいる所 | 消えた（画像のデコードは機種ごとの読み込みへ移った）。絵は project.json の `textures` に載せて名前で引く。生成した画素は `Platform.GpuResources.ensureTexture` で上げる | コンパイル |

| `Platform.Window` の handler を自分で書いている所（テンプレ・ゲームには無い。engine の LwjglLayer・GlOffscreen・WebLayer だけ） | op `getDisplay` を足す。今と同じなら `def getDisplay(k) = k(Display.desktop(design))` | コンパイル |
| `App.Frame` を字で全部の欄を書いて組んでいる所 | 欄 `sizeClass = Display.SizeClass.Large` を足す（`{ … \| App.emptyFrame() }` か `App.frameOf` を通していれば要らない） | コンパイル |
| `App.ViewCtx` を字で全部の欄を書いて組んでいる所 | 欄 `display = Display.desktop(design)` を足す（`App.viewCtxOf` / `viewCtxOfFonts` / `pickCtx` を通していれば要らない） | コンパイル |

ほかの pub（`LwjglLayer.withProject`・`ensureMainThread`・`GlOffscreen` の口）の形は変わらない。

## 絵とふるまい

**変わらない**。実機の GL の絵（gl-capture の 9 場面 54 枚）・gl-parity の行と GL の絵は前の版とバイトまで同じ。

- フォントの焼き上がりの取り置き（`~/.cache/flix_game_engine/font`）は、ファイルの長さが書いた形と 1 バイトでも違うと読まずに焼き直す（前は末尾の余りを見なかった）。

## 足した物

- jar `fge-gl-<ハッシュ>.jar`（render_gl の `[jar-dependencies]`。engine の版の Release でなく、`render_gl/java` の中身のハッシュで名付けた Release `fge-gl-<ハッシュ>` に置く）: render_gl の描き手が呼ぶ GL の関数の集まり `fge.gl.GlContext`（Java の interface）と、
  その LWJGL 版 `LwjglGl`・呼び出しを控える版 `RecordingGl`・定数 `GlConst`。ゲームの flix.toml に書かなくても、engine の依存として取りに行く。
  engine の作業コピーでは `make gl-jar`（`make sync` の前に走る）が組んで各 `lib/external` へ置く（前の名前の `fge-gl-*.jar` は消す）。
- `RenderTexture.uploadBytes(gl, { width, height, alpha }, bytes)`（画像のバイト列を上げる）・`RenderTexture.uploadAlphaMask(gl, side, pixels)`（字の距離場を上げる）。デコードと生成は呼ぶ側がする。
- 環境変数 `FLIX_GE_GL_LOG=<ファイル>`（と `FLIX_GE_GL_LOG_FRAMES`・既定 6）: 実機（窓あり・`GlOffscreen`）の GL の呼び出しを起動の分と頭のコマだけ 1 行ずつ控える。
  描き手を直した前後で並びを diff する用。控える間は起動画面を描かない（時刻で間引くので並びが揺れる）。置いていなければふるまいは変わらない。
- ブラウザ版（PC の Chrome で確かめた・TeaVM 0.14.1 の WASM GC）: `bin/fge export-web <ゲーム> [--check] [--out <dir>] [--font-atlas-dir <dir>]` と、
  その束 engine_full_web（`make sync-engine-full-web`・engine_full と同じ木に engine_web を足した物・デスクトップの engine_full は変わらない）。
  ブラウザの handler は `WebLayer.withProject` / `withWeb`・`WebFs.runFileRead` / `runFileWrite`（セーブは localStorage の `<id>/saves/…`）。
  JS を閉じ込める Java は jar `fge-web-<版>.jar`（`fge.web`）、TeaVM の穴の手当ては `fge-web-tools-<版>.jar`。ゲームは `web/WebMain.flix` を置く（rpg-starter に入れた）。
  まだ engine の Release には添えていない（ゲームのリポジトリから書き出すのは次の版から）。
- 画面の情報 `Display`（engine）: `Display.Display = { size, scaleFactor, designScale, pointer, sizeClass }`・`Display.SizeClass`（`Small` / `Medium` / `Large`・Ren'Py の screen variant と同じ分け方）・
  `Display.PointerKind`（`Mouse` / `Touch`）・`Display.desktop(design)`・`Display.sizeClassOf(coarsePointer, shortSide)`。`Platform.Window.getDisplay()` が返し、
  App が `ViewCtx#display`（全部）と `Frame#sizeClass`（区分だけ）に置く。デスクトップ版はいつも Large・Mouse なので、今の絵とふるまいは変わらない。
  ブラウザ版は主な pointer が指（`pointer: coarse`）で、画面の短い辺が 600 CSS px 未満なら Small・それ以上は Medium（起動の時に決める）。
  頁の `?size=small|medium|large`・`?input=touch|mouse` で PC から確かめられる。
- ブラウザ版のスマホ対応（`engine_web/js`）: project.json の `web` 欄を `bin/fge export-web` が bundle.json へ解く。
  `web.keysDoc`（キーの割り当ての Doc）・`web.virtualPad`（`dpad: true` と `buttons: [{label, action}]`・指の端末だけ十字キーとボタンを重ねて出す・縦持ちは画面の下・横持ちは左右）・
  `web.touchGestures`（`longPress` / `swipeLeft` / `swipeRight` → 操作の名前）・`web.orientation`（`landscape` / `portrait`・指の端末で向きが違えば「画面を横にしてください」）。
  操作の名前はその Doc の 1 本目の知っているキーに解く。知らない操作は書き出しを止める。
- 縦持ちの起動: project.json の `web.portraitDesign: { "width": 540, "minHeight": 960, "maxHeight": 1296 }`（minHeight は width より大きい・maxHeight は任意で既定は width × 2.4 と minHeight の大きい方）を持つゲームは、
  スマホ（指の端末で短い辺が 600 CSS px 未満・区分 Small）を縦に持ってブラウザで開くと縦の design で起動する（幅は width に固定・高さは起動した時の描き先の比から決めて minHeight〜maxHeight に切る・
  描き先は切り欠きとホームバーの内側）。書いていないゲームと、タブレット（Medium）・マウスの端末（PC の窓が縦長でも）は今と同じ横の design。頁の `?orientation=portrait|landscape` で PC から確かめられる。
  遊んでいる途中で回しても作り直さず、起動の時の比のまま帯で合わせる（縦で起動した後に横へ回すと「画面を縦にしてください」が出る）。
  `Display.Orientation`（`Landscape` / `Portrait`）と `Display#orientation`（起動の時に選んだ design の向き・持ち方ではない・`Display.orientationOf(design)`）を足した。
  `ViewCtx#display#orientation` で読み、当たりを取る側は `Display.orientationOf(frame#viewport)` で同じ向きを引く（Frame には足していない）。
  `ProjectLoader.Project#portraitDesign`・`ProjectLoader.PortraitDesign`・`ProjectLoader.portraitDesignOf(spec, view)`・`ProjectLoader.portraitConfigOf(proj, view)`、
  `Display.defaultPortraitView()`（390×844）・`Display.phonePortrait(view, design)`（画面なしの縦の描き出しとテストの Display）。
  デスクトップは横のまま。縦の並べ方を確かめるなら `FLIX_GE_PORTRAIT=1`（または `=390x844`）で起動する（`LwjglLayer.withProject`。録った flow は横で再生されて食い違う）。
  `bin/fge export-web` は `web.portraitDesign` の形（width・minHeight は 1 以上・minHeight は width より大きい・maxHeight は minHeight 以上・`orientation: "landscape"` と一緒に書かない）を検査する。
  手本は sound-novel-starter（縦の画面の並べ方・`novel.portrait.json`・描き出しの `portrait-<場面>`）。
  canvas の上の指は、離した時にその位置のクリック（押した時の位置）・縦のドラッグはホイール（40 CSS px で 1 刻み）。マウスとキーのふるまいは変わらない。
- `bin/fge font-bake <ゲーム> <出力> [--glyphs collected|all|desktop] [--dev-dir <所>]... [--no-gate]`: ブラウザ版へ同梱するフォントアトラスを窓なしで生成する。
  yarn・Doc の文字列の値・src の文字列リテラルの字を集め、project.json の fonts を 1 本ずつデスクトップの起動時と同じアトラスに生成して
  `<出力>/<fonts[].name>.fontatlas`（`RenderFontCache.decode` で読む形）と `<出力>/fonts.json` に書く。どのフォントのアトラスにも無い字があれば、
  字と出所（ファイル:行）を出して 1 で止まる（`src/render`・`src/sim`・`doc = "..."` の行・私用領域の字は知らせるだけ）。生成する入口の jar は
  `<ゲーム>/build/font-bake/` に組んで使い回す。engine 0.85.0 より古いゲームでは生成できない（字を集めるだけの `--collect-only` は流せる）。
- `FontAtlasBake.bakeProject(rootDir, glyphs, outDir)`（`glyphs` は `FontAtlasBake.Glyphs.All` / `DesktopUsed` / `Only(字の集合)`）と `FontAtlasBake.main`（上の道具が呼ぶ入口）。
- ブラウザ版の書き出しの圧縮（`bin/fge export-web`）: 書き出し先の中だけで、絵（png）を WebP（既定は劣化なし・`cwebp -lossless -exact`）、
  音（wav）を WebM の Opus（`ffmpeg` の libopus）、フォントアトラスを gzip に替える。替えた方が大きい物は元のまま。ゲームの assets/ とデスクトップ版は変わらない。
  設定は project.json の `web.compress`（`audio`・`audioBitrateKbps`（ステレオの値・既定 96・モノラルは半分）・`uncompressedAudio: [glob]`・
  `images`・`lossyImages: [{glob, quality}]`（先に書いた方が勝つ））。書いていなければ全部する。道具が無い種類は圧縮せずに書き出し、大きさの表に入れ方を 1 行出す。
  bundle.json に `transcoded`（論理の道 → 配る道）と sounds[] の `seconds`・`loopStart`・`loopEnd`（wav の smpl のループ点・秒）が増え、
  頁は配る道で取って論理の道で表へ入れる。ブラウザ版でも smpl のループ点で回るようになった（前は全体を回していた）。
  Opus を解けないブラウザは隣に残した元の wav を取り直し、それも駄目ならその音だけ鳴らさず起動を続ける。engine の devbox に `libwebp` を足した。
  Studio のフォームに出したいゲームは、templates/*/project.schema.json の `web` の節を自分の project.schema.json へ写す。
- フォントアトラスの辺の選び方 `RenderFont.AtlasSizing`（`Growable` = 今までの 4096/8192・`Tight` = 用意した字が収まる最小の 4 の倍数）と
  `RenderFont.bakeFontCpuSized(sizing, …)`。`FontAtlasBake` は `Tight` で生成する（ブラウザは実行中に字を足さない）。デスクトップの `bakeFontCpu` は `Growable` のままで絵は変わらない。
  詰め方の 1 字ぶんは `RenderFont.shelfPlace`・辺は `RenderFont.tightAtlasSide`。
- `RenderFontCache.encode(baked)`（生成したアトラスをファイルの中身にする）・`RenderFontCache.writeFile(path, bytes)`。キャッシュ（`store`）もこれで書く — 中身は前の版とバイトまで同じ。
