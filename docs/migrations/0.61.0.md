# engine 0.60.1 → 0.61.0 の手当て

**ゲームで直す物は無い。**

## 変わったこと

- **`App.withFullscreen(f: w -> Bool, app)` が増えた。** World から窓 ⇄ 全画面を宣言する。App が起動の拍（world0）と、
  実機・再開のフレームの後に `GameEngine.Game.setFullscreen(f(world))` を当てるので、設定の画面で切り替えればその場で替わる。
  呼ばなければこれまでどおり（App は全画面を触らない）。
- `App.Rec` に `fullscreen = Option[w -> Bool]` が増えた（`0.61.0.auto.md` の「直す物」はこれ）。App は `App.make` などの
  組み立て関数と `App.with*` で作るので、ゲームは触らない。`App.Rec` のレコードを手で組んでいる所だけ `fullscreen = None` を足す。
