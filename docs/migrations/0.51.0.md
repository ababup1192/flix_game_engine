# engine 0.50.0 → 0.51.0 の手当て（下書き）

会話の台本（.yarn）に変数と条件を足した（Yarn Spinner と同じ書き方の部分集合。全文は `bin/fge yarn help`）。

## ゲームで直す物

1. **直さなくても効く所**: 変数も条件も `{式}` も使わない .yarn は、木（dialogue.json）が版 1 のままバイトごと同じに書かれる。組み直しは要らない。
2. `Yarn.Statement` を `case _` なしで match している所は、`Set(name, expr, source)` と `If(branches, source)` の 2 つを足す。
3. **`YarnRunner.Event.Choices` / `Shown.Choices` の中身が `List[Yarn.Line]` から `List[YarnRunner.DialogueOption]`（`{ line, available }`）に変わった**
   （公式と同じく、行末の `<<if>>` が偽の選択肢も `available = false` で並ぶ）。`lines` を受けていた所は `option#line` を読む。
   `Action.Choose(i)` の番号はこの並び（選べない物も数える）で、選べない番号は何も変えない。キーボードのカーソルが
   選べる物だけを数えているなら、番号へ写してから選ぶ（雛形 novel-starter の `World.pickAtCursor`）。
   灰色で見せるか隠すかはゲームが決める（novel-starter は灰色: `UiSlots.Entry` の meta を外し、`labelOff` へ字を移す）。
4. `Yarn.Line` に `parts`、`Yarn.Choice` に `condition` の欄が増えた（読むだけのゲームは直さなくてよい。出来事の Line の `text` は値を差し込んだ後の字）。

## 新しく使える物

| 口 | 中身 |
|---|---|
| `<<declare $x = 値>>`・`<<set $x to 式>>`・`<<if>>`〜`<<endif>>`・`-> 字 <<if 式>>`・`{$x}`・`visited("…")`・`visited_count("…")` | 宣言の無い変数・型の違いは build が行番号つきで止める |
| `YarnRunner.startWith(storage, program, node, now)` | 変数と訪れた数を持ち越して始める |
| `YarnRunner.storageOf` / `withStorage` / `valueOf(name, runner)` | ゲームから読む・書く（書いていなければ初めの値） |
| `YarnStorage.empty` / `get` / `set` / `visitCountOf` / `toJson` / `fromJson` | 変数の置き場・セーブの形 `{"variables": {...}, "visits": {...}}` |
| `YarnRunner.startAtWith(storage, program, node, line, now)` | プレビューで変数の値を決めてその行まで流す（`startAt` は初めの値） |
| `YarnStorage.withArgs(args, program, storage)` | 始まりの引数の `$名前=値` を宣言の型で読む（宣言の無い名前・読めない値は Err） |
| `bin/fge talk shot` / `goto <file.yarn>:<行> '$名前=値'…` | 始まり `talk node= line= $名前=値` を組んで撮る・飛ばす（ゲームの始まり `talk` が withArgs を通す） |
| `YarnRunner.DialogueOption` | 出した選択肢 1 つ `{ line, available }` |
| `Yarn.declarationOf` / `variablesOf` / `toText` | 宣言と値の字 |
