# engine 0.83.0 → 0.84.0 の手当て

## ゲームで直す物（消えた口 → 代わり）

0.77〜0.81 で「0.84.0 で消える」と知らせていた古い口を消した。どれもコンパイルで止まる（project.json の旗だけは lint-forbid が止める）。
古い口を使う所には、0.81 までに lint-forbid が知らせを出していた（`bin/fge forbid --all`。project.json の旗だけは起動の時の 1 行の知らせだった）。

| 消えた口 | 代わり | 知らせていた規則 |
|---|---|---|
| `Vec2.sqrt`・`Vec2.sin`・`Vec2.cos`・`Vec2.atan2`・`Vec2.pi`・`Vec2.tau` | `Num.` の同じ名前（値は同じ。`mount = "fge"` のゲームは `use fge::{…}` に `Num` を足す）。`bin/fge refactor rewrite --from 'Vec2.sin($x)' --to 'Num.sin($x)' --apply` でまとめて替えられる | `num-from-vec2` |
| project.json の `"scene3dLinearColor": false` | 無い（3D は線形の色だけ）。暗い `ambient` を少し上げるか `hemisphere` で足す・光の `intensity` と `range` を線形の目盛りで合わせ直す（0.79.0.md の「ゲームで直す物」） | `scene3d-linear-color-flag`（この版で足した・止める） |
| `GameEngine.ensureMainThread()` | `LwjglLayer.ensureMainThread()`（ふるまいは同じ） | `engine-jvm-old-calls` |
| `Texture3d.decode(bytes)` | `Texture3d.decodeUsing(dec, bytes)`（`dec` は読み込みの頭で `LoadProgress.imageDecoder()` で受け取る） | `engine-jvm-old-calls` |
| `Gltf.loadTextured(path)`・`Gltf.loadTexturedWith(limits, path)` | `Gltf.loadTexturedUsing(dec, limits, path)`（上限なしは `Gltf.noTextureLimits()`） | `engine-jvm-old-calls` |
| `Gltf.fromGlbTextured(bytes)`・`Gltf.fromGlbTexturedWith(limits, bytes)` | `Gltf.fromGlbTexturedUsing(dec, limits, bytes)` | `engine-jvm-old-calls` |
| 型 `ShaderEffect.ShaderRenderCmd`（モジュール `ShaderEffect` ごと） | `DrawCmd.SurfaceRenderCmd`（中身は同じ） | `shader-render-cmd-alias` |
| `LoadProgress.runNoop` の下で `LoadProgress.imageDecoder()` を受け取る | 画面なしとテストの入口を `HeadlessLoad.handle` で包む。runNoop の下で受け取ると `bug!` で止まる（0.83 までは javax.imageio の物を返して 1 行知らせていた） | — |
| `Game.app` の中で `App.onRenderRequest`・`App.onShotRequest` を繋ぐ | `Main`（と画面なしの入口の `E2e`）で繋ぐ。lint-forbid が止める（0.83 までは知らせだけ） | `dev-request-outside-main` |
| ゲームの src で `Render.Internal.*`・`SoftRaster.Internal.*` を書く | 親のモジュールの関数（`Render.*`・`SoftRaster.*`）。lint-forbid の `app-internal` が `App.Internal` と同じく止める（ゲームが自分で持つ `<モジュール>.Internal` は止めない） | `app-internal` |

上の表で消えた名前の規則（`num-from-vec2`・`engine-jvm-old-calls`・`shader-render-cmd-alias`）も、知らせから止める規則に替えた。
直し忘れの古い書き方は、コンパイルのエラーより先に lint-forbid が代わりの名前つきで止める。

## 絵とふるまい

**変わらない**。テンプレの reference・ギャラリー・gl-parity の行と絵・実機の GL の絵（gl-capture）・3D の部屋の CPU の絵は前の版とバイトまで同じ。
3D の色の旗の偽の分かれ道を消しただけで、既定（線形）の式は同じ。GL のシェーダーの字は `uLinearColor` の 2 行が消えたぶん変わる（GPU のプログラムの鍵が変わり、初回に組み直す）。

## 足した物

- `CharacterBody3d.aabbOf(settings, body)`: 体の当たりの範囲（足元から `height`・水平は ±`radius`）を `Mesh3d.Bounds` で返す（Bevy の Collider の aabb・Godot の `get_aabb` に当たる）
- `CharacterBody3d.isTilted(box)` を pub にした（真上から 11.5° より傾いた面か。Floor の sloped と同じ判定）
- `Scene3d.droppedLightsOfScenes(scenes)`: 場面の列で光の上限を超えて捨てた点光源・スポットの数（GL と CPU の描き手が使う `pickLights` と同じ数）。
  画面なしの描き出しやテストから `Scene3d.droppedLightsOfScenes(Render.drawScenes3d(items))` の 1 行で読める（前は F3 の診断の行だけ）
- `LogCapture.capture(f)`（engine_tools）: テストの中で `Log.warnThen` などの知らせを stderr へ出さずに集め、`(値, 行の並び)` を返す。
  Flix のテストの実行器は stderr に出たテストを FAIL にするので、知らせを出す経路をテストで通す時に包む（`docs/error-handling.md`）
- `make lint`: engine の作業場の lint のうち 0 件の物をまとめて流す

## 振る舞いが変わる物

- `Ray3d.hitBox`（と、それを使う `Ray3d.hitShape`・`CharacterBody3d` の床を探す ray）: 厚さ 0 の箱（`CollisionShape3d.boxOfNode` で作った床の板など）は中を持たない、と扱う。
  ray の始まりが板の上（1e-9 m の幅の中）なら距離 0 で当たる。前は、板の上に合わせた足元が丸めで板の 1e-16 m 下に来ると「箱の中から始まった」で外れ、
  下向きの ray が床を素通りした。足元から上向きに打つ ray も床の板に距離 0 で当たるので、天井を探す ray は足元より少し上から打つ。厚さのある箱は前と同じ

- F3 の診断の行（`FrameDiagnostics.summaryLines`）を ASCII だけの文言にした（`CPU submit 2.00 ms / swap 0.50 ms`・`3D placed 12 / drawn 12 / draw calls 30` など）。
  欧文だけのフォントで描くゲームで □ にならない。行の字を比べているテストは直す
- F3 と `FrameDiagnostics.Diagnostics#gpuNs` の GPU の時間を、描き先ごとの `GL_TIME_ELAPSED` の query の合計で測る（前は最初の描き先の始まりから最後の終わりまで）。
  macOS の GL は `GL_TIMESTAMP` が常に 0 で、前は全部 0.00 ms と出ていた。query を作れない GL では `GPU -`（`gpuNs` は None）

## engine の中の置き場（ゲームの直しは要らない）

- engine/src のフォルダを `core/`・`render2d/`（前の `render/`）・`physics2d/`（`CollisionShape2D`）・`scene3d/`・`shader/`（`ShaderDoc`・`ShaderGen`・`ShaderEval`・`ShaderJson`・`PostProcess`）・
  `platform/`（`Platform`・`GameEngine`・`RenderTarget`・`LoadProgress`・`GamepadMap`）にそろえた。モジュールの名前は同じ
- 大きなファイルを分けた: `SoftRaster` の中身を `SoftRaster.Internal.*`（8 つ）・`Render` の中身を `Render.Internal.Extract`・`Render.Internal.PassReads`・
  `Render3d` の光の uniform を `Render3d.Light` へ。ゲームが呼ぶ関数は元のモジュールに残した。1 ファイル 1,200 行の lint（`make lint-max-lines`）の例外は `ShaderGen` だけ
- engine/src（契約層）の禁止の import と JVM の呼び出しの例外が 0 件になった（lint-forbid の `engine-contract-*`）
