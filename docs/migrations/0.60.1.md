# engine 0.60.0 → 0.60.1 の手当て

**ゲームで直す物は無い。**

## 変わったこと

- **`project.json` の `glyphs` が `"auto"` の時、打った半角・全角スペースが画面に出る。** 字をその場でアトラスに足す所
  （`RenderGlyphGrow`）が、形の無い字（スペース）を捨てていたので、送り幅 0 の字として前後の字が詰まっていた。
  起動時にアトラスを作る時と同じく、送り幅だけを持つ字として載せる。フォントが持っていない字はこれまでどおり載せない。
- `RenderFont.advanceOnlyGlyph` が `pub` になった（中身は変わらない）。
