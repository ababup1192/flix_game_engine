# engine 0.82.0 → 0.83.0 の手当て

## 決定性の門と、ギャラリーの 1 枚から実機で開く口（C6）

**ふるまいと絵は変わらない**（ギャラリーと実機の GL の絵は前の版とバイトまで同じ）。直す所は「ギャラリーの場面を始まりにする」所だけで、
それも足さなければ今までどおり動く。

- **遊んだ記録が Frame の欄を 2 つ足して書く**: 窓のフォーカス（`focus=0|1`・変わったフレームだけ）とパッドの機種（`padkind=generic|steam|unknown`・
  pad から出せない時だけ）。再生はそれを `Frame#windowFocused`・`Frame#padKind` に入れる（前は再生だけいつも真・pad から出した機種）。
  前の版の記録はそのまま再生できる（書いていない間は前と同じ値）。`bin/fge flow check` もこの 2 語を読む
- **記録の最後に `expect world=<16 字>`**（World 全体の要約・`WorldHash.sha256Of`）と、最後の指紋を書く。flow でも `expect world=…` と書ける（どのゲームにもある問い）。
  App を組む時に Main だけが読む外の値（起動した時刻・起動の時に読んだセーブなど）を World に入れているゲームは、記録の再生がこの行で止まる。
  その欄だけ `App.withWorldSummaryMask(f)` で決まった値へ置き換える（templates/sound-novel-starter の Game.app が手本）
- **系で `frame#diagnostics` を読まない**: 記録に残らず再生では None なので、読んで World を変えると再生と食い違う。ゲームの src で書くと
  lint-forbid の `frame-diagnostics-in-system` が止める（1 コマの時間は F8・`POST /perf`・`FLIX_GE_FRAME_STATS` で外から見る）
- **入力の台本** `FLIX_GE_INPUT_SCRIPT=<flow のパス>`: デスクトップの起動で、実機のキー・マウス・パッド・フォーカスの代わりに台本を読ませる
  （tap・hold・release・wait とキー・点の的だけ。読めなければ起動の誤り）。流し終えた周で窓を閉じた時と同じに終わる
- **`make determinism`**（engine の作業場）: テンプレ 3 本を隠しウィンドウで台本どおりに遊ばせ、書いた記録を画面なしで再生して一致を見る。窓を開くので CI には載せない
- **ギャラリーの場面を始まりに**: `App.withShots(Resources.shotsOf(names, worldOf))` で場面を組む関数を繋ぐと（命令口の `GET /shots` が一覧）、`shot:<場面>` の名前で引ける（`START=shot:quit`・flow の `start shot:quit`）。
  始まりの一覧（`withStarts`）とは別の表で、起動の既定・`GET /starts` は変わらない。実機の START で引けるのは DEBUG の起動だけ。
  `SHOT=<場面> make run` はその World から F8 で止めた状態で開く。テンプレ 4 本は場面を組む関数を `src/Shots.flix`（純粋）へ移し、
  `SceneRender` はそれを呼ぶだけにした（自分のゲームで真似るなら、描き出しの初めの World の作り方ごと Shots へ移す）。
  描き出しは `App.Headless.writeShotRecord(outDir, name, Some(指紋の元の字))` で `gallery/<場面>.json` を書ける
- `App.Internal.DevTools.Hooks#close` は最後の World も受ける（`(State, Option[w]) -> Unit`）。App.Internal を呼ぶのは engine の中だけなので、ゲームは直す所が無い
- 実機の起動は、始まりの登録簿（withStarts）が無いゲームでも `START=shot:<場面>` を読む（shot: でない START は今までどおり無視）
- 実機のループは 1 周の頭で dt を読んでから入力を読む順になった（`Platform.FrameClock.getDeltaTime` の doc）。ふるまいは変わらない

## F8 が 3D の場面の中の物を指す

- `Scene3d.withName(name, i)`・`Scene3d.nameOf(i)`: 置いた物に名前を付ける（絵は変わらない・3D の描き出しのキャッシュの鍵にも入れない）。
  `Scene3d.InstanceFields` に欄 `name` が増えた（閉じた型 `Instance3d` の中身なので、`meshInstance` で作るゲームは直す所が無い。
  `InstanceFields` をパターンで全部書いている所だけ `name = _` を足す）
- `Model3d.partInstances(world, model)`: glb の parts を 1 つずつ置き、名前に glTF のノードの名前を入れる
- `Ray3d.nearestInstance(ray, maxDistance, instances)`: レイが一番近くで当たる置いた物
- F8 で 3D の場面を囲むと、注釈の Hit（チケットの README と annotation.json・リモートの `view=scene`）の名前に、
  矩形の真ん中に見えている置いた物の名前が入る（前は空）
