# キャラのアニメーション — 方向・コマ・歩き

前提: 立ち絵(アイドル)が `docs/art-ref/px-character.md` の C 工程で確定してから来る。
**優れたアニメはキーフレームの読みやすさから生まれる — コマを足しても
読めないキーフレームは救えない**(px-character.md の C1 と同じ理屈)。

## 方向

- 方向は 4(down / up / side)。**横は反転で使い回す** — 左右で別絵を作るのは、
  強い方向性ライティングか非対称のデザイン(片手武器・片側の髪)があるときだけ
- 反転しても絵が動かないのが engine の規約(anchor はそのまま)
- **3 方向のアイドルを先に確定**してからコマを作る。方向間で頭頂の高さ・接地の行・
  配色をそろえる(コンタクトシートで並べて見る)

## コマの決まり

- **最小 3 コマ**。2 コマでは軌跡(何がどう動いたか)が出ない
- キーフレーム(動きの端=向きが変わる所)を先に確定し、**似せすぎない**。
  似たキーフレームの間に中間コマを足しても動きは生まれない
- 中間コマはキーフレーム側に寄せる(等間隔にしない)と動きにキレが出る
- **再利用したコマは必ず 1 箇所直す** — コピーして位置をずらしただけのコマは
  ロボットの動きに見える
- 潰しと伸ばしは体積一定 — 縦を 1 行縮めたら横を拡げる
- 操作に応える動作(ジャンプ・攻撃)の予備動作は短くするか無くす。
  魅せる動作にだけ付ける(向きはメインの逆)

## 歩き

- 歩行ループは 3 コマ(右足前 → 中間 → 左足前)から。中間 1 コマを再利用して
  4 コマにすると、逆再生が後退になる
- **その場歩きでも「画面上を移動して足が地面を掴む」姿を想像して描く** —
  接地する足の X を意識し、完成後に位置を中央へ戻す
- 走りのコマを遅回しにして歩きに流用してよい
- **2D のまま脚だけずらす細工は向きごとに食い違う**(正面で動いて見えても横で
  死ぬ)。4 方向をそろえるなら三面図から起こす `bin/fge carve` の経路を使う

## 関節と装備(歩きで体が崩れないために)

- **人型の脚は、膝を進行方向へ 1 段だけ折る。逆関節・S 字にしない**
  (鳥・獣脚・虫・機械の脚はそちらが正しい形なので、この行は当てはめない) — 蹴り上げ足は
  「腿は立ち絵の列のまま → 膝から下+ブーツを 1px だけ同じ向きへ」の 1 回折りで
  描く。脚を立ち絵の列のままにしてブーツだけ横へずらすと、足首が折れた
  逆関節に読まれる(warrior の歩きで実際に指摘された)
- **装備追従(1 コマ遅れ)で開く隙間は腕側で閉じる** — 体を 1px 上げて武器を
  置き残すと、腕と持ち手の間に透過の継ぎ目が開く。武器を動かして閉じるのでは
  なく、腕(袖)を伸ばして持ち手まで届かせる。肩に掛かる装備(盾)は体と
  同じ量だけ動かす — 置き残すと肩が外れて見える

## サブピクセル(1 ドット未満の動き)

- コマを複製してドットをずらし、境目に既存パレットの中間色を 1〜2 色置く。
  新しい色は作らない
- ずらす方向は**線・形が向いている方向**(動きの方向ではない)
- **顔のパーツには使わない** — 目が変形すると悪目立ちする。顔は 2 パターンの
  位置切替で動かし、体・頭にだけ使う
- 曲線が行をまたぐとき 1 ドットだけ残さない(最低 2〜3 ドット)
- 揺れ・眠り・風・炎のちらつきなど微小な動きにだけ効く。全コマ全部位に
  使うと絵が溶ける

## 外すと壊れやすい順(上ほど、外すと動きが死ぬ)

1. **動くものにディザ** — コマ替えでちらついてノイズになる
2. **2 コマループ** — 軌跡が出ない。往復にしか見えない
3. **ずらしただけのコマ** — 必ず形のどこかを描き直す
4. **コマごとの色替え** — パレットは全コマ共通。lint-anim がコマ間の飛びを見る

検査は `bin/fge anim`(コマ間の大きさ・飛び。pingpong は Doc に
`"loop": "pingpong"` を宣言しないと破綻と誤認される)。
