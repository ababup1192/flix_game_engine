# ドット絵（読み分け）

画風（色・色数・輪郭の有無）は `AGENTS.local.md` の画風の節が正。ここには、描き比べ（2026-10-16・3 回の判定と 20 枚の確かめ）で
勝ちに効いた行と、依頼主のダメ出しを止める行だけを置く。**お題の種類の行に書かれたファイルだけを読む。**

| お題の種類 | 読む物 |
|---|---|
| 止まったキャラ・敵 | `character.md` |
| 小物（アイコン・道具） | `character.md` の「形を先に」「輪郭の線」 |
| 歩き | `character.md` → `walk.md` |
| 背景・地面タイル | `background.md` |

周回は `.claude/rules/drawing.md` の「絵の周回」のとおり（r2 で止める）。

## 詳しい参考（既定では読まない）
