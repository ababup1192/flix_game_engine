# ドット絵（読み分け）

画風（色・色数・輪郭の有無）は `AGENTS.local.md` の画風の節が正。ここには、描き比べ（2026-10-16・3 回の判定と 20 枚の確かめ）で
勝ちに効いた行と、依頼主のダメ出しを止める行だけを置く。**お題の種類の行に書かれたファイルだけを読む。**

| お題の種類 | 読む物 |
|---|---|
| 止まったキャラ・敵 | `character.md` |
| 小物（アイコン・道具） | `character.md` の「形を先に」「輪郭の線」 |
| 歩き | `character.md` → `walk.md` |
| 背景・地面タイル | `background.md` |

周回は `.claude/rules/drawing.md` の「絵の周回」のとおり（r2 で止める）。

## 批評は描いていない役に頼む

- r1 の批評は、描いていないサブエージェントに頼む。お題の文は絵と別のファイルにして、**先に絵だけで「何も聞かされていない人に何に見えるか」と目が止まる 3 か所を書かせてから**お題を読ませる。主題や中心の部品が当たらなければ、それが一番の直し。自分の批評では見えない誤り（灯っていないランプ・壁に見える石畳）がここで出た。
- r2 では、出た BLOCKING を全部直す（1 周に 1 つずつだと r2 で止まった時に負けた）。直した方が良いか迷う時だけ、前後を名前を伏せて並べて批評役に選ばせる。

上の 2 つは aseprite-ai-artist（https://github.com/with-pebbly/aseprite-ai-artist 、`agents/pixel-critic.md`、MIT。Copyright (c) 2026 with-pebbly）の手順を描き比べで確かめて書き直した。ライセンス文は同じフォルダの `NOTICE.md`。

## 困った時（既定では読まない）

上のファイルで足りないと分かった時だけ、engine の `docs/art-ref/` から当たる節を引く。全部を読むと読む量が 50 倍になり、
描き比べでは質が上がらなかった（キャラの数値表を足した組は最下位）。

| 困った時 | 引く所（engine の `docs/art-ref/`） |
|---|---|
| パレット・色の予算・ディザ・タイル地形・オートタイルを決める | `retro-pixel.md` |
| 新しい画面の画風を決める・View の部品を探す | `visual-dict.md`（部品の表は `visual-dict/reference.md`） |
| 48px 以上の顔・会話の顔グラ・四足の生き物 | `px-character.md`（`px-character/faces.md`・`animation.md`） |
| 場面の中に人を置く（光・影・風をそろえる） | `figure-drawing.md` |
| 3 面図の立ち絵 1 枚から歩き 4 方向を機械で彫る | `carve-sprite.md` |
