# このゲーム固有の設計原則

サウンドノベルのテンプレート「夏草の駅」。十年ぶりに祖母の町へ帰った「私」と、幼なじみの千夏。
5 分で読み終わり、選び方で結末が 3 つ。ノベルゲームの機能（NVL/ADV・ルビ・選択肢と変数・背景の切り替え・
環境音・ログ・オート・スキップ・既読・セーブとロード・設定）を一通り見せる教科書。

- **文章・分岐・演出の順番は全部シナリオ**（`assets/talk/natsukusa.yarn`。直したら `bin/fge yarn build assets/talk`）。
  演出はコマンド（`<<bg>>` `<<nvl>>` `<<adv>>` `<<clear>>` `<<ambience>>` `<<se>>` `<<fx>>` `<<shake>>` `<<wait>>`）で書き、
  意味は `src/Stage.flix`。新しいコマンドは `Stage.Cue` に case と `cueOf` の枝、`Stage.commandNames` に名前を足す
  （語彙 `assets/talk/vocab.json` は `make talk-vocab`）。シナリオに式や条件を足すのは Yarn の `<<if>>` `<<set>>` まで。
- **画面に出す言葉はシナリオか Doc**: シナリオの外の言葉（タイトル画面・ボタン・設定・知らせ）は `assets/novel.story.json` の
  labels（鍵の正は `StoryDoc.Label`）。調整する数（文字の速さ・オートの待ち・ログの行数・揺れ）は `assets/novel.kind.json`。
- **セーブはブックマーク**: セーブは YarnRunner のブックマーク（ノード・変数・送りと選択）と、前のノードから持ち越す舞台
  （背景・環境音・パーティクル）。ロードはブックマークを当て直して今のノードのコマンドを黙って反映し、持ち越す物をセーブの値で戻す。
  ログの各行も同じ形（`Saves.Mark`）を持つので、ロールバックとバックログから戻るのはロードと同じ道を通る。
  背景の重ね・揺れの途中は終わりの形にする（`Stage.settle`）。
- **時計は 2 本**: 文字送り・`<<wait>>`・背景の切り替え・揺れは物語の時計 `storyClock`（画面や確認のウィンドウを開いている間は止まる）、
  タイトル画面・クレジット・蛍・知らせは実時間 `realNow`。
- **場面の値は場面の中に・Doc は Res に**: Doc とシナリオの木は World に置かず `Res`（`src/Res.flix`。App の w は `Resources.With[Res.Res, World.World]`）。
  World の欄はどの場面でも要る物だけ。読んでいる間だけの値は `World.Scene.Reading` の `Read`、
  画面のカーソルは `World.Panel` の payload、確認のウィンドウは `ask` の `(Ask, Answer)` に置く。Bool・0/1 の数で
  意味を持たせず enum にする（`Answer.Yes`・`Layout.Side`・`Saves.Display` など）。規則は章のファイル
  （`WorldRead`・`WorldLog`・`WorldSaves`・`WorldSettings`・`WorldMenu`）に置き、外から呼ばない物は pub にしない。
  View の部品は `View.Env` とその場面の payload だけを受ける。
- **プレイヤーは詰まない**: どの結末もクレジットを経てタイトル画面へ戻る。Doc やシナリオが壊れても fail-open で起動する。
- **ブラウザ版の書き出しは project.json の web 欄**: 文言 `startPrompt` は「タッチして開始」のまま。写真の背景は
  `compress.lossyImages` の q85。背景・BGM・効果音を足したら `deferred` に入れるか決める（タイトルの背景と最初に鳴る音は入れない。
  書き方と届く前のふるまいは engine の `docs/startup.md`）。届く前の背景・環境音で暗転して待つ規則は `WorldRead` の「素材の待ち」の節
  （入口は `Game.withAssetLoading` で、Main とブラウザの入口だけが足す。テスト・flow・描き出しは全部届いた形のまま）。
- 文字送り（UiTypewriter）・ルビつきの字の配置と折り返し（RichText.placeRuby）・シナリオの実行（YarnRunner）・
  ミキサー（AudioMixer）はエンジンの物を使う。自前の文字折り・会話の進め方・音量の掛け算を書かない。

## この画面の画風

**「実写の写真を、ピントの合わない記憶のようにぼかし、時間帯の光で染める。その上に明朝の字を静かに置く」。**

- 背景は描かない。昼の実写の写真（CC0 / CC BY）を 1 枚ずつ使い、ぼかし・彩度・明るさ・色・上から差す光・四隅の落ちを
  シェーダー（`src/Backdrop.flix`・数は `assets/novel.backdrops.json` の grades）で付ける。同じ写真を夕暮れ・夜・朝に使い回す。
- 字は明朝 1 書体。白に近い生成りの字に 1px の影。NVL は画面いっぱいの薄い幕の上、ADV は下のウィンドウ（上から下へ濃くなる地と金の細い縁）。
- 色は 3 つ: 写真の色 / 生成りの字 / 金の差し色（カーソル・名前・送りの印）。ウィンドウの地は藍に寄せた黒。
- 縦の画面（スマホを縦に持った時）は、写真を全面に置いたまま上から下へ濃くなる覆いで沈め、画面いっぱいの頁に文を上から積む（前の行は少し薄く）。
  NVL も ADV も同じ頁（ADV の台詞は名前を小さく添えて積み、場面が変わると頁を改める）。操作は右上の …（設定・タイトルへ・隠すのメニュー）と、
  その下の右端に字の無い丸いアイコン 3 つ（しおり・ログ・オート）を縦一列（`src/Rail.flix`・積み方と大きさは `assets/novel.rail.json`）。
  しおりは [セーブ｜ロード] を列の左に開き、オートの長押しはスキップ、ほかのアイコンの長押しは名前のツールチップを出す。頁と選択肢は列の左で折り返す。進み具合のバーは付けない。
  列の丸は面に階調を入れない例外（49 px の記号で、形が一意に読めるかで見る）。階調は … の丸・ツールチップ・メニューの地が受け持つ。
- **読んでいる間も画面を止めない**: 背景は切り替えの頭でピントが外れてから合い、夜は蛍が明滅しながら漂う。
  蛍は実時間と番号だけから導く（保存しない = 同じ時刻なら同じ絵）。
- やらないこと: 写真をぼかさずに出さない（字が読めない・写真の情報が多すぎる）。字を太字や縁取りで飾らない。
- **これは数ある画風の 1 つでしかない。** このテンプレから作るゲームは、画風を自分で決めてここに書き直してよい。
