# このゲーム固有の設計原則

サウンドノベルのテンプレート「雪どけを待たない便り」。冬の山里で配達を手伝う灯と、坂の上の工房の木版画家・冬馬の文通。
10 分ほどで読み終わり、選び方で結末が 3 つ。ノベルゲームの機能（NVL/ADV・ルビ・選択肢と変数・背景の切り替え・
環境音・ログ・オート・スキップ・既読・セーブとロード・設定）を一通り見せる教科書。

- **文章・分岐・演出の順番は全部シナリオ**（`assets/talk/` の .yarn。作例は yukidoke.yarn。直したら `bin/fge yarn build assets/talk`）。
  演出はコマンド（`<<bg>>` `<<window>>` `<<audio>>` `<<fx>>` `<<shake>>` `<<show>>` `<<hide>>` `<<wait>>`。主の引数は位置・ほかは `key=value`）で書き、
  引数の表と意味は `src/Commands.flix`（表に無い引数・型・Doc に無い名前は `bin/fge yarn build` が止める）。このゲームだけのコマンドは
  `src/GameCommands.flix` に 1 つ足し、後に残る値は `Stage` の `props`（`PropertyTween` の `game.` の鍵）に書いて `src/GameView.flix` で描く
  （語彙は `make talk-vocab` が書く: テンプレートの命令は `assets/talk/vocab.std.json`（追随で上書き）、ゲームの命令と Doc の場所は `assets/talk/vocab.json`）。シナリオに式や条件を足すのは Yarn の `<<if>>` `<<set>>` まで。
  話し手の呼び名・変数の表示名・「はじめから」で開くノード（`opening`）は `assets/novel.story.json`、描き出しの場面（make render の SHOT）は
  `assets/novel.shots.json` に書く。どちらも `bin/fge yarn build` が vocab.json の from を通して読み、台本の名前と照らす（Flix を走らせずに名前を足せる）。
- **画面に出す言葉はシナリオか Doc**: シナリオの外の言葉（タイトル画面・ボタン・設定・知らせ）は `assets/novel.story.json` の
  labels（鍵の正は `StoryDoc.Label`）。ゲームだけの言葉（結末の名前など）は同じ Doc の gameLabels に鍵を決めて書き、
  `StoryDoc.gameLabelOf(鍵, 既定の言葉, res#story)` で引く（Label の enum には足さない）。調整する数（文字の速さ・オートの待ち・ログの行数・揺れ）は `assets/novel.kind.json`。
- **セーブはブックマークと、その台詞の舞台と頁**: セーブは YarnRunner のブックマーク（ノード・変数・送りと選択）と、
  その台詞を出した時の舞台の全部（`Stage.Snapshot`。背景・文章の出し方・頁の数・立ち絵と小物・`props` の値）と頁。
  ロードはそのノードに入る直前の舞台と頁（`Saves.Mark` の `entry`）からブックマークを当て直してバックログを作り、
  舞台と頁は最後にセーブの値で置き換える（`WorldRead.restore`）。ノードに入った所は出来事の .yarn の行で見分ける（`WorldRead.trackEntry`）。
  `<<wait>>` の間にセーブできるのは、バックログの一番新しい行が台詞の時だけ。
  ログの各行も同じ形（`Saves.Mark`）を持つので、ロールバックとバックログから戻るのはロードと同じ道を通る。
  背景の重ね・揺れの途中は終わりの形にする（`Stage.settle`）。ノードの頭から開く所（プレビュー・描き出し）は、
  opening から流してそのノードに最初に着いた時の舞台から始める（`WorldRead.buildEntryStage`）ので、ノードの頭で舞台を言い直さなくてよい。
- **時計は 2 本**: 文字送り・`<<wait>>`・背景の切り替え・揺れは物語の時計 `storyClock`（画面や確認のウィンドウを開いている間は止まる）、
  タイトル画面・クレジット・蛍と雪の粒子・知らせは実時間 `realNow`。
- **場面の値は場面の中に・Doc は Res に**: Doc とシナリオの木は World に置かず `Res`（`src/Res.flix`。App の w は `Resources.With[Res.Res, World.World]`）。
  World の欄はどの場面でも要る物だけ。読んでいる間だけの値は `World.Scene.Reading` の `Read`、
  画面のカーソルは `World.Panel` の payload、確認のウィンドウは `ask` の `(Ask, Answer)` に置く。Bool・0/1 の数で
  意味を持たせず enum にする（`Answer.Yes`・`Layout.Side`・`Saves.Display` など）。規則は章のファイル
  （`WorldRead`・`WorldLog`・`WorldSaves`・`WorldSettings`・`WorldMenu`）に置き、外から呼ばない物は pub にしない。
  View の部品は `View.Env` とその場面の payload だけを受ける。
- **プレイヤーは詰まない**: どの結末もクレジットを経てタイトル画面へ戻る。Doc やシナリオが壊れても fail-open で起動する。
- **ブラウザ版の書き出しは project.json の web 欄**: 文言 `startPrompt` は「タッチして開始」のまま。写真の背景は
  `compress.lossyImages` の q85。背景・BGM・効果音を足したら `deferred` に入れるか決める（タイトルの背景と最初に鳴る音は入れない。
  書き方と届く前のふるまいは engine の `docs/startup.md`）。届く前の背景・立ち絵は engine が待つ（押した所まで戻して待ち、
  届いたら押した入力を渡し直す。手で待ちを書かない。本画面の View は届いていない絵も描く物の列に入れる = `View.Env` の `skipTextures` を空に。
  飛ばすのはセーブの枠のサムネだけ）。待つ間、タイトルの選んだ行が光る（`App.withLoadWait` → `World.loadWait` → `View.title`）。
  入口は `Game.withAssetLoading` で、Main とブラウザの入口だけが足す。テスト・flow・描き出しは全部届いた形のまま。
- 文字送り（UiTypewriter）・ルビつきの字の配置と折り返し（RichText.placeRuby）・シナリオの実行（YarnRunner）・
  ミキサー（AudioMixer）はエンジンの物を使う。自前の文字折り・会話の進め方・音量の掛け算を書かない。
  例外はクレジットの行（`src/CreditsLayout.flix`）: 中央そろえの行を禁則つきで読点・中黒・括弧の所で折り、流れ切る長さも同じ並びから出す
  （engine の RichText の折りは字の境目で切り、禁則を持たない）。
- **クレジットの書き方の決まり**（`assets/novel.credits.json` と `CREDITS.md`）: 画像生成で作った絵や、engine・自作の合成で作った音は、
  場面や音の種類を並べない（「背景は画像生成で作りました」「効果音の一部は合成」くらい）。外の素材で規約が表記を求める物
  （作者名・曲名・サイト・ライセンス）は書く。縦の画面（540 幅）に入らない行は折って流れるが、1 行は短いほど読みやすい。
  縦の画面のクレジットは `make render SHOT=credits VIEW=phone`（数秒で `debug/portrait-credits.png`）で確かめる。
- **BGM・効果音を外から足す時は、engine の `docs/audio.md` の「外から持ってくる BGM・効果音」の候補から選ぶ**（ノベルには魔王魂・PeriTune・甘茶の音楽工房、効果音は効果音ラボ）。
  規約の要点（魔王魂はクレジット必須・PeriTune の曲を有償の作品に入れる時と、音を自由に鳴らせる画面を作る時は相談）と書く所（`CREDITS.md` と `assets/novel.credits.json` の 2 か所）もそこにある。

## 縦が基本（design・PC のウィンドウ・絵・camera・通し）

このテンプレートは**スマホを縦に持って遊ぶ形を基本に作る**。PC でも同じ縦の画面をそのまま出すので、絵・組み・通し（flow）は 1 つで済む。

- **design は縦の 540×1170**（project.json）。並べ方は `Layout.Fit.Portrait`（大きさは `assets/novel.portrait.json`・右の列は `assets/novel.rail.json`）。
  スマホのブラウザは `web.portraitDesign`（幅 540・高さは画面の比から 960〜1296）で同じ組みを選ぶので、高さが変わっても崩れない並べ方にする
  （下限の 960 は描き出しの `portrait-short-*` で見る）。
- **横の組み**（`Fit.Regular`・`Fit.Small`・`novel.small.json`）はコードに残してある。使うのは design が横の時だけで、描き出しでは撮らない（壊れても絵では気付けない。テストの `TestSmallScreen` などだけが見る）。
  残す訳: このテンプレートを写して作ったゲームは .flix をテンプレートから写して追随するので、縦へ移る前のゲームが写しても動くように。
  縦が基本へ移ったゲームが無くなったら外す。新しく作るゲームは横の組みを直さない・見ない。
- **PC のウィンドウ**: デスクトップ版は縦長のウィンドウ（360×780・よくある PC の画面の高さに収まる大きさ）で開く。ウィンドウを横に広げた時・全画面・PC のブラウザでは、縦の画面を高さに合わせて真ん中に置き、
  左右の余白（ピラーボックス）は今の背景の写真（時間帯の色とぼかし）を窓いっぱいに広げて塗る（`App.withLetterboxView(Resources.view(View.letterbox))`・
  `View.letterbox` が写真だけを地の色で沈めて渡し、engine が広げる）。立ち絵・粒・字は左右に出さない。黒い帯にしたいゲームは Game.flix のその 1 行を消す。
- **絵（背景の写真）は縦の構図で作る**（9:19.5 前後）。画面の高さが 960〜1296 で変わるので、写真は画面を覆うように真ん中で切って置く。
  1. 画像生成には縦長（1024×1536 など、いちばん縦長の大きさ）で頼み、「縦長のスマホの画面に収める。大事な物は横の真ん中 70%・縦の 15〜85% に入れる」と書く。
     一枚絵（人の姿が写った物）は、元の背景を画像の編集で直して姿を足す（同じ場所の背景と並べて、ずれないように）。
  2. 仕上げは真ん中で 9:19.5 に切って縮める（例: `ffmpeg -i in.png -vf "scale=-2:1560,crop=720:1560" -q:v 2 assets/bg/<名前>.jpg`）。
     ぼかして出すので 720×1560 で足りる（一枚絵も同じ）。
  3. `assets/novel.backdrops.json` の photos に `"aspect": 横÷縦`（720×1560 なら 0.4615）を書く。書かないと 16:9 の横長の写真として真ん中を切る。
  4. 出どころは `CREDITS.md` の表に書く（作り方の欄に「縦に生成して 720×1560 に切り抜き」）。`assets/novel.credits.json` は画像生成の絵を場面ごとに並べない決まりなので、足す行は無い。
- **`<<camera>>` の x・y は画面（＝縦の写真の幅・高さ）が 1**。x=0.25 は写真の幅の 1/4 だけ右を見る。zoom=z の時に写真の端が出ないのは
  x・y がどちらも ±(1 − 1/z) / 2 の中（z=1.5 なら ±0.17）。見せたい物の位置から決める: 写真の左から 0.7 の所を真ん中にするなら x=0.2。
- **通し（flow）は縦の 1 本**: 点で押す手（`tap x,y`・`hold x,y`）は縦の design の座標で書く。右の列（しおり・ログ・オート）は離した時に
  押したことになるが、押し始めた所も返事に数える（`E2e.replyCountOf`）ので `tap x,y` で押せる（例は `e2e/bookmark.flow`）。右の列と … は上と右から積むので、PC（540×1170）とスマホ（540×1169）で同じ点に当たる。
  画面の下の端から測る物（頁・選択肢）は高さで動くので、点でなく役（`confirm`・`next` など）で押す。

## 速く作る流れ — Flix を先に固め、その後はシナリオと Doc だけで回す

ノベルは、Flix を直す仕事を先に終わらせると、後は .yarn と JSON だけを直して作れる。Flix を直さなければ型検査もコンパイルも要らず、
走らせたままその場で反映される。

1. **先に Flix で終わらせる物**: このゲームだけのコマンド（`src/GameCommands.flix`）、その描き方（`src/GameView.flix`）、
   このゲームだけの Doc（`src/GameRes.flix`）、テンプレートへの追随。ここまでで `make check`・`make test`・flow を緑にする。
   コミットの時の門（独自語の `bin/fge jargon`・lint）もこの段で通しておく（`bin/fge precommit --files <触ったファイル…>` で素振りできる）。
   後の段でコメントや Doc の note の言葉で止まると、そのために .flix を直して型検査と jar の作り直しが 1 回増える。
2. **その後は .yarn と JSON だけ**: 台詞・分岐・演出の並び・変数・背景や立ち絵の割り当て・色・文言・数。
   名前や引数の誤りは `bin/fge yarn build assets/talk`（vocab.json を通して Doc の名前も照らす）が止める。
   **決まりは Doc の欄で変える**（暗転の形・背景の切り替えの秒と曲線・立ち絵の濃さの曲線・文字の枠を消す秒・型ごとの揃え・話し手の強調・小物の重なり）。欄の一覧はスキーマの label と各 Doc の note、その行だけ替えるなら命令の引数。Flix に戻るのは欄が無い時だけ。
3. **走らせたまま反映する**: `DEBUG=1 make run` で起動する（DEBUG が無いと保存を見張らない）。
   - JSON の Doc は保存して約 0.5 秒で、いま出ている画面に反映される。
   - .yarn は保存だけでは反映されない。`bin/fge yarn build assets/talk`（0.1 秒ほど）で dialogue.json を書くと、ゲームが読み直す。
     読んでいた行は保ったまま、ノードの頭から読み直してその行へ戻る（背景の切り替えや頭の待ちをもう一度通る）。Studio は .yarn の保存で build まで流す。
   - 直した行を見に行く: 起動中なら `bin/fge talk goto assets/talk/<file>.yarn:<行>`、起動していなければ `bin/fge talk shot …:<行>` で 1 枚。
4. **シナリオを全部読まない**（長い物語ほど、頭から読むだけで重くなる）:
   - 全体の形は `bin/fge yarn graph assets/talk --json -`（ノード・矢印・演出の並び。台詞の本文は入れない）。
   - 直すのはそのノードの行だけを開く（行からノードは `bin/fge talk where <file>.yarn:<行>`）。
   - シナリオを通して読む・直すなら `bin/fge yarn script assets/talk` の md と、直した md を戻す `--diff`。
5. **秒の直しはまとめる**: 台詞・選択肢・分岐の直しは、比べ（`migrate shoot`・`migrate diff`）の時間がほとんど増えない。
   `<<wait>>` や切り替えの秒を変えると、時刻で動く物（粒子・揺れ）がその後ろで全部ずれて絵が変わり、比べが重くなる。秒の直しは 1 回にまとめる。
   比べのコマは画面なしの GPU（WebGPU）で塗る（初めての撮りが CPU の約半分）。GPU の基準は機械ごとに違うので、別の機械の基準と比べる時は
   その機械で前の版から `make migrate-baseline MIGRATE_OVERWRITE=1 MIGRATE_PAINT=gpu` で撮り直す（GPU で塗れない前の版の基準は CPU のまま、`migrate-new` も CPU で塗って比べる）。
6. **Flix に戻る合図**: 同じ演出をコマンドの組み合わせで何度も書いている（1 つのコマンドにまとめる）、
   `<<if>>` `<<set>>` で書けない式が要る、Doc の欄が足りない。戻ったら 1. の門を通してから、また 2. へ。
7. **テープで見てもらう**（`make tape FLOW=e2e/tape.flow` → `debug/tape/tape/index.html`）: flow を縦の画面（スマホを縦に持った時・
   `FLOW_VIEW=phone`）で 1 回撮る（頁は切り替えのボタンを出さない）。PC も同じ縦の画面なので別に撮らない。
   PC の物（マウスで押す・区分 Large）と並べたい時だけ `TAPE_VIEWS="phone pc"`（頁は縦で開き、上のボタンで替える。台詞や待ちの秒が食い違うと `bin/fge tape` が欄の名前を言って止める）。
   既定でブラウザ版も書き出し（`bin/fge export-web`・作業フォルダは `/tmp/fge-tape-web/<ゲーム>`）、
   頁の上の「はじめから遊ぶ」がタイトルから開く。書き出しが要らなければ `TAPE_PLAY=0`（ボタンは出ない）。
   ディスクを溜めない: `make tape` は mp4 を作った後に元のコマ（`debug/video/<名前>[-phone]`・8 GB 超もある）を消す（残すなら `TAPE_KEEP_FRAMES=1`）。
   `bin/fge tape publish` は同じゲームの同じ flow の古い版の動画を置き場から外す（既定は最新 1 版だけ残す・頁は残して「動画は消えた」と最新へのリンクを出す・`--keep-videos N|all`）。

## この画面の画風

**「実写の写真を、ピントの合わない記憶のようにぼかし、時間帯の光で染める。その上に明朝の字を静かに置く」。**

- 背景は描き込まない。昼の光の実写風の縦の構図の絵（画像生成・作り方は上の「縦が基本」）を 1 枚ずつ使い、ぼかし・彩度・明るさ・色・上から差す光・四隅の落ちを
  シェーダー（`src/Backdrop.flix`・数は `assets/novel.backdrops.json` の grades）で付ける。同じ絵を朝・夕方・灯り・夜に使い回す。
  人の姿が写った一枚絵（結末の後ろ姿）は、ぼかしだけを弱めた grade（`still_morning`・`still_evening`）で出す（姿が溶けないように）。
- 字は明朝 1 書体。白に近い生成りの字に 1px の影。NVL は画面いっぱいの薄い幕の上、ADV は下のウィンドウ（上から下へ濃くなる地と金の細い縁）。
- 色は 3 つ: 写真の色 / 生成りの字 / 金の差し色（カーソル・名前・送りの印）。ウィンドウの地は藍に寄せた黒。
- 画面は縦（PC も同じ縦の画面を真ん中に出す）。写真を全面に置いたまま上から下へ濃くなる覆いで沈め、画面いっぱいの頁に文を上から積む（前の行は少し薄く）。
  NVL も ADV も同じ頁（ADV の台詞は名前を小さく添えて積み、場面が変わると頁を改める）。操作は右上の …（設定・タイトルへ・隠すのメニュー）と、
  その下の右端に字の無い丸いアイコン 3 つ（しおり・ログ・オート）を縦一列（`src/Rail.flix`・積み方と大きさは `assets/novel.rail.json`）。
  しおりは [セーブ｜ロード] を列の左に開き、オートの長押しはスキップ、ほかのアイコンの長押しは名前のツールチップを出す。頁と選択肢は列の左で折り返す。進み具合のバーは付けない。
  列の丸は面に階調を入れない例外（49 px の記号で、形が一意に読めるかで見る）。階調は … の丸・ツールチップ・メニューの地が受け持つ。
- 立ち絵と小物（`<<show>>` `<<hide>>`・`src/Cast.flix`）は写真の上（world の層の蛍の手前）。人物は字の地の下、小物は頁の幕（NVL と縦の画面の頁）の上・字の下
  （幕で小物がくすまないように。ADV では人物と同じ world の層）。透過画像を 2 つの画素の間をなめらかに
  つなぐシェーダーの面で貼り、出入りと表情の替えはクロスフェードだけ（すべらせない）。息の揺れは足元を据えて高さを僅かに伸び縮みさせる。
  縦の画面では頁の覆いで人物も沈む（`novel.cast.json` の `portraitVeilWithCast` を 1 未満にすると人物が出ている間だけ覆いが薄くなる）。
  テンプレートの物語には冬馬の立ち絵（plain・puzzled・smile）と手描きの地図（小物）を出す。どれも昼の光で描いた透過画像で、
