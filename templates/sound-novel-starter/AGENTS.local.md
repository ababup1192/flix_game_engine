# このゲーム固有の設計原則

サウンドノベルのテンプレート「夏草の駅」。十年ぶりに祖母の町へ帰った「私」と、幼なじみの千夏。
5 分で読み終わり、選び方で結末が 3 つ。ノベルゲームの機能（NVL/ADV・ルビ・選択肢と変数・背景の切り替え・
環境音・ログ・オート・スキップ・既読・セーブとロード・設定）を一通り見せる教科書。

- **文章・分岐・演出の順番は全部シナリオ**（`assets/talk/natsukusa.yarn`。直したら `bin/fge yarn build assets/talk`）。
  演出はコマンド（`<<bg>>` `<<nvl>>` `<<adv>>` `<<clear>>` `<<ambience>>` `<<se>>` `<<fx>>` `<<shake>>` `<<wait>>`）で書き、
  意味は `src/Stage.flix`。新しいコマンドは `Stage.Cue` に case と `cueOf` の枝、`Stage.commandNames` に名前を足す
  （語彙 `assets/talk/vocab.json` は `make talk-vocab`）。シナリオに式や条件を足すのは Yarn の `<<if>>` `<<set>>` まで。
- **画面に出す言葉はシナリオか Doc**: シナリオの外の言葉（タイトル画面・ボタン・設定・知らせ）は `assets/novel.story.json` の
  labels（鍵の正は `StoryDoc.Label`）。調整する数（文字の速さ・オートの待ち・ログの行数・揺れ）は `assets/novel.kind.json`。
- **セーブはブックマーク**: セーブは YarnRunner のブックマーク（ノード・変数・送りと選択）と、前のノードから持ち越す舞台
  （背景・環境音・粒）。ロードはブックマークを当て直して今のノードのコマンドを黙って畳み、持ち越す物をセーブの値で戻す。
  ログの各行も同じ形（`Saves.Mark`）を持つので、ロールバックとバックログから戻るのはロードと同じ道を通る。
  背景の重ね・揺れの途中は終わりの形にする（`Stage.settle`）。
- **時計は 2 本**: 文字送り・`<<wait>>`・背景の切り替え・揺れは物語の時計 `storyClock`（窓を開いている間は止まる）、
  タイトル画面・クレジット・蛍・知らせは実時間 `realNow`。
- **プレイヤーは詰まない**: どの結末もクレジットを経てタイトル画面へ戻る。Doc やシナリオが壊れても fail-open で起動する。
- 文字送り（UiTypewriter）・ルビつきの字の配置と折り返し（RichText.placeRuby）・シナリオの実行（YarnRunner）・
  ミキサー（AudioMixer）はエンジンの物を使う。自前の文字折り・会話の進め方・音量の掛け算を書かない。

## この画面の画風

**「実写の写真を、ピントの合わない記憶のようにぼかし、時間帯の光で染める。その上に明朝の字を静かに置く」。**

- 背景は描かない。昼の実写の写真（CC0 / CC BY）を 1 枚ずつ使い、ぼかし・彩度・明るさ・色・上から差す光・四隅の落ちを
  シェーダー（`src/Backdrop.flix`・数は `assets/novel.backdrops.json` の grades）で付ける。同じ写真を夕暮れ・夜・朝に使い回す。
- 字は明朝 1 書体。白に近い生成りの字に 1px の影。NVL は画面いっぱいの薄い幕の上、ADV は下の窓（上から下へ濃くなる地と金の細い縁）。
- 色は 3 つ: 写真の色 / 生成りの字 / 金の差し色（カーソル・名前・送りの印）。窓の地は藍に寄せた黒。
- **読んでいる間も画面を止めない**: 背景は切り替えの頭でピントが外れてから合い、夜は蛍が明滅しながら漂う。
  蛍は実時間と番号だけから導く（保存しない = 同じ時刻なら同じ絵）。
- やらないこと: 写真をぼかさずに出さない（字が読めない・写真の情報が多すぎる）。字を太字や縁取りで飾らない。
- **これは数ある画風の 1 つでしかない。** このテンプレから作るゲームは、画風を自分で決めてここに書き直してよい。
