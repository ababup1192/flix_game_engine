# このゲーム固有の設計原則

（ここに、このゲームだけの原則を書く。共通の作法はエンジン側の AGENTS.core.md が
sync で AGENTS.md に入るので、重複して書かない。書いたら engine 側で
`make sync-agents GAME=<このフォルダ>` を再実行して AGENTS.md に反映する。）

例:
- 画面に文字を出さない。すべて絵と音で伝える。
- プレイヤーは死なない。失敗は時間の損だけで表す。

## この画面の画風

- 昼の浅瀬の潮だまりを真上から。主役は水の中の透け（砂・小石・海藻）と、岩の湿り気（濡れた岩は暗く艶があり、乾いた岩は明るくざらつく）。水と岩の境は DualGrid の角の丸い塊。
- 色は 3 つ: 下地＝濡れた岩の灰緑と砂、主役＝ターコイズの浅い水、差し色＝ヤドカリの朱（朱は主役と、主役への警告の輪だけに使う）。光＝わずかに黄の昼光（#f0e6c4）・影＝青緑（#1d3436）。
- やらないこと: 強い日差しのグレア・白飛び（一番明るい色も #f0e6c4 止まり。加算の光は使わない）。真夏の海岸のような全部日向・高彩度にしない。
