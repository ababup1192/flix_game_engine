# このゲーム固有の設計原則

（ここに、このゲームだけの原則を書く。共通の作法はエンジン側の AGENTS.core.md が
sync で AGENTS.md に入るので、重複して書かない。書いたら engine 側で
`make sync-agents GAME=<このフォルダ>` を再実行して AGENTS.md に反映する。）

例:
- 画面に文字を出さない。すべて絵と音で伝える。
- プレイヤーは死なない。失敗は時間の損だけで表す。

## 状態の置き場

- 場面の値は場面の enum（`World.Screen` の case の payload）の中に・Doc と描く元は `Res` に。World の一番上の欄に足していかない。

## このゲームの画風

<!-- 直下の「最初に決めて…」の定型文は bin/fge status の未記入判定と結合している。Makefile の new-game が各テンプレへ注入する仮置き行も同じ定型句を使う。文言を直すなら 3 箇所とも直す（このコメント自身に全文を書かないのは、書き込み後も残って判定を誤らせるため） -->
（**最初に決めて、ここに 2〜3 行で書く。** 何を見て育った絵か・色は何色でいくか・
何をしないか。テンプレの見た目をそのまま引き継がない — 骨組みが持っている
「暗い空 + 光る地平 + 塵」は数ある画風の 1 つでしかない。）

例:
- 明るい紙に水彩。輪郭線は茶色の細線。加算のグローは使わない（白地では見えない）。
- 色は 4 色だけ（紙・空・主役・影）。階調はディザで作り、色を足さない。
