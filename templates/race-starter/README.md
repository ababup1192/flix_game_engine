# Race

flix_game_engine の見下ろしレースのテンプレート。舞台は真夏の海岸ハイウェイ。
合言葉は **「最後のコーナーまで勝敗が判らないレース」** — 危険な走りだけがニトロゲージを貯め、
ゲージだけがライバルを千切れます。安全運転では勝てません。

- **急カーブとドリフト**: 速いままカーブへ入るとアウトへ膨らむ。X を押しながら曲がると
  ドリフト — 減速せず深く曲がれてゲージも貯まるが、外へ流れ続け、草に落ちるとスピン。
- **スリップストリーム + ラバーバンド AI**: 前走車の真後ろに付くと加速。ライバル 3 台は
  距離差で速くなったり遅くなったりして、常に接戦へ戻ってくる。
- **ニトロ**: ゲージ満タンで Z。爆発的に速いが、発動中はハンドルが半分しか効かない。
- **押し合いとクラッシュ**: 車どうしがぶつかると互いに横へ弾かれ、少しのあいだ減速する
  （スピンはしない・ゲージも減らない）。スピンは障害物の直撃とドリフト失敗の草落ちだけ
  （1 秒操作不能 + ゲージ半減）。
- **障害物 4 種**: 点の **コーン** / 隙間だけが通れる **土管ゲート**（狭い隙間を両側すれすれで
  抜けるとゲージが 2 回ぶん貯まる）/ 道を左右に往復する **振り子バー**（位置は行番号と時刻の
  式で決まるので、毎周まったく同じリズム — ブレーキで待つかニトロで抜けるかを覚えて選ぶ）/
  コーナーの外側に立つ **ガードレール**（当たってもスピンしない。擦っている間ずっと減速 +
  火花 + ゲージ加算 — 壁に擦り付けて曲がる遅いが確実な線）。
- **坂**: 登りで遅く・下りで速い。頂上の向こうは道が隠れて先が読めません。
- **アイテム**: 効果は取った瞬間の順位で決まる（下位ほど強い。乱数ゼロの逆転補正）。
- 完走時に最下位だと **LOSE**。それ以外は WIN（1 位だけボーナス）。

操作: ←→（ハンドル）/ ↓（ブレーキ）/ X 押しっぱなし（ドリフト）/ Z（ニトロ発動）/
Space・Enter（Title・Win・Lose では決定）。

## 始め方

Flix コンパイラはエンジンリポの `bin/flix` ラッパ経由で呼ぶので、devbox shell の外でも動きます。
エンジンの場所が既定（生成時に埋め込み）と違うときは `ENGINE=/path/to/flix_game_engine` を付けてください。

| コマンド | 何をするか |
|---|---|
| `make run`    | ゲームを起動する（ウィンドウが開く） |
| `make debug`  | 保存即反映(watchFile)と F8 を有効にして起動 |
| `make check`  | 型検査だけ走らせる（一番速い確認） |
| `make test`   | テストを実行する |
| `make render-all`   | ギャラリー PNG と効果音を全部作り直す（決定的な 8 場面: title / s1_drift / s2_nitro / s3_crash / s4_uturn / s5_gate / s6_rail / s7_bar） |
| `make render SHOT=s1_drift` | その場面だけ `debug/s1_drift.png` へ描き出す（複数は `SHOT="title s5_gate"`） |
| `make reference-check`  | 描き出した絵をリファレンス画像とバイト比較する |
| `make reference-update` | いまの gallery をリファレンス画像として更新する |

## 読む順（全体像のつかみ方）

**遊ぶ → 読む → JSON をいじる** の順で仕組みが見えます。

1. まず `make run` で遊ぶ（コーナーをドリフトで攻め、ゲージを貯めてニトロで抜く）。
2. コードは **エントリ→状態→描画→入力→描き出し** の順で読む:
   1. `src/Main.flix` … init/update/view/reloads を App に繋いで起動する目次。まずここ。
   2. `src/World.flix` … ゲームの規則ぜんぶ（純粋）。冒頭 doc に **5 本柱**と
      **場面の移り変わりの図**（Title→Racing→Win/Lose→Title）がある。
      まず `tickRacing`（1 フレームの物語）と `curveDrift`（コーナリングの心臓）を読む。
   3. `src/Proj.flix` … OutRun 式の疑似遠近（1 行ぶんをセグメント 1 本として奥ほど詰め、道を折り込む投影）。
   4. `src/View.flix` と `src/ViewScene.flix` / `src/ViewRoad.flix` / `src/ViewCar.flix` …
      状態を絵に写す層たち（空と海 → 路面と縁石 → 車とドット絵 → 粒 → HUD → 幕）。
   5. `src/Controls.flix` … キーの割り当てと Doc の読み直し。
   6. `src/Sfx.flix` … World から「いま鳴らす音」を導く（一発の音と、鳴り続ける音。下の「音」を参照）。
   7. `src/render/SceneRender.flix` … 決定的な 8 場面を PNG に描き出す（リファレンス画像比較・目視批評）と、
      `src/render/SfxRender.flix` … 効果音 13 本を WAV に描き出す。どちらも `make render-all` の 1 手で走る。
3. 数値・色・コースをいじる（保存すると走行中のゲームに即反映されます）:
   - `assets/race.rules.json` … 手触りぜんぶ（速度・グリップ・ドリフト・ニトロ・スピン・アイテム）。
   - `assets/race.rivals.json` … 敵の性格（地力・コーナーの上手さ・好みのレーン）とラバーバンドの強さ。
   - `assets/race.theme.json` … 空・海・路面・縁石・マシンの色。
   - `assets/race.palette.json` … ドット絵の細かい色（タイヤ・ガラス・ヤシ・コーン）。
   - `assets/race.course.json` … コースの**形**（区間の表。長さ・曲がる強さ・坂・道幅・
     ガードレールの側）。いまは 66 行 2 幕（前半＝U 字で覚える幕 / 後半＝その鏡で試す幕）で 1 周。
   - `assets/race.props.json` … コースに**何を置くか**（rows の 1 行 = コースの 1 行・1 文字 = 道幅を 9 等分した
     レーン 1 本の塗り絵）。形と置き場で Doc を分けてあります（1 Doc = 1 関心の見本）。
   - `assets/fx/*.fx.json` … 煙・火花・噴射炎・衝撃波・クラッシュの粒。
   - `assets/race.sfxtune.json` … 効果音のつまみ（下の「音」を参照）。

黒箱（エンジンの部品）に出会ったら `make module Q=<やりたいこと>`（目次はエンジンリポの `docs/module-index.md`）で
`Render`（描画）・`Fx` / `FxDoc`（粒）・`PxSprite`（ドット絵）・`App`（ゲームループ）・
`JsonCodec`（JSON 読み）・`HeadlessRender`（PNG の描き出し）を引きます。

## 音（何が鳴るか・どこをいじると変わるか）

効果音は録音素材ではなく、`make render-all` が `src/render/SfxRender.flix` の合成レシピから
`assets/sfx/*.wav` を描き出した生成物です（`.wav` を直接編集しても次の描き出しで消えます）。

| いつ | 音 | 質感 |
|---|---|---|
| 走っている間ずっと | `engine` | 低い唸り。**速いほど高くなる**（鳴り続ける音） |
| ドリフト中ずっと | `skid` | 擦れた雑音（鳴り続ける音。ゲージが貯まるほど濃い） |
| ガードレールを擦っている間ずっと | `scrape` | 細い金属の擦れ（鳴り続ける音。タイヤの擦れとは太さで聞き分ける） |
| ドリフトの終わり | `grip` | 下がる 2 音。食いついた |
| ニトロ発動 | `nitro` | 駆け上がる 4 段階 + 噴射。一番強い音 |
| 直撃・草落ちのスピン | `crash` | 潰れた直撃のあと破片が散る |
| ライバルとの押し合い | `bump` | クラッシュと同じ質感で短く弱く |
| アイテム取得 | `item` | 明るく上がる 2 音 |
| ライバルを 1 台抜く | `overtake` | すれ違いの風 |
| 1 周した | `lap` | 上がる 2 音のジングル |
| ゴール | `win` / `lose` | 上がる 4 音 / 下がる 3 音 |
| 決定（開始・仕切り直し） | `start` | 短い 2 音のブリップ |

- **鳴らすきっかけ**を変える: `src/Sfx.flix`。一発の音は前後の World の差から名前を導く
  `events`、鳴り続ける音は今の World から「鳴っていてほしい音」を宣言する `hums` です。
  どちらも純関数なので、「いつ鳴るか」はここだけを読めば分かり、
  テスト（`test/TestSfx.flix`）で固定できます。
- **音量・高さ・長さ**を変える: `assets/race.sfxtune.json`（音ごとに volume / pitch / speed）。
  これは WAV に書き込まれる値なので、保存したら `make render-all` して起動し直すと届きます。
- **エンジン音の唸りの幅**を変える: 同じ Doc の `enginePitchLow` / `enginePitchHigh`
  （止まっているとき / 最高速のときの高さ）。ここだけは WAV を描き出し直さなくてよく、保存すると
  走行中のゲームへ即反映されます。
- **音そのもの**を作り替える: `src/render/SfxRender.flix`。矩形波・雑音・減衰・重ね・連結だけの語彙です。

鳴り続ける音は `App.withSustained` で書きます（`App.withAudio` は「このフレームで鳴らし始める名前」
だけを返す口なので、止め時のある音は書けません）。宣言に載っている間その音は鳴り続け、
載らなくなったフレームで止まります。音量と高さは毎フレーム与え直せるので、
速度で唸りが変わるエンジン音・強さで太る風・走っている間の足音のループはこの関数で作ります。

## いちばん小さな変え方（保存即反映）

- **すぐゴールしたい**: `race.rules.json` の `totalLaps` を 1 に。
- **接戦を強くしたい**: `race.rivals.json` の `rubberCatchUp` を大きく（離されてもすぐ追ってくる）。
- **ドリフトを楽にしたい**: `race.rules.json` の `driftSlide` を小さく（外へ流れにくい）。
- **コースの形を変える**: `race.course.json` の区間（sections）を書き換える。`curve` を大きくすると
  曲がりが行ごとに足し上がって急になり（40 前後で U 字）、`hill` は同じ数式で坂になり
  （1.0 が数行続くと丘の向こうが隠れる）、`width` を下げると道が細くなる。
  `rail` を `out` にするとコーナーの外側に壁が立つ。**curve と hill の合計は 1 周で 0 にする**
  （そうしないと空の流れと地平線が周回の継ぎ目で飛ぶ）。1 周の距離は行数 × 40px で
  自動的に決まる（別の数値として合わせ直す必要は無い）。
- **置き物を変える**: `race.props.json` の `rows` を塗り替える。`I` アイテム / `X` コーン /
  `G` 土管ゲート（その列が隙間）/ `P` 振り子バー。行数はコースの行数と揃える。
  ゲートの隙間の広さ（`gateGapLanes`）と振り子バーの周期・長さ（`barPeriod` /
  `barPhaseStep` / `barHalfWidth`）も同じファイルにある。

規則そのもの（曲がる・滑る・抜く・壊れる）はコード（`src/World.flix`）側にあります。
Doc はあくまで「調整したい初期値の宣言」で、壊れても既定値で必ず起動します（fail-open）。
