# このゲーム固有の設計原則

見下ろしレースのテンプレート。合言葉は **「最後のコーナーまで勝敗が判らないレース」**。
5 本柱 — 急カーブとドリフト / スリップストリーム + ラバーバンド AI / ニトロ / 押し合いとクラッシュ /
順位で決まるアイテム — が 1 本のループに噛み合う: 危険な走りだけがゲージを貯め、
ゲージだけが敵を千切れる。安全運転は構造的に勝てない。

- **規則はコード、数値・色・コース・敵の性格は Doc**。走る・曲がる・滑る・抜く・壊れるの規則は
  `src/World.flix`（純粋）にある。JSON に if 文を書き始めたら境界を越えた合図。
  手触りは `assets/race.rules.json`、敵は `assets/race.rivals.json`、色は `assets/race.theme.json` と
  `assets/race.palette.json`（ドット絵）、コースは `assets/race.course.json`、粒は `assets/fx/*.fx.json`。
- **コースは区間の表（sections）**: 1 行 = 同じ曲がり方・坂が続くひとまとまり。`len`（何行）/
  `curve`（曲がる強さ・+ が右）/ `hill`（坂・+ が登り）/ `width`（道幅 %）/ `rail`（壁の側）だけを持つ。
  **曲がりも坂も行を追うごとに足し上がる**（`Proj` が 2 回足し上げて道の折れと高さを出す）ので、
  同じ値が続くほど先の道は急に折れ・急に起きる（90 度・U 字・丘はこれ）。曲がりと坂は
  `Proj.Ramp` という同じ型・同じ引き方を共有する — 横に効くか縦に効くかだけが違う。
  行 → 区間の割り当てを決めるのは `CourseDoc.sectionAt` だけで、余りで巻き戻して周回する。
- **形と置き場は別 Doc**: 道の形は `race.course.json`、そこに何を置くかは `race.props.json`
  （rows の 1 行 = コースの 1 行・1 文字 = 道幅を 9 等分したレーン 1 本の塗り絵）。同時に読み直したい物でも、
  同時に触りたい物でもないので割ってある（`docs/doc-conventions.md` の「1 Doc = 1 関心」）。
  レーンは画面の位置ではなく道の中の位置なので、道が細くなれば当たりも一緒に細くなる。
- **障害物は「範囲」1 つにまとめる**: コーン・土管ゲート・振り子バーは、どれも
  `World.blockersAt` が返す `{lo, hi}`（道の中心からの横ずれの範囲）で表す。当たりも絵も
  この 1 か所から引くので、見えている物と当たる物がずれない。ゲートは範囲 2 つ（隙間の左右）に
  なるだけで、規則は 1 つのまま。すれすれは範囲 1 つにつき 1 回数えるので、狭い隙間を
  両側すれすれで抜けると自然にゲージが 2 回貯まる。
- **振り子バーは閉じた式**: `laneOf(行, t) = sin(2π(t/period + 行×phaseStep))`。乱数も
  覚えておく状態も持たない。行番号が位相を決めるので毎周同じリズムになり、覚えて攻略できる。
- **ガードレールは壊れない罰**: 当たってもスピンさせず、擦っている間ずっと減速 + 火花 +
  ゲージ加算。壁に擦り付けて曲がる「遅いが確実な線」を下手な人に残すのが仕事なので、
  ここをスピンにすると救済にならない。
- **横位置は道の中心からの横ずれ**: 自機もライバルもタイヤ痕も粒も、画面の絶対 x ではなく
  `off`（道の中心から右へ何 px）で持つ。道がどこまで曲がっても車は道に乗ったままで、
  画面 x を作るのは `Proj.screenX` の 1 か所だけ。
- **前進は距離、周回は割り算**: 自機は横（playerOff）にしか動かず、前進は `distance` を伸ばすだけ。
  順位は「自機より前にいるライバルの数 + 1」。空間分割や本格物理は持ち込まない。
- **カーブは「道が曲がる」**: 車を曲げるのではなく、道そのものが曲がっていく。横位置は道の中心から
  測るので「道に付いていく」ぶんは式に出てこず、グリップ超過ぶんだけアウトへ置いていかれる
  （`World.curveDrift`）。ドリフトは超過に関わらず一定速度で外へ流れる。この 1 関数がコーナリングの全て。
- **道の折れに縮みを掛けない**: `Proj.screenX` は「道の中の横位置」にだけ遠近の縮みを掛け、
  道そのものの折れ（`bendAt`）はそのまま足す。掛けると遠いセグメントほど横ずれが消えて道が必ず
  消失点へ収束し、45 度より急なカーブが描けなくなる。代わりに急カーブでは道が画面の外へ出て、
  そのセグメントは描かない（`ViewRoad.onScreen`）。曲がった実感は空・太陽・雲の横流し（`skyParallax`）が担う。
- **出来事は行またぎで 1 回だけ**: アイテム取得・障害物との当たり・すれすれは「通し行番号が
  増えた瞬間」にその行を 1 回だけ評価する（`World.crossRow`）。同じマスで二重に起きない。
  取ったアイテムは通し行番号の Set（taken）で覚える — 周回すると番号が変わるので次の周は復活する。
- **ラバーバンドは速度補正だけ**: ライバルの賢さは「距離差で速くなる/遅くなる」「コーナーで
  下手なりに減速する」「2 行先の道の中心へ寄る・前が詰まったら横へずれる」の 3 式で全部。
  経路探索・学習・乱数は持ち込まない（決定的 = テストも描き出しも安定）。
- **アイテムは乱数ゼロ**: 効果は「取った瞬間の順位」で決める（1 位 = スコアだけ / 2 位 = ゲージ /
  3 位以下 = 即ブースト）。運ではなく仕組みで逆転劇を保証する。
- **並走を罰しない**: 車どうしの接触は押し合い（互いに横へ弾かれ、少しのあいだ減速）で、
  スピンもゲージ没収もしない。追いついた瞬間に必ず壊れると、上位での駆け引きが成り立たない。
  スピンは障害物の直撃とドリフト中の草落ちだけが担う。
- **プレイヤーは詰まない・壊れない**: スピンしても必ず復帰し、レースは最後まで走れる。
  壊れた Doc でも fail-open で必ず起動し、Win/Lose から Space で必ず Title へ戻れる。
- **粒はエンジンのパーティクルに任せる**: 煙・火花・噴射炎・衝撃波・クラッシュは `assets/fx/*.fx.json` の宣言 +
  `Fx.burst / drawAll / sampleAt`（閉形式 — 粒の状態は保存しない）。World は「いつどこで焚くか」だけを
  持ち、絵は View が世界座標を毎フレーム投影して描く。タイヤ痕だけは世界座標の点列を持つ
  （路面に残る物は時刻から導けないため）。
- **カメラの振りは硬く切らない**: `Proj.softYaw` は上限へ滑らかに近づける（`x / (1 + |x|/上限)`）。
  硬く clamp すると急カーブでは常に上限に貼り付き、自機が画面の縁に固定されて
  自分の位置が読めなくなる。`yawGain` を下げても、貼り付いている間は絵が変わらない。
- **坂ではセグメントを奥から積む**: 平らな道ではセグメントどうしが重ならないので並び順は絵に出ないが、
  坂があると重なる。`Proj.segments` と `ViewRoad.partsOf` はどちらも奥 → 手前の順で返し、
  後から積んだ手前のセグメントが奥を隠す（丘の向こうの道が見えなくなる）。
- **道が画面から消えても奥行きは語る**: 急カーブでは道も道ぎわのヤシも画面の外へ抜けるので、
  草原の側（道から 130px 以上離れた升目）にもヤシの群れ・低木・標識を置く
  （`ViewScene.outfield`）。画面に入る升番号は投影の式を解いて求める（総当たりしない）。
  水平線には遠景の岬（`ViewScene.headlands`）を 3 枚重ね、曲がりと一緒に流す。
- **足さないもの**: 本格ドリフト物理（荷重・カウンター）・ダメージ/リタイア・複数コース・
  ミニマップ・乱数アイテム・ジャンプ（坂は滞空させない）。この骨格に亜種の決め打ちを
  足さない（足すなら複製した先で）。

## この画面の画風

**「真夏の海岸ハイウェイ。空は青く、海は光り、路面は白く灼けている。
速さは流れる景色とタイヤ痕で、危険は膨らむ白煙で見せる」。**

- 色は 3 つ: コバルトの空 / 灼けたアスファルト / 縁石の赤。
  砂（`sand`）だけは 3 色の間をつなぐ中間色として足してある（路肩の筋・草の轍・海ぎわの浜）。
  主役の 3 色は増やさない。
- やらないこと: 暗がりや霧で誤魔化さない（全部日向で見せる。主役の分離は落ち影の仕事）。
- 道は OutRun 式の疑似遠近（`src/Proj.flix`）: セグメントの高さを奥ほど詰め、行の横ずれを絵の折れ込みで
  見せる。層は `src/View.flix` の頭に並べてある。各層が「絵の下限」の 4 性質のどれを受け持つかも
  同じ場所に書いてある。
- マシンは矩形 1 枚でなくドット絵（`assets/race.sprite.json`・17×27）。車体 3 色だけテーマの
  player / rivalA..C で塗り替え、細部の色は `race.palette.json` が source of truth（`bin/fge palette` が「legend の意味色キーが色票から解けるか」を見張る）。
- **これは数ある画風の 1 つでしかない。** このテンプレから作るゲームは、画風を自分で決めて
  ここに書き直し、View の層構成ごと作り替えてよい（決め方は engine の `docs/art-ref/visual-dict.md`）。
  真似してほしいのは色や効果ではなく「層に分けて、各層に役割を持たせる」組み方の方。

## テストの当てどころ（ルールだけ）

- カーブ導出（直線の行で 0・曲がる行でその区間の curve = `World.curveAt`）とグリップ/ドリフトの横移動。
- ドリフトの成立（X + ハンドル・スピン中は不成立）とゲージ収支（ドリフト/スリップ/すれすれで
  貯まる・上限 1.0・発動で使い切る・未満タンでは撃てない）。
- スリップの範囲の判定（真後ろ・幅内で true = `World.slipActive`）。
- ラバーバンド（後ろのライバルは速く・前のライバルは遅く）。
- 行またぎの出来事（アイテムの順位別効果・二重取得なし・障害物ヒットでスピン・すれすれ加算）。
- 障害物 3 種（ゲートの隙間だけが通れる・隙間で両側すれすれ 2 回・バーの位置が閉じた式で
  1 往復すると戻る・ガードレールは道の端で止めてスピンさせずゲージを貯める）。
- 坂の速度（登りで遅く・下りで速い）。坂の見え方（セグメントの高さ・地平線の上下）はテストしない。
- スピン（操作不能・時間で復帰・ゲージ半減）と押し合い（接触で横へ弾かれる・スピンしない）。
- 追い抜き（加点・順位・二重加点なし）・勝敗（totalLaps で Win / 最下位だけ Lose・1 位だけ finishBonus）。
- 場面の決定（Title→Racing・Win/Lose→Title）・はみ出し判定（`World.onRoad`）。
- 煙・タイヤ痕・傾き・投影の写像はテストしない（スナップショット / 目視の担当）。
