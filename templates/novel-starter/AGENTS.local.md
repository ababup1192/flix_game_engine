# このゲーム固有の設計原則

ノベル・推理のテンプレート「消えた絵」。雨の夜の洋館、停電した書斎から一枚の絵が消えた。
主人公は招かれた時計職人（観察が癖）。

- **文章・分岐・結末は全部 Doc の rows**（assets/novel.story.json）。台本を書き換えれば
  別の事件になる。進め方の規則（ビートの送り・分岐・結末で表紙へ戻る）はコード（World）。
- **疑う相手を選ぶたび、館の照明がひとつ消える**（エッセンス）。suspect の選択肢だけが
  灯りを消す。灯りは台本の lamps より多くは消えず、もう一度はじめると全部つき直る。
- **操作は「選ぶだけ」**: ↑↓（カーソル）と決定（クリック / Z / Enter / Space）。ほかはメニュー（物語を
  止めるだけ）と表紙での終了。それ以外の操作を足さない。キーは `assets/novel.keys.json`（KeysDoc）。
- **時計は 2 本**: 文字送りと灯りの演出は物語の時計 `World.storyClock`（App.addClock・メニューで止まる・
  dt は `Clock.dtOf`）、雨・炎・埃・メニューの点滅は実時間 `w#realNow`（止まらない。秒へ戻すのは周期の関数に渡す所だけ）。
- **プレイヤーは死なない・詰まない**: どの結末も読み終われば表紙へ戻る。壊れた台本でも
  fail-open で必ず起動し、必ず表紙に帰れる。
- ダイアログ・文字送り・選択肢はエンジンの UiDialog / UiTypewriter / RichText / UiSlots /
  UiMenu を使う。自前の文字折りやメニューを書かない。

## この画面の画風

**「雨の夜の書斎。光は灯りの周りだけで、そこから離れるほど部屋は闇に沈む」。**

- 色は 3 つ: 沈んだ藍 / 灯りの金 / 雨の窓の青。
- やらないこと: 部屋を一様な明るさで塗らない（どの面も、灯りに近い側と遠い側で濃さが違う）。
  光を三角の光線として描かない — 縁が立つと舞台照明に見えて、部屋の空気が消える。
- 層は `src/View.flix` の頭に並べてある（壁 → 床 → 窓 → 額縁の影 → 額縁 → 灯り → 埃 → 暗くするオーバーレイ → 表紙 → ダイアログ）。
  各層が「絵の下限」の 4 性質（面に階調か質感 / 主役が背景から分離 / 層が分かれている /
  時間が流れている）のどれを受け持つかも同じ場所に書いてある。
- **読んでいる間も画面を止めない**: 雨は落ち、炎は灯りごとに位相をずらして揺れ、
  灯りの下を埃が昇る。どれも実時間 `realNow` と番号だけから導く（保存しない = 巻き戻しても同じ絵）。
- **これは数ある画風の 1 つでしかない。** このテンプレから作るゲームは、画風を自分で決めて
  ここに書き直し、View の層構成ごと作り替えてよい（決め方は engine の `docs/art-ref/visual-dict.md`）。
