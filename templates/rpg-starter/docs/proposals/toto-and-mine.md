## 1. トトの加入（T1「なくした杖」・決定）

流れ: 依頼の後、村で噂を聞く → ほこらでトトが「杖をほりモグに持っていかれた」→ ほこらの南の森の小さな洞窟 `toto_cave`（16×15・1 画面・出会い無し）
→ 入って正面に鉄格子、横に壁のレバー。引くと格子が上がる → 奥でほりモグ（`<<fight horimogu StaffBack>>`・新しい敵は足さない）
→ だいじなもの「トトのつえ」`totostaff` を持ち帰る → `<<take totostaff 1>>` → `<<join toto>>`。

- 洞窟は**仕掛けの初出**。敵も時間の圧も無い所で壁のレバーを 1 回だけ教え、坑道で難しく使う。
- **ほこらのイベントのマスは消す**（踏むたびに困っている話が開くのを止める）。トトに話しかけた時だけ `Shrine` が開く。
- 噂は依頼の後の村人 1 人（`Woman`）と、ミナが仲間にいる時のほこらの一言。坑道の入口の門（gate = toto）と `MineGate` は今のまま。
- トトの `joinLv` は 2 のまま（改訂 1 では 3 にしたが、坑道の出会いを減らしたのでルカとミナは Lv 2 前後で着く。3.1）。

```
Shrine:  <<if $toto>>（何も出さない）
         <<elseif $has_totostaff>> 返す → <<take totostaff 1>> → <<join toto>>
         <<elseif $quest == "none">> 「ぼくは トト。しゅぎょうちゅう なんだ」
         <<else>> 杖をなくした話 → 「みなみの もりの ほらあなに…」
```

選ばなかった案: T2 ほこらの封印（鍵をもらうだけで物語が薄い）・T3 魔物に囲まれたトト（固定の戦い 1 つだけで新しい形が無い）。

## 2. 坑道 B1〜B3（案 B・改訂 2）

### 2.1 そろえる事

- **1 階に仕掛け 1〜2 つ**。仕掛けはその階の入口近くで 1 回見せ、奥で本番に使う。
- 迷路: 正解の道 1 本 + 行き止まり 2〜3 本（**行き止まりの先には必ず宝箱か人**）+ 帰りの近道 1 本（奥から入口の近くへ。仕掛けを解くと開く）。
- 坑道の出会いの間隔はマップの値で上書きする（`minSteps / maxSteps`。空なら rules）。中ボス・ひとくいばこ・人で時間が増える分、雑魚の戦いを減らす（3 節）。
- **詰まない**: 岩はマップを出ると元の位置へ戻る。岩の部屋は上り階段の近くに置く。暗い階の入口にたいまつの宝箱を必ず置く。

### 2.2 仕掛けの種類（整理）

| 仕掛け | 何をすると | 何が起きる | 旗 |
|---|---|---|---|
| **壁のレバー** `lever` | しらべる | `flag` の旗が立つ / 倒れる（切り替え） | `opened` に出し入れ |
| **床のスイッチ** `plate` | `hold = false`: 先頭が踏む / `hold = true`: 岩を載せる | false は踏めば旗が立ったまま。true は同じ `flag` の床が全部岩で押さえられた時に旗が立ち、そのまま（解けた事を覚える） | `opened` |
| 開く物 `gate` | — | `flag` の旗が `openWhen`（on / off）の時だけ通れる。絵は `sprite`（鉄格子・がれき・飛び石） | 読むだけ |
| 押せる岩 `rock` | 歩いて押す | 1 マス先が床（物・人・岩・閉じた gate が無い）なら 1 マス動き、先頭も 1 マス進む。止まる時はぶつかる音 | 置き場は場面の値（マップを出ると元へ） |
| トロッコ `cart` | しらべる → 「のる？ はい」 | レールの上を自動で走り、レールの終わりで降りる。分かれ目 `junction` では `flag` の旗で `dir` か `dirOn` へ曲がる。走っている間は入力を受けない・出会い無し | 読むだけ |
| 水晶 `crystal` | しらべる | `order` の順に点ける。違えば同じ `flag` の水晶が全部消える。全部点くと `flag` の旗 | `opened` |
| 番をする者 `guard` | しらべる | `node` の会話 → `<<fight 敵 勝ちのノード>>` → 勝ちのノードの `<<open id>>` で消える（中ボス・ひとくいばこ） | `opened` |

スイッチは「壁のレバー」と「床のスイッチ」の 2 種類だけ。トロッコの分かれ目も壁のレバーの旗で切り替える（専用のスイッチは作らない）。

各階の迷路（[ ] = 区画・━ = 通路・⇢ = 一方通行・◇ = トロッコ）:

```
B1  [入口・ボルじい]━[分岐の広間: 壁のレバー ◇]
        ◇ レバー off → 北へ走る → [北の行き止まり: てつのつるはし] ◇ 帰りのトロッコ → 分岐の広間
        ◇ レバー on  → 東へ走る → [東の坑道]━[下り階段]
    [入口]━[岩の部屋 1: 岩を床へ → 格子]━[小部屋: 120G・やくそう ×3]
    [東の坑道]⇢(壊れたレール沿いの細道)⇢[入口]     … 帰りの近道
B2  [上り階段]━[入口の小部屋: コロンの店・たいまつ ×3 の宝箱]━[暗い迷路 3×2 画面]━[下り階段]
    迷路の行き止まり: かぎ / まほうのローブ / まりょくのみ ×2 / [くろがねゴブリン]━[はがねのつるぎ]
    割れた床 3 つ → [B3 西の小部屋: せいすい ×2]⇢(上り階段)⇢[B2 の入口の小部屋]
B3  [上り階段]━[取り残された人・石碑]━[湖の外周: 水晶 3 つ]━(飛び石)━[小島: みずのはごろも]━[鍵の扉]━[ボスの間]
    [上り階段の脇]━[岩の部屋 2: 岩 2 を床 2 へ → 格子]━[宝の部屋: 宝箱 2 つ（片方がひとくいばこ）]
```

決める事:
- **トロッコ**: レールは今の `=` `|` の 2 文字のまま。曲がり角は隣のレールから選んで描く（1 文字を増やさない）。
  トロッコは乗り終えると元の駅へ戻る（置き場を覚えない）。帰りは向こうの駅のトロッコか歩きの道。1 マス 0.08 秒（`rules.secondsPerRail`）。
  乗っている間は先頭の絵をトロッコに重ね、2 人目・3 人目は描かない（降りた所で trail を空にする。出入口の後と同じ）。
- **岩の部屋**: B1 は岩 1・床 1（押すだけで解ける）。B3 は岩 2・床 2（押す順を間違えると角に詰まる。ボルじいが先に「つまったら かいだんを でいりすれば もとに もどる」と言う）。
- **暗さ**: B2 は見えるのが先頭のまわり 1 マス。たいまつをフィールドで使うと 3 マス（120 歩）。たいまつは戦いでは今どおり敵 1 体に 12。B1 の宝のたいまつは消す。
- **落とし穴**は B3 の西の小部屋への寄り道。近道にはしない（鍵を飛ばせない）。
- **水晶の順番**は石碑と、B3 の人の台詞の両方で言う（「ひがしの あお、にしの あお、きたの あお」のように場所で）。違う順なら 3 つとも消えて「すいしょうの ひかりが きえた…」。罰の戦いは無し。

## 4. 実装の手間

### 4.1 新しい仕組みと、足す所

| 仕組み | 足す所 | 手間 |
|---|---|---|
| objects の kind 8 つ（lever・plate・gate・rock・cart・junction・crystal・guard） | `MapDoc.ObjectKind` に case・`objectKindOf` に 1 行ずつ・欄 `sprite, flag, openWhen, hold, order, dir, dirOn, node` | 小 |
| しらべる・通れるか・描くか | `WorldField` の 3 つの関数（`examine`・`canEnter`・`FieldView` の物の絵）に kind ごとの枝 1 つずつ。match を入れ子にしない | 中 |
| 旗の出し入れ | 名前付きの旗 `Progress.Rec.flags`（`FlagId`）を `Progress.withFlag` で立てる・下ろす（レバー・床のスイッチ）。開けた物の `opened` とは別に持ち、マップをまたいで読める。セーブに入る（版 4） | 小 |
| 岩を押す | `FieldRec` に `rocks: Map[String, Grid.Cell]`（今のマップの岩だけ。マップを移ると Doc の位置へ）・歩く関数に「前が岩なら押す」の枝・岩が動いたら hold の床を見て旗 | 中 |
| トロッコ | `Stride` に `Riding(List[Grid.Cell], startedAt)`・走る道はレールを辿る純関数 `Rail.pathFrom(map, cell, dir, opened)` で乗った時に 1 回だけ作る・`InputLayer` は Busy・出会いを数えない | 中 |
| 暗さとたいまつ | map の group に `dark`・items に `lightSteps`・`Progress` に残り歩数（せいすいと同じ形）・`WorldMenu` でたいまつを使える・`ZOrder.Layer` に `Dark`（Actors より手前）・見えるマスの外へ墨の矩形（1 画面 240 個以内。800 の予算に入る） | 中 |
| 会話 | `$has_<だいじなもの>`（items の kind = key の行から並べる）・`<<take 道具 個数>>`・`<<heal>>`・`<<shop 名前>>`・`<<open id>>` を扉以外の objects にも広げる・`make talk-vocab` | 小 |
| 店を 2 つ | `rpg.shops.json` の goods に `shop` | 小 |
| マップごとの出会いの間隔 | map の group に `minSteps / maxSteps` | 小 |
| 敵 2 体 | `rpg.foes.json`・`foe_moves.json`・`recolors.json` に行 | 小 |
| セーブ | 版を 3 へ（`lightSteps`。旗は `opened` のまま。岩は書かない） | 小 |

### 4.2 仕掛けの足し方を 1 つの形にそろえる

覚えるのは次の 4 つだけ。早見表（`AGENTS.local.md`）に 1 行ずつ、`map.schema.json` の note に同じ表を書く。

| 何か | Doc のどこ | 例 |
|---|---|---|
| マスにある物（調べる・押す・踏む・乗る） | `objects` の 1 行（`kind` を選ぶ） | chest・door・lever・plate・gate・rock・cart・junction・crystal・guard |
| 話す人 | `npcs` の 1 行（`node`） | ボルじい・コロン・取り残された人 |
| マップ全体の性質 | map の group の値 | `dark`・`minSteps`・`maxSteps`・`bgm` |
| 別のマップへ移る | `exits` の 1 行 + 通れる 1 文字 | 階段・落とし穴・洞窟の口 |

**固定の戦いはどれも同じ形**: 会話のノードで `<<fight 敵 勝ちのノード>>`、勝ちのノードで `<<open id>>`（消す）と `<<give>>` / `<<gold>>`。
中ボス・ひとくいばこ・洞窟のほりモグ・ボスの 4 つとも、コードに「この敵だけ」の枝を書かない。

objects の **JSON は平らなまま**（Studio のフォームが 1 行 = 1 物で出す）: `id, kind, x, y, sprite, item, count, gold, key, flag, openWhen, hold, order, dir, dirOn, node`。kind ごとに使う欄だけ埋める。
**読む時に組む**: `MapDoc.objectKindOf` が kind の名前と、その kind が使う欄だけから `MapDoc.ObjectKind` の case を組む（`Object = { id, x, y, sprite, kind: ObjectKind }`・`Chest({ item: Option[ItemId], count, gold }) | Door({ key: ItemId })`）。道具・敵・会話のノードの名前は読む時に Doc の id へ引き、引けない行は飛ばして 1 行言う（旗のように Doc を持たない名前は `Flag.fromJson`）。
規則は `src/WorldObject.flix` に kind ごとの 5 つの関数（`stateOf`・`blocks`・`examine`・`onArrive`・`onPush`）として集め、`WorldField` は見つけた物を渡すだけ。物の今のマスと状態は `WorldObject.objectsNow(map, r, progress)` の 1 か所（岩のように動く物は、ここで Doc の位置を今の位置へ替える）。状態（`ObjectState` = Closed / Opened / Gone）は `stateOf(kind, opened, flags)` が導き、塞ぐか（`blocks`）と絵（`FieldScreen.thingPart`）はそれだけを読む（鉄格子は「旗が立つと Gone」を stateOf に 1 枝）。旗は 2 つ: 開けた物は `Progress.Rec.opened`、物が立てて別の物が読む名前付きの旗は `Progress.Rec.flags`（`Flag.FlagId`。MapDoc と Progress の下の層 `src/Flag.flix` に置き、名前から作るのは読む所だけ。セーブの版 4 から往復する）。
**新しい kind を足す手順**（早見表の 1 行）: `MapDoc.ObjectKind` に case（その kind だけが使う値を payload に）→ `MapDoc.objectKindOf` に 1 行 → `make check` が並べる所（`WorldObject` の `stateOf`・`examine`・`onArrive`・`onPush`・`MapDoc.profileOf`・`FieldScreen.thingBoxOf`・`Res.kindProblemsOf`）→ スキーマの enum と欄 → テスト 2 本（調べると旗が変わる / 旗で通れるかが変わる）。
P8 の agent-eval のお題に「仕掛けを 1 つ足す（objects の kind）」を 1 本足す候補にする（PLAN 11 節の 7 と一緒に相談）。
