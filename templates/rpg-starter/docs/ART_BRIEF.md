# 絵の設計書（場面の絵を描き出す段階）

rpg-starter を 0 から作り直す。まず各場面の絵を、製品さながらの質でエンジンで描き出して並べる。
ゲームの規則（World・入力）はまだ作らない。この段階で作るのは**絵の部品（sprite.json）**と、
**場面を組んで PNG にする描き出し（SceneRender）**だけ。部品はそのまま本実装へ持ち越す。

## 人の注文（style-interview 2026-10-28）

- 視点: 見下ろし（村・ワールドマップ・ダンジョン）＋ 正面の戦闘（敵を正面から見る・仲間は窓に名前と数値）
- スタイル: 粗いピクセルアート（FC の実機に近い粗さ）
- パレット: FC 実機風の限定パレット（FC の 54 色から選ぶ・1 スプライトは 3 色＋透明まで）
- 輪郭: くっきり黒縁（純黒ではなく墨 `ink`）
- トーン: ビビッド
- ポストエフェクト: かけない（素のドット）

- 敵: 可愛らしく（丸いシルエット・大きめの目・愛嬌のある表情）。種類は多めに（依頼主 2026-10-28）

## 題材・色・やらないこと

- **題材**: 山あいの湖のほとりの「ルーネ村」。村の泉が枯れた。北の山の**水晶の坑道**の奥で、
  水晶を食べる大トカゲが水脈をふさいだ。村長の依頼を受け、鉱夫の娘と見習い魔法使いを仲間にして
  坑道（3 階層）へ向かい、ボスを倒して村へ帰ると泉がまた湧く。
- **色 3 つ**: 下地 = 草の緑（fc1A / fc2A / fc0A）・主役 = 主人公の青いマント（fc12 / fc21）・
  差し色 = 灯りの橙（たいまつ・水晶の光・宝箱。fc27 / fc28 / fc38）
- **光と影**: 光は左上から（全部の絵でそろえる）。光の色 = わずかに黄（受光面は黄寄りの段を選ぶ）、
  影の色 = 青〜紫（影の面は青寄り・紫寄りの段を選ぶ。茶色の物でも影は fc08 より fc03 / fc0C 寄りを混ぜてよい）
- **やらないこと**: なめらかなグラデーションを使わない。階調は FC の色の段とディザだけで作る。

## 器の大きさ（色の予算）

`色の予算: 極小 — 256×240 / 背景 1 タイル = 墨 + 3 色 / スプライト = 3 色 + 透明（墨を含む） / 画面 25 色前後 / 広い動かない面はディザ`

- 画面: **256×240**（design px）。描き出しは 3 倍の 768×720。
- タイル: **16×16**（FC のメタタイル。中の 8×8 を意識すると FC らしくなる）。
- 人: **16×16**（頭身はおよそ 2 頭身。4 方向 × 歩き 2 コマ）。
- 敵（正面）: 雑魚は 24〜48px、ボスは 80〜96px 角。敵は BG で描かれた想定で、
  **1 体 = 墨 + 3 色を 2 組まで**（FC の背景属性 2 つ分）。
- 文字: PixelMplus10（`assets/PixelMplus10-Regular.ttf`・10px）。窓の 1 行は 12〜16px。

## 色票（`assets/rpg.palette.json`）

- キーは **`fcXX`**（FC の色番号 $00〜$3D）と **`ink`**（墨。FC の黒 $0F の代わり。#0C0A1E）。
- **色票に色を足さない。** 54 色の外の色を使いたくなったら、FC の色の段とディザで作る。
- 白 `fc30` は取っておき（文字・泡・目の光・主役の 1 点）。広い面に使わない。
- 純黒 #000000 は使わない（墨 `ink` を使う）。

## ドット絵の書き方の決まり

- 作るのは `assets/rpg.<種類>.sprite.json`（`legend` の 1 文字 → 色票のキー。`paletteFile` は
  `assets/rpg.palette.json`）。手で格子を打っても、`art/*.px.star` / `art/*.pxsrc.json` から
  `bin/fge px build` で作ってもよい（台本から作るなら台本も `art/` に残す）。
- 描く前に `.claude/skills/pixel-art/SKILL.md`（engine 直下）の表で、お題の種類の行のファイルだけを読む。
  色の予算・ディザ・タイル地形は engine の `docs/art-ref/retro-pixel.md` の節を引く。
- `kind` を宣言する（tile / character / prop / icon / ui / background / vfx）。`bin/fge px kinds` 参照。
- 目で確かめる: `bin/fge sil <sprite.json>`（目視用の PNG）。検査: `bin/fge sprite <sprite.json>`・
  `bin/fge px check <sprite.json>`。タイルは 3×3 に並べて継ぎ目を見る。
- 確かめに描き出した PNG は `debug/` の下へ（git 管理外）。
