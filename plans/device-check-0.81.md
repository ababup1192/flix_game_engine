# 0.81 の実機確認（人の手で触る 12 項目）

どれも「壊れていたら分かりやすく出る」物。急がない。見つかった物は 0.81.x の直しとして割り込ませる。
結果は各行の □ を ☑ か ✗（何が起きたか 1 行）にして伝えてください。

## night_apartment（`cd ~/Documents/flix_ge_workspace/night_apartment && make run`）

1. □ クリックでマウスをキャプチャ → 見回せる → Esc で放れる
2. □ WASD で歩く・Shift で走る。階段・扉・壁で引っかかったり抜けたりしない（当たり判定を CharacterBody3d へ替えた）
3. □ 自販機・扉・住人などを見て E → 画面の下に英語の文言が出る／扉を見て E → 開け閉め
4. □ 光の見え方（線形の色）: 自販機の前・廊下・階段・202〜205 の部屋が、前と比べて変でないか
5. □ F3 → 左上に診断の行。「落とした光」が 0 か（部屋 2 つと住人が重なる所で 8 本を超えないか）
6. □ F8 で止める → 矩形を引く → 注釈を書く → F8 で再開（止めた画面と注釈の絵が等倍か）
7. □ 全画面の切り替え（Cmd+Enter など、ゲームの割り当て）と戻し

## fps3d_lab（`cd ~/Documents/flix_ge_workspace/fps3d_lab && make run`）

8. □ 部屋でクリック → マウスで見回す（横・上下）→ Esc で放れる → もう一度 Esc で終了の確認
9. □ 照準を番兵・本棚・地球儀に向けると名前が出る。番兵を見て Enter で敬礼
10. □ 壁や家具に沿って滑る（引っかからない）・光の見え方（書斎・礼拝堂）
