# テープ — PC・タブレット版（モックで合意済み。見た目と動きの正は `mock-wide.html`）

スマホ版（`mock.html`・`spec.md`）の操作感はそのまま残し、広い画面では「シートでせり上げていた物」を常に出しておく横の欄へ移す。
選ぶ → できることだけ出る、帯を送るとシーク、という流れは変えない。

## 今（0.94 の頁）を広い画面で開くと

- スマホの縦の 1 列をそのまま広げるだけ。動画は真ん中に細く、左右は黒い余白（1440×900 で画面の 2 割ほどしか使わない）
- 下のカード 3 枚が横に間延びし、シート（チャプター・注釈を書く・一覧）は画面の幅いっぱいにせり上がって動画を隠す
- キーボードで何もできない（Space で再生もしない）。マウスのホバーも無い
- 帯は横に長くなるので見通しは良くなるが、広げる・縮める（ズーム）が無い

## 手本（人の指示: PC の動画編集ソフトを参考に・ただしシンプルさは保つ）

Premiere / DaVinci Resolve / Final Cut と、レビュー用の Frame.io の並べ方にそろえる。足すのは並べ方と操作の型だけで、パネルやメニューを増やさない。

- 上半分の真ん中が大きなビューア、下は画面の幅いっぱいのタイムライン（左端にトラックの見出し 映像 / 台本 / 音）。タイムラインの上の目盛り（ルーラー）に時刻、注釈はルーラーの上のマーカー（Frame.io のコメントの印）
- 左はチャプター（編集ソフトの「プロジェクト / ビン」の位置）、右はインスペクタ（選んだ物の中身とできること）と、その下に注釈の一覧（Frame.io のコメント欄の形: 時刻・帯の色・本文。押すとその時刻へ）
- 再生の操作は編集ソフトの型: J / K / L（戻し再生・停止・再生。押すたびに速く）、← →（1 コマ）、Home / End、M（マーカー＝今のコマに注釈）
- タイムラインのズームはルーラーの右端の小さなスライダーと Ctrl/⌘＋ホイール。トラックの高さは固定（変えさせない）
- やらない: メニューバー・ドックの組み替え・複数のビューア・トラックの追加・波形の大きな表示・色の補正などの編集の機能

## どの画面でどの形になるか

判断は CSS の media query と `matchMedia`（読み込み時と、回した・窓を変えた時）。字の大きさは変えず、形だけを替える。

| 形 | 条件 | 中身 |
|---|---|---|
| スマホ（今のまま） | 幅 < 720px | 縦 1 列・下のドック・シート |
| タブレット縦 | 幅 ≥ 720px かつ 縦長（高さ ≥ 幅） | 上: 動画（大きく）＋右に細い「選んだ物」の欄 / 下: 帯（高さ 3 段 → 帯ごとに太く）。シートは右の欄の中に開く |
| 横長（タブレット横・PC） | 幅 ≥ 1024px かつ 横長 | 3 列: 左「チャプター」（常に出す・分岐のカードも）/ 真ん中: 動画と帯 / 右「選んだ物」と「注釈の一覧」。注釈を書く・文章を直すは右の欄の中で書く（シートを使わない） |
| 間（720〜1023px の横長） | 上の 2 つに入らない横長 | タブレット縦と同じ 2 列 |

入力の違い（形とは別に足す）:

| 条件 | 足す物 |
|---|---|
| マウス（`(hover: hover) and (pointer: fine)`） | キーボードの操作（下）・ホバーでカードと帯のクリップの中身を出す・ホイールで帯を送る・Ctrl/⌘＋ホイールで帯を広げる/縮める・右の欄の上に操作の早見 |
| 指（`pointer: coarse`） | 今の操作のまま（タップ・長押し・帯を指で送る）。ピンチで帯を広げる/縮める |

キーボード（マウスの時だけ早見を出す。入力欄にいる時は効かない）:

| キー | 動き |
|---|---|
| Space / K | 再生／停止 |
| J / L | 戻し再生／再生（押すたびに 2 倍・4 倍。K で止める） |
| ← / → | 1 コマ戻す／進める |
| Home / End | 頭／お尻 |
| M | 今のコマに注釈（N と同じ。編集ソフトのマーカーの型） |
| Shift + ← / → | 1 秒 |
| [ / ] | 前の行／次の行（台本の行の頭へ） |
| ↑ / ↓ | 選ぶ帯を 映像 ⇄ 台本 ⇄ 音 で替える（今のコマの物を選ぶ） |
| N | 今選んでいる物に注釈（何も選んでいなければシーン全体） |
| E | 台詞を直す（台本の台詞を選んでいる時） |
| R | 囲む |
| O | 物を選ぶ |
| P | ここから遊ぶ（playUrl が無くボタンが出ていない時は何もしない） |
| Esc | やめる（囲む・物を選ぶ・書きかけ） |
| ⌘/Ctrl + Enter | 付ける／直す |
| ⌘/Ctrl + S | 書き出す（1 回目で書き出しを開き、2 回目で保存） |

## 変えない物

- データ（tape.json・TAPE）・書き出す .md の形・localStorage の鍵
- 色（黒地・黄色だけが目立つ色・帯の色）・ドットの字の起動画面
- スマホ版の見た目（720px 未満はバイトまで今のまま。モックとの一致のテストを通し続ける）

## 決まった事（2026-11-14）

並べ方:

1. 横長の 3 列では、左のチャプターを常に出す（出し入れの切り替えは作らない）
2. 横長の動画（横画面のゲーム）は 3 列のまま、真ん中を広くする（左 216px・右 300px）。真ん中の枠の比は動画の縦横比のまま（決め打ちしない）。スマホの形には効かせない
3. キーボードの割り当ては上の表のまま
4. ⌘/Ctrl + S は 2 回押し: 1 回目で書き出しを開いて保存のボタンに focus、2 回目で保存
5. タイムラインの真ん中の線（今のコマ）は固定で、帯の方が動く
6. シートのボタンは右上の ✕ と、右下の黄色の確定（＋ 追加 / ✓ 適用 / ↓ 保存）。入力が空・変えていない時の確定は薄くして押せない

キーと保存の決まり:

- 日本語の変換中（`isComposing`、または keyCode 229。Safari は確定のキーを isComposing 偽・keyCode 229 で送る）は、Esc と ⌘/Ctrl + Enter を含めてどのキーも効かない
- P は playUrl が無い（ここから遊ぶのボタンが出ていない）時は何もしない
- ⌘/Ctrl + S は、書きかけの注釈・直し（そのシートが開いている）がある時は書き出しを開かず、トーストで「先に付けるか閉じてください」と出す
- 保存は downloads の口 → 共有シート → ダウンロード の順。ただしマウスの広い形では共有シートを飛ばす（downloads の口 → ダウンロード）。指の形は今までどおり

形が変わった時（iPad を回す・窓が 1024 や 720 をまたぐ）:

- 開いている書きかけのシート（注釈・文章を直す）は閉じずに、書いた字と focus を持ったまま新しい置き場（右の欄 ⇄ 下からのシート）へ移す
- 書きかけでないシート（チャプター・一覧・このコマ・書き出す）は閉じる。2 列でチャプターのシートを開いたまま 3 列になった時も閉じる（左の欄と同じ中身が 2 つ並ぶため）
- 広い形からスマホの形へ書きかけのまま戻る時は、シートの後ろの暗い幕（scrim）を付け直す

注釈のマーカー・一覧から音の注釈を選ぶ時は、注釈に欄を足さず（.md と localStorage の形は変えない）、名前が同じ音のうち時刻が一番近い物を選ぶ。見つからなければ時刻だけ移して何も選ばない。
