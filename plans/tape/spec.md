# テープ — 仕様（合意したモックから起こした物）

**正は `plans/tape/mock.html`（artifact: https://claude.ai/artifact/D34o7epL9BTadqDFgx4f7f ）。** この文書はモックの画面と挙動を言葉にした物で、食い違ったらモックが正。
モックと違う物を作りたくなったら、作る前に人へ相談する（作業員は止まって親へ報告）。

## 何をする物か

e2e の flow を流して撮った動画を、スマホで 1 つの頁（index.html・video.mp4・strip.jpg）として見る。GitHub Pages の推測できない URL に置き、レビュワーに渡す。止めたコマで映像・台本・音に注釈を付け、台本の文章をその場で直し、
最後に AI へのプロンプト（.md・JSON つき）を保存する。人は見る・指す・つまむ、AI は書く・確かめる。

## 画面（縦 1 画面・ページはスクロールしない。高さ 667 で全部が収まる）

上から:

1. **上の帯**: 左に一覧（付けた数のバッジ）、真ん中に題名と今のシーン名（⌄ つき。タップでチャプター）、右に「書き出す（n）」（0 件なら押せない）
2. **プレビュー**: 動画（縦長のまま）。上に canvas を重ねる
   - タップ = 再生／停止（真ん中に再生／停止の印が一瞬）
   - 長押し（0.28 秒）= 押している間だけ元の文章（直した台詞を重ねていない絵）
   - 止めている時だけ、右下に「「シーン名」に注釈」ボタン（再生中と囲む・物を選ぶの最中は出さない）
   - 直した行が流れている間は、メッセージウィンドウの位置に直した台詞を重ね、上の端に「直した文章を重ねています · 長押しで元と比べる」
   - 止めている時、付けた注釈の矩形をそのコマの前後 12 コマで出す（再生中は出さない）
3. **タイムライン**: 上の行に「時刻 / 長さ」・再生ボタン・「ここから遊ぶ」。下に 3 段の帯
   - 帯は 映像（コマの絵の帯・シーン名）／台本（行ごとのクリップ・話し手の色・演出コマンドは灰色・直した行に「直」）／音（♪ 名前）
   - 帯の左端に、帯の絵（映像・台本・音）を色つきで固定
   - 真ん中の白い線が今のコマ。帯を横に送るとシーク（−1f +1f のボタンは無い）
   - 分岐の所に白いひし形「分」。タップでチャプターの分岐のカードへ
   - 付けた注釈は、その帯の上に色の点
4. **下（ドック）**: 何も選んでいない時は「今のコマにある物」のカード 3 枚（映像: シーン名 ／ 台本: 話し手「文」 ／ 音: 近い音）。注釈の数を ●n
   - カードか帯のクリップをタップすると、それが選ばれる（帯で白いふち。台本ならメッセージウィンドウに藤色の点線）
   - 選んだ時の下: 帯の色のバッジ・何を選んだか・✕。その下に、その物でできることだけ
     - 映像: 囲む ／ 物を選ぶ ／ このコマ（World の値・出ている物）
     - 台本（台詞）: 文章を直す（主） ／ 注釈
     - 台本（演出コマンド）: この演出に注釈（主）
     - 音: この音に注釈（主） ／ 聴く（少し前から再生）
   - 選んだまま帯を送ると、選んでいる台詞・音も今のコマの物に移る
   - 注釈を付け終えた・直し終えたら、3 枚のカードに戻る
   - 囲む・物を選ぶの最中は、下の行が案内の文に変わる
5. **シート**（下からせり上がる 1 枚）: 注釈を書く・文章を直す・一覧・このコマ・チャプター・書き出す
   - 左上「やめる」、右上「付ける／直す／閉じる」
   - 開いて 0.45 秒の間は、後ろの幕へのタップで閉じない（スマホの指を離した時のクリック対策）

色: 黒地。目立つ色は黄色（#ffcc4d）だけ。帯の色 = 映像 #6cc4ff・台本 #c8a6ff・音 #ffcc4d。話し手の色はゲームが渡す。

## 注釈の種類

| kind | 帯 | 何に付くか | rect |
|---|---|---|---|
| `rect` | 映像 | 指で囲んだ所 | あり |
| `object` | 映像 | 画面に出ている物（id・名前） | 物の矩形 |
| `scene` | 映像 | シーン全体（id・名前・from・to） | なし |
| `script` | 台本 | 台本の行（演出コマンドなら command も） | なし |
| `sound` | 音 | 鳴った音（素材の名前・環境音か効果音か・台本の行） | なし |

文章の直し（scriptEdits）は注釈とは別に持つ: ファイル・ノード・行・話し手・前・後。改行は台本の「／」。

## 書き出す .md の形（モックの buildPrompt が正）

1. 一言（題名・ゲーム・commit）と「注釈は 映像・台本・音 のどれかに付く。rect は画面に対する割合」
2. `## 台本の直し（このとおりに書き換えてください）` — 「台本が変わっていたら、行番号でなく「前」の文章で探してください。」の一行と、行ごとに前と後
3. `## 映像への注釈` / `## 台本への注釈` / `## 音への注釈`
4. JSON: `game, commit, flow, fps, reproduce{flow,talk}, scriptEdits[], annotations[{id, track, kind, target, scene, frame, seconds, rect, script, note, probes}]`

保存: claude.ai の中なら downloads の口、Pages や単体の HTML なら共有シート（iOS・Android の「ファイルに保存」）、だめならダウンロード。コピーも残す。

## 本物で埋める物（モックでは手で合わせた）

| モックの欄 | 本物での出どころ |
|---|---|
| scenes | flow の `mark`（と台本のノード） |
| timeline（いまの台本の行） | probe `talkLine` をフレームごと |
| lines（台本の行の中身） | .yarn を読む |
| sounds | 鳴らした出来事（素材名・時刻・台本の行） |
| objects | 描いた物の名前と矩形（ゲームが宣言した分） |
| probes | vocab の probes をフレームごと |
| strip.jpg | 動画から 0.5 秒ごとのコマ |
| MSG（メッセージウィンドウの寸法）・話し手の色 | ゲームが渡す（`msg`・`speakers`。色は theme の Doc）。`msg.when`（問い → 値）がそろうコマだけ直した台詞を重ねる（NVL の間は重ねない） |
| branches | 複数の flow（同じ始まりから分かれた物）の木 |

## ここから遊ぶ

押すと別のタブで Pages の最新のブラウザ版が開き、そのシーン（台本の行）から始まる。直した台詞があれば、前の文が一致する行だけに当てて始める（ずれていたら当てずに言う）。直した台本で開いた時は、その旨の帯を出す。
ポップアップを開くスクリプトは使わない（普通のリンク）。

## 作らない物（モックに無い）

- 台本の行を足す・消す・並べ替える編集
- タイムラインの上でクリップを動かす編集
- 注釈の返信・共有

## 届け方

`bin/fge tape publish` が Pages の `tapes/<YYYYMMDD>-<乱数 16 桁>/` に置き、URL を出す（noindex・一覧なし・30 日で消す）。レビュワーは注釈を付けて .md を保存し、作った人へ返す。
